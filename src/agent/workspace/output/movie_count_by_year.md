# 电影数量按年份分布统计

## 查询 SQL
```sql
SELECT start_year, COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie' AND start_year IS NOT NULL
GROUP BY start_year
ORDER BY start_year
```

## 统计结果

| 统计项 | 数值 |
|--------|------|
| 年份范围 | 1894 - 2032 |
| 总年份数 | 138 年 |
| 最早电影年份 | 1894 年（1 部） |
| 电影数量最多的年份 | 2024 年（21,336 部） |
| 电影数量最少的完整年份 | 1894 年（1 部） |

## 关键趋势

- **早期（1894-1920）**：电影产业起步，从个位数增长到 2,646 部/年
- **黄金时代（1930s-1940s）**：稳定在 1,100-2,200 部/年，二战期间略有下降
- **战后复苏（1950s-1960s）**：稳步增长至 3,000+ 部/年
- **现代增长（1970s-2000s）**：从 4,000 部/年增长至 10,000+ 部/年
- **爆发期（2010s-2024）**：从 13,000 部/年飙升至 21,336 部/年（峰值）
- **未来年份（2025+）**：数据不完整，数量递减
