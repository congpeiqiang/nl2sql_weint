查询计划：average_rating 最高的 10 部电影（片名 + 评分）

1. 从 titles 表（别名 t）查询，仅保留 title_type = 'movie' 的电影
2. 应用评分可信度过滤：num_votes > 10000（避免低投票数影片评分虚高）
3. 排除评分缺失：average_rating IS NOT NULL
4. 选择输出列：t.primary_title（片名）、t.average_rating（评分）
5. 按 t.average_rating DESC 降序排序
6. 取前 10 行（通过 run_sql 的 limit 参数控制，SQL 中不写 LIMIT）

说明：本查询为单表查询，无需 JOIN。
