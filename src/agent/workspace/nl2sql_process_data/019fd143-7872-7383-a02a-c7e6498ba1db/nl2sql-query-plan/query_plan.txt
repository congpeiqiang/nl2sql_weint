查询计划：参演电影平均评分最高的前10位演员（参演电影数>=5且每部电影投票数>50000）

1. 从 titles 表筛选 title_type='movie' 且 num_votes > 50000 的电影（先筛选再JOIN，减少数据量）
2. 通过 principals.title_id = titles.id 连接 principals 表
3. 通过 principals.name_id = names.id 连接 names 表
4. 在 principals 上过滤 category_id IN ('actor', 'actress')（演员定义）
5. 按 n.id, n.primary_name 分组
6. 计算每个演员的参演电影数 COUNT(DISTINCT p.title_id) 和平均评分 AVG(t.average_rating)
7. 用 HAVING 过滤参演电影数 >= 5
8. 按平均评分 AVG(t.average_rating) DESC 排序
9. 取前10位（通过 run_sql limit=10 控制，SQL 中不写 LIMIT）
