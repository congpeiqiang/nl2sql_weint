查询计划：按十年分组统计电影的平均评分和数量

1. 数据源：titles 表（别名 t），单表查询，无需 JOIN。
2. 筛选条件：
   - t.title_type = 'movie'（只统计电影，排除短片/电视剧/游戏等）
   - t.start_year IS NOT NULL（start_year 可能为 NULL，需过滤以保证年代计算有效）
3. 计算年代（decade）：FLOOR(t.start_year / 10) * 10
   - 示例：1994 → 1990, 2005 → 2000, 2023 → 2020
4. 聚合计算：
   - 平均评分：AVG(t.average_rating)
   - 电影数量：COUNT(*)
5. 分组：按年代 FLOOR(t.start_year / 10) * 10 分组
6. 排序：按年代升序排列（decade ASC），便于按时间顺序查看
7. 输出列：decade（年代）、avg_rating（平均评分）、movie_count（电影数量）
