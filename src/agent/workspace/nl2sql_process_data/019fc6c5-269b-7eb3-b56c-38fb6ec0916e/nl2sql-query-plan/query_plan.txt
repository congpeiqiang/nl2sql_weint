查询计划：1990年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的电影记录
2. 在筛选结果中进一步过滤 start_year BETWEEN 1990 AND 1999（1990年代）
3. 排除 average_rating 为 NULL 的记录（无评分的电影不参与平均计算）
4. 对筛选后的记录计算 AVG(t.average_rating) 作为平均评分
5. 返回单行结果：平均评分（avg_rating）

说明：
- 单表查询，无需 JOIN
- 整体聚合，无需 GROUP BY
- 聚合查询返回单行，无需 LIMIT
- 使用别名 t 引用 titles 表
