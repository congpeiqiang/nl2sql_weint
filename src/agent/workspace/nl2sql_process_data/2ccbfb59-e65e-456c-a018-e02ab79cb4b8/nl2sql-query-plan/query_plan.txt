查询计划：统计 2000-2023 年每年电影产量，并计算相比上一年的增长率

1. 从 titles 表筛选 title_type='movie' 且 start_year BETWEEN 2000 AND 2023 且 start_year IS NOT NULL 的行
2. 按 start_year 分组，统计每年电影数量 COUNT(*)
3. 使用 LAG(COUNT(*)) OVER (ORDER BY start_year) 获取上一年电影产量
4. 计算增长率 = (当年产量 - 上一年产量) / 上一年产量 * 100%，使用 NULLIF 防止除零
5. 按 start_year ASC 排序输出
6. 通过 run_sql 的 limit 参数控制返回行数（24 年数据）

注意：
- 2000 年作为第一年，LAG 返回 NULL，增长率应为 NULL
- 数据源为 MySQL，支持窗口函数 LAG
- 增长率保留 2 位小数，乘以 100 转为百分比
