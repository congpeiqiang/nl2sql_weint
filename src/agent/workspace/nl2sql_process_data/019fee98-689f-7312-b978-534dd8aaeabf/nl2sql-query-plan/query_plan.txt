查询计划：找出评分衰退最严重的电视剧系列，计算首季平均评分和末季平均评分的下降幅度

数据源：MySQL

1. 从 titles 表筛选电视剧系列（title_type='tvSeries'），作为系列表 s
2. 通过 episodes 表关联：episodes.parent_id = s.id（系列 → 剧集）
3. 通过 episodes.id = ep.id 关联到剧集标题表 ep（titles 表），获取剧集评分 average_rating
4. 过滤条件：ep.average_rating IS NOT NULL，e.season_number IS NOT NULL
5. 构建 CTE season_ratings：按 s.id, s.primary_title, e.season_number 分组，计算每季平均评分 AVG(ep.average_rating) AS season_avg_rating
6. 构建 CTE series_stats：对每个系列聚合
   - total_seasons = COUNT(*)
   - min_season = MIN(season_number)，max_season = MAX(season_number)
   - first_season_rating = MAX(CASE WHEN season_number = MIN(season_number) THEN season_avg_rating END)
   - last_season_rating = MAX(CASE WHEN season_number = MAX(season_number) THEN season_avg_rating END)
   - HAVING COUNT(*) >= 3（至少3季）
7. 最终 SELECT：计算下降幅度 decline_rate_pct = (first_season_rating - last_season_rating) / first_season_rating * 100
8. 按 decline_rate_pct DESC 排序，取下降最严重的系列
9. 通过 run_sql 的 limit 参数控制返回行数（不写 SQL LIMIT）
