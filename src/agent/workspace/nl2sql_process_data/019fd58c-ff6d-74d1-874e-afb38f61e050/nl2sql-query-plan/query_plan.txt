查询计划：导演-演员黄金搭档（合作>=3次且平均评分>=7.5）

1. 从 titles t 筛选 title_type='movie' 且 num_votes>5000 且 average_rating IS NOT NULL 的电影作品
2. 通过 pd.title_id = t.id 连接 principals pd（导演），并筛选 pd.category_id='director'
3. 通过 pa.title_id = t.id 连接 principals pa（演员），并筛选 pa.category_id IN ('actor','actress')
4. 通过 pd.name_id = d.id 连接 names d，获取导演名 d.primary_name
5. 通过 pa.name_id = a.id 连接 names a，获取演员名 a.primary_name
6. 按导演(d.id, d.primary_name)和演员(a.id, a.primary_name)分组
7. 计算每组合作次数 COUNT(*) 和平均评分 AVG(t.average_rating)
8. 用 HAVING 过滤：COUNT(*) >= 3 且 AVG(t.average_rating) >= 7.5
9. 按合作次数 DESC、平均评分 DESC 排序
10. 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT）
