1. 构建 actor_works CTE：从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id IN ('actor','actress') 且 t.title_type='movie' 且 t.average_rating IS NOT NULL
   - 按 p.name_id 分组，计算 AVG(t.average_rating) AS actor_avg_rating
2. 构建 director_works CTE：从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id='director' 且 t.title_type='movie' 且 t.average_rating IS NOT NULL
   - 按 p.name_id 分组，计算 AVG(t.average_rating) AS director_avg_rating
3. 将 actor_works a INNER JOIN director_works d ON a.name_id = d.name_id
   - 内连接确保只保留同时是演员和导演的人
4. JOIN names n ON a.name_id = n.id 获取人物姓名 primary_name
5. SELECT n.primary_name, ROUND(a.actor_avg_rating,2) AS actor_avg_rating, ROUND(d.director_avg_rating,2) AS director_avg_rating
6. 通过 run_sql 的 limit 参数控制返回行数（不写 SQL LIMIT 子句）
