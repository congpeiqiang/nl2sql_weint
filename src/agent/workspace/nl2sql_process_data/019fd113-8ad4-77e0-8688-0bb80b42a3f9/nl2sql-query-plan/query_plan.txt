查询计划：克里斯托弗·诺兰导演的电影的平均评分

目标：计算克里斯托弗·诺兰（Christopher Nolan）作为导演的所有电影的平均评分（AVG(average_rating)）

步骤：
1. 从 names 表筛选 primary_name = 'Christopher Nolan' 的人物记录，获取其 id
2. 通过 principals.name_id = names.id 连接 principals 表，筛选 category_id = 'director' 的记录，获取诺兰导演的作品 title_id
3. 通过 principals.title_id = titles.id 连接 titles 表，筛选 title_type = 'movie' 的电影作品
4. 对筛选出的电影作品计算 AVG(titles.average_rating) 作为平均评分
5. 返回平均评分结果

JOIN 关系：
- principals.name_id = names.id（参与者 → 人物）
- principals.title_id = titles.id（参与者 → 作品）

WHERE 条件：
- names.primary_name = 'Christopher Nolan'（导演姓名）
- principals.category_id = 'director'（导演角色）
- titles.title_type = 'movie'（电影类型）

聚合：
- AVG(titles.average_rating)（平均评分）
