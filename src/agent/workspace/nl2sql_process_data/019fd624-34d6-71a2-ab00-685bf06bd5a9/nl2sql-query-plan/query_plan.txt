查询计划：找出职业生涯跨度最长的前10位演员

1. 从 names 表获取演员信息（names.id, names.primary_name）
2. 通过 principals.name_id = names.id 连接到 principals 表
3. 通过 principals.title_id = titles.id 连接到 titles 表
4. 筛选条件：
   - principals.category_id IN ('actor', 'actress')  # 演员定义，包含男女演员
   - titles.start_year IS NOT NULL  # 排除无年份的作品
5. 按 names.id, names.primary_name 分组
6. 计算每个演员的职业生涯跨度：MAX(titles.start_year) - MIN(titles.start_year)
7. 确保演员至少有2部作品（HAVING COUNT(DISTINCT titles.id) >= 2），使跨度有意义
8. 按职业生涯跨度 DESC 排序
9. 取前10行（通过 run_sql 的 limit 参数控制，不在 SQL 中写 LIMIT）
