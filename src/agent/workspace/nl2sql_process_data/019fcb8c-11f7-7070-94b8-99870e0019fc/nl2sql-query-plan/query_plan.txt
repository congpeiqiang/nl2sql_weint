查询计划：查询 1990 年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）中筛选数据
2. WHERE 条件：
   a. t.title_type = 'movie' — 只查电影类型
   b. t.start_year >= 1990 AND t.start_year <= 1999 — 限定1990年代
   c. t.start_year IS NOT NULL — 排除年份为NULL的记录（业务规则：NULL值处理）
   d. t.average_rating IS NOT NULL — 排除无评分的记录，确保AVG计算准确
3. SELECT 计算 AVG(t.average_rating) — 对所有符合条件的电影求平均评分
4. 无需 JOIN（单表查询）
5. 无需 GROUP BY（整体聚合，不按子维度分组）
6. 无需 ORDER BY（只返回一个聚合值）
7. 无需 LIMIT（聚合查询只返回一行）
