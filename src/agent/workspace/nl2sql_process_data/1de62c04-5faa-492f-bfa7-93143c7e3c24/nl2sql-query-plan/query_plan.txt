查询计划：职业生涯跨度最长的前10位演员

1. 从 titles 表获取每部作品的 start_year（作品年份），仅保留 start_year IS NOT NULL 的作品
2. 通过 principals.title_id = titles.id 连接 principals 表（参与者表）
3. 在 principals 中筛选演员：category_id IN ('actor', 'actress')
4. 通过 principals.name_id = names.id 连接 names 表（人物表）
5. 按演员分组（GROUP BY names.id, names.primary_name）
6. 对每个演员计算职业生涯跨度 = MAX(titles.start_year) - MIN(titles.start_year)
7. 按职业生涯跨度降序排序（ORDER BY career_span DESC）
8. 取前10行（LIMIT 10）
9. 显示字段：names.primary_name（演员名）、职业生涯跨度年数
