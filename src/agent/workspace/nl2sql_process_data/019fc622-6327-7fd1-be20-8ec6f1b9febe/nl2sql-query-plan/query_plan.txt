查询目标：统计电视剧系列（title_type='tvSeries'）的数量分布，包含三个子查询。

子查询1：电视剧系列总数
1. 从 titles 表筛选 title_type='tvSeries' 的行
2. 使用 COUNT(*) 统计总数

子查询2：按类型（genre）统计电视剧系列数量分布
1. 从 titles 表筛选 title_type='tvSeries' 的行（别名 t）
2. 通过 titles_genres（别名 tg）连接 genres（别名 g）：t.id = tg.title_id AND tg.genre_id = g.id
3. 按 g.display_name 分组
4. 使用 COUNT(DISTINCT t.id) 统计每个类型的系列数量（避免多类型关联导致重复计数）
5. 按 series_count DESC 排序

子查询3：按首播年份统计电视剧系列数量趋势
1. 从 titles 表筛选 title_type='tvSeries' 且 start_year IS NOT NULL 的行
2. 按 t.start_year 分组
3. 使用 COUNT(*) 统计每个年份的系列数量
4. 按 t.start_year ASC 排序
