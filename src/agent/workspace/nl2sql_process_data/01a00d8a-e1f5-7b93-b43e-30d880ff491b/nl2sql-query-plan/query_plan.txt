查询计划：查询熔接数据（工艺阶段 = '预热|熔接'）

1. 从 aix_crystal_comm_data 表查询数据（单表，无 JOIN）
2. WHERE 筛选：proc_stage = '预热|熔接'（熔接工序；该取值已通过数据探查确认存在）
3. SELECT 列出熔接工序关键字段：
   - id（主键）
   - device_code（设备编码）
   - collect_time（采集时间）
   - puller_batch_no（炉次编号）
   - ingot_no（棒次编号）
   - work_order_no（工单编号）
   - proc_stage（工艺阶段）
   - melt_bright（熔接亮度）
   - melt_time（熔料时间）
   - melt_time_seconds（熔料时长秒）
   - melt_depth（熔液深度）
4. ORDER BY collect_time DESC 按采集时间倒序，优先展示最新熔接数据
5. 行数由 run_sql 的 limit 参数控制（SQL 中不写 LIMIT 子句，避免与 run_sql 服务端自动追加的 cap 冲突）
