查询计划：找出职业生涯跨度最长的前10位演员

1. 从 names 表（别名 n）获取演员姓名 primary_name
2. 通过 principals 表（别名 p）连接：p.name_id = n.id，筛选演员 p.category_id IN ('actor', 'actress')
3. 通过 titles 表（别名 t）连接：t.id = p.title_id，筛选 t.start_year IS NOT NULL
4. 按演员分组 GROUP BY n.id, n.primary_name
5. 计算每个演员的：
   - 第一部作品年份 first_year = MIN(t.start_year)
   - 最后一部作品年份 last_year = MAX(t.start_year)
   - 职业生涯跨度 career_span = MAX(t.start_year) - MIN(t.start_year)
6. 按 career_span DESC 排序
7. 取前10行（通过 run_sql 的 limit 参数控制，SQL 中不写 LIMIT）
