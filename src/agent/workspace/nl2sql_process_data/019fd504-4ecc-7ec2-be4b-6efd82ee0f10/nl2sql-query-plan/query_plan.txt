查询计划：查询既是演员又是导演的跨界者，对比其演员作品和导演作品的平均评分

1. 构建 actor_works CTE：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id IN ('actor','actress')（演员定义，包含男女演员）
   - 筛选 t.title_type = 'movie'（只统计电影作品）
   - 筛选 t.average_rating IS NOT NULL（排除无评分作品）
   - 按 p.name_id 分组
   - 计算 AVG(t.average_rating) AS actor_avg_rating 和 COUNT(*) AS actor_movie_count
   - HAVING COUNT(*) >= 3（至少3部演员作品，保证统计有意义）

2. 构建 director_works CTE：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id = 'director'（导演定义）
   - 筛选 t.title_type = 'movie'（只统计电影作品）
   - 筛选 t.average_rating IS NOT NULL（排除无评分作品）
   - 按 p.name_id 分组
   - 计算 AVG(t.average_rating) AS director_avg_rating 和 COUNT(*) AS director_movie_count
   - HAVING COUNT(*) >= 2（至少2部导演作品，保证统计有意义）

3. 关联两个 CTE 找出跨界者：
   - JOIN actor_works a ON director_works d ON a.name_id = d.name_id
   - 内连接确保该人既是演员又是导演

4. 关联人物表获取姓名：
   - JOIN names n ON a.name_id = n.id

5. 选择输出列：
   - n.primary_name, a.actor_movie_count, ROUND(a.actor_avg_rating,2), d.director_movie_count, ROUND(d.director_avg_rating,2), ROUND(d.director_avg_rating - a.actor_avg_rating,2) AS rating_difference

6. 排序：
   - ORDER BY rating_difference DESC（按评分差异降序）

7. 限制行数：
   - 通过 run_sql 的 limit 参数控制（SQL中不写LIMIT子句）
