导演-演员黄金搭档查询计划（合作 >=3 次 且 平均评分 >= 7.5）
===========================================================

目标：找出合作 3 次以上（>=3）且合作电影平均评分 >= 7.5 的导演-演员组合，
输出：导演名、演员名、合作次数、平均评分。

执行步骤（CoT 推理）：

1. 【锁定导演侧参与者】从 principals 表取别名为 pd 的行，筛选 category_id='director'，
   得到"导演-作品"记录集合（pd.title_id 即该导演执导的作品）。

2. 【锁定演员侧参与者】从 principals 表取别名为 pa 的行，筛选
   category_id IN ('actor','actress')（业务规则：演员必须同时包含男/女演员），
   得到"演员-作品"记录集合（pa.title_id 即该演员参演的作品）。

3. 【作品表关联】将 titles 表（别名 t）与 pd 连接：pd.title_id = t.id，
   并加过滤 t.title_type='movie'（只统计电影）且 t.num_votes > 5000（评分可信度）
   且 t.average_rating IS NOT NULL（评分非空）。

4. 【导演-演员配对】将 pd 与 pa 通过同一部电影关联：pa.title_id = t.id，
   这样每部电影上，每位导演与该片每位演员形成一对（导演, 演员, 电影）组合行。

5. 【人名关联】将 pd.name_id 连接到 names（别名 d）取导演名 d.primary_name；
   将 pa.name_id 连接到 names（别名 a）取演员名 a.primary_name。

6. 【分组统计】按 (d.id, d.primary_name, a.id, a.primary_name) 分组：
   - 合作次数 = COUNT(*)（该组合共同电影上的行数）
   - 平均评分 = AVG(t.average_rating)（合作电影评分的均值）

7. 【分组后筛选 HAVING】保留 COUNT(*) >= 3（合作 3 次以上）且
   AVG(t.average_rating) >= 7.5（平均评分达标）的组合。

8. 【排序】按 collaboration_count DESC、avg_rating DESC 排序（合作越多越靠前，
   同次数时评分高者优先）。

9. 【行数控制】SQL 中不写 LIMIT，执行时通过 run_sql 的 limit 参数控制返回行数。

关键连接列：
- principals.title_id = titles.id（作品关联）
- principals.name_id = names.id（人物关联）
- principals 自关联：pd.title_id = pa.title_id（同一作品上的导演与演员配对）

数据来源校验：种子示例 sql/director_actor_collaboration.md 与上述计划一致
（HAVING COUNT(*) >= 3 AND AVG(t.average_rating) >= 7.5，WHERE num_votes>5000）。
