查询计划：查询电影 "The Matrix" 的演员姓名和角色排序(ordering)

1. 从 titles 表（别名 t）中筛选出 primary_title = 'The Matrix' 且 title_type = 'movie' 的作品记录
   - 条件：t.primary_title = 'The Matrix' AND t.title_type = 'movie'
   - 目的：定位到目标电影的唯一作品ID

2. 通过 principals.title_id = titles.id 连接 principals 表（别名 p）
   - 目的：获取该电影的所有参与者记录

3. 在 principals 表上应用演员过滤条件
   - 条件：p.category_id IN ('actor', 'actress')
   - 目的：只保留演员（包含男演员和女演员），排除导演、编剧等其他职位

4. 通过 principals.name_id = names.id 连接 names 表（别名 n）
   - 目的：获取每位演员的姓名信息

5. 选择输出字段
   - SELECT n.primary_name AS actor_name, p.ordering
   - 目的：显示演员姓名和角色排序

6. 按 p.ordering ASC 排序
   - 目的：按角色重要性排序，ordering=1 为最主要角色
