查询计划：1990年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的电影记录
2. 进一步筛选 start_year BETWEEN 1990 AND 1999，限定为1990年代
3. 排除 start_year 为 NULL 的记录（WHERE t.start_year IS NOT NULL）
4. 对筛选后的记录计算 AVG(t.average_rating) 得到平均评分
5. 返回单行结果：平均评分（avg_rating）

说明：
- 单表聚合查询，无需 JOIN
- 无需 GROUP BY（查询整体平均，非分组平均）
- 无需 ORDER BY / LIMIT（聚合查询仅返回一行）
