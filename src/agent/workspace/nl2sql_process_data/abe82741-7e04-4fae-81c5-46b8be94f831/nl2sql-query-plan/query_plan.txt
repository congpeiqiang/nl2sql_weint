查询计划：职业生涯跨度最长的前10位演员

1. 从 names 表（别名 n）获取演员信息，需要字段：n.id, n.primary_name
2. 通过 principals 表（别名 p）连接 names 和 titles：
   - JOIN principals p ON p.name_id = n.id
   - JOIN titles t ON t.id = p.title_id
3. 筛选条件：
   - p.category_id IN ('actor', 'actress')  -- 演员定义规则：包含男演员和女演员
   - t.start_year IS NOT NULL  -- 排除 start_year 为 NULL 的作品
4. 按演员分组：GROUP BY n.id, n.primary_name
5. 计算每个演员的职业生涯跨度：MAX(t.start_year) - MIN(t.start_year) AS career_span
6. 按 career_span 降序排序：ORDER BY career_span DESC
7. 取前10行（通过 run_sql 的 limit 参数控制，不在 SQL 中写 LIMIT）
