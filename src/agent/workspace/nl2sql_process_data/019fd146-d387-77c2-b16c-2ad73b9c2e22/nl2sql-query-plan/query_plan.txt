查询计划：电影 "The Matrix" 的参演演员及其角色排序

1. 从 titles 表（别名 t）筛选出电影 "The Matrix"：
   - 条件：t.primary_title = 'The Matrix' AND t.title_type = 'movie'
   - 目的：定位到该电影的唯一作品记录（titles.id）

2. 通过 principals 表（别名 p）关联作品与参与者：
   - 连接条件：p.title_id = t.id
   - 目的：获取该电影的所有参与者记录

3. 筛选出演员（包含男演员和女演员）：
   - 条件：p.category_id IN ('actor', 'actress')
   - 目的：只保留演员，排除导演、编剧等其他职位

4. 通过 names 表（别名 n）关联参与者与人物：
   - 连接条件：p.name_id = n.id
   - 目的：获取演员的姓名（n.primary_name）

5. 选择输出字段：
   - n.primary_name AS actor_name（演员姓名）
   - p.ordering AS role_ordering（角色排序）

6. 排序：
   - 按 p.ordering ASC 升序排列（ordering=1 为主演，值越小越重要）

7. 返回结果行（通过 run_sql 的 limit 参数控制行数，SQL 中不写 LIMIT）
