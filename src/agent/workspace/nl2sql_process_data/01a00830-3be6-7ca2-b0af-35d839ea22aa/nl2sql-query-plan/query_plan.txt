QUERY PLAN - 曲目（Track）数据概览查询

目标：返回曲目明细（曲目名称、所属专辑、类型）+ 曲目总数概览。

1. 明细查询：
   1.1 从 track 表读取曲目：trackid（ID）、name（曲目名称）、albumid、genreid、milliseconds、unitprice
   1.2 LEFT JOIN album 表（track.albumid = album.albumid）→ 取 album.title 作为"所属专辑"
       - 使用 LEFT JOIN：允许存在 albumid 为 NULL 的曲目（schema 中 albumid 可空）
   1.3 LEFT JOIN genre 表（track.genreid = genre.genreid）→ 取 genre.name 作为"类型/流派"
       - 使用 LEFT JOIN：genreid 可空，且 genre.name 可空
   1.4 无 WHERE 过滤（查询全量曲目）
   1.5 按 track.trackid ASC 排序，保证输出稳定
   1.6 不写 LIMIT 子句；行数由 run_sql 的 limit 参数控制

2. 总数概览查询：
   2.1 独立执行 SELECT COUNT(*) FROM track 得到曲目总数
