查询计划：查询片长超过180分钟的电影

1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的电影
2. 进一步筛选 runtime_minutes > 180 且 runtime_minutes IS NOT NULL 的记录（排除NULL片长）
3. 选择输出字段：primary_title（电影标题）、runtime_minutes（片长）
4. 按 runtime_minutes DESC 排序，便于查看最长的电影
5. 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT 子句）

说明：
- 单表查询，无需 JOIN
- 无聚合，无需 GROUP BY / HAVING
- 业务规则：title_type='movie' 才是电影；runtime_minutes 可能为 NULL 需处理
