查询计划：average_rating 最高的 10 部电影（显示标题和评分）

1. 从 titles 表（别名 t）筛选 title_type='movie' 的电影
2. 应用评分可信度规则：过滤 num_votes > 10000（避免低投票数影片评分虚高）
3. 过滤 average_rating IS NOT NULL（排除无评分记录）
4. SELECT 列：t.primary_title（标题）、t.average_rating（评分）
5. 按 t.average_rating DESC 排序（评分从高到低）
6. 取前 10 行（LIMIT 10，通过 run_sql 的 limit 参数控制）

无需 JOIN，单表查询。
