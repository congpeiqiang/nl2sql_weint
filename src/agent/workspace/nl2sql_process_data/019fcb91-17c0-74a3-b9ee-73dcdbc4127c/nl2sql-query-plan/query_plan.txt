查询计划：1990年代电影平均评分

1. 从 titles 表（别名 t）中筛选数据
2. 过滤条件：title_type = 'movie'（只查电影）
3. 过滤条件：start_year BETWEEN 1990 AND 1999（1990年代）
4. 过滤条件：start_year IS NOT NULL（排除年份缺失的记录）
5. 过滤条件：average_rating IS NOT NULL（排除评分缺失的记录）
6. 对过滤后的结果计算 AVG(average_rating)，得到1990年代电影的平均评分
7. 返回单行单列结果

说明：
- 单表查询，无需 JOIN
- 无需 GROUP BY（整体聚合）
- 无需 ORDER BY 和 LIMIT（只返回一个聚合值）
- 数据源方言：MySQL
