# 查询计划：既是演员又是导演的跨界者，对比演员作品和导演作品的平均评分

## 目标
找出同时出现在演员表（category_id IN ('actor','actress')）和导演表（category_id = 'director'）中的所有人物，分别计算他们作为演员参演电影的平均评分和作为导演执导电影的平均评分，并对比两者。

## 执行步骤

### 步骤1：构建演员作品CTE (actor_works)
1. 从 principals 表（别名 p）筛选 category_id IN ('actor', 'actress') 的记录
2. 通过 p.title_id = t.id 连接 titles 表（别名 t）
3. 筛选 t.title_type = 'movie'（只统计电影作品）
4. 筛选 t.average_rating IS NOT NULL（排除无评分的作品）
5. 按 p.name_id 分组
6. 计算 AVG(t.average_rating) AS actor_avg_rating 和 COUNT(*) AS actor_movie_count
7. 使用 HAVING COUNT(*) >= 3 过滤（确保有足够样本量）

### 步骤2：构建导演作品CTE (director_works)
1. 从 principals 表（别名 p）筛选 category_id = 'director' 的记录
2. 通过 p.title_id = t.id 连接 titles 表（别名 t）
3. 筛选 t.title_type = 'movie'（只统计电影作品）
4. 筛选 t.average_rating IS NOT NULL（排除无评分的作品）
5. 按 p.name_id 分组
6. 计算 AVG(t.average_rating) AS director_avg_rating 和 COUNT(*) AS director_movie_count
7. 使用 HAVING COUNT(*) >= 2 过滤（确保有足够样本量）

### 步骤3：合并两个CTE找出跨界者
1. 将 actor_works (a) 与 director_works (d) 通过 a.name_id = d.name_id 进行 INNER JOIN
   - 只有同时出现在两个CTE中的人（既是演员又是导演）才会被保留
2. 通过 a.name_id = n.id 连接 names 表（别名 n）获取人物姓名

### 步骤4：输出结果
1. SELECT 人物名、演员作品数、演员平均评分、导演作品数、导演平均评分、评分差异
2. 评分差异 = director_avg_rating - actor_avg_rating
3. 按评分差异 DESC 排序（导演评分高于演员评分的排前面）
4. 使用 ROUND(x, 2) 保留两位小数

## 关键JOIN关系
- principals.title_id = titles.id（参与者→作品）
- principals.name_id = names.id（参与者→人物）
- actor_works.name_id = director_works.name_id（演员作品→导演作品，找跨界者）

## 业务规则应用
- 演员定义：category_id IN ('actor', 'actress')（必须同时包含男女演员）
- 导演定义：category_id = 'director'
- 只统计电影：title_type = 'movie'
- 排除无评分作品：average_rating IS NOT NULL
