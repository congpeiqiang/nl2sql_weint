# 查询计划：找出合作 3 次以上的导演-演员组合，且合作电影平均评分 >= 7.5

## 目标
找出合作 3 次以上且合作电影平均评分 >= 7.5 的导演-演员组合。

## 执行步骤

### 步骤 1: 确定导演参与者集合
- 从 `principals` 表筛选出所有 `category_id = 'director'` 的记录，作为导演参与者集合 `pd`
- 通过 `pd.title_id` 关联到 `titles` 表，确保作品类型为 `movie`
- 通过 `pd.name_id` 关联到 `names` 表获取导演姓名

### 步骤 2: 确定演员参与者集合
- 从 `principals` 表筛选出所有 `category_id IN ('actor', 'actress')` 的记录，作为演员参与者集合 `pa`
- 通过 `pa.title_id` 关联到同一部 `titles` 表（与导演在同一部电影中）
- 通过 `pa.name_id` 关联到 `names` 表获取演员姓名

### 步骤 3: 关联导演与演员（通过同一部电影）
- 导演参与者 `pd` 和演员参与者 `pa` 通过 `titles` 表关联
- 即：`pd.title_id = t.id` 且 `pa.title_id = t.id`，两者在同一部电影中

### 步骤 4: 应用过滤条件
- `t.title_type = 'movie'`：只统计电影
- `t.num_votes > 5000`：确保评分可信度
- `t.average_rating IS NOT NULL`：排除无评分电影

### 步骤 5: 分组聚合
- 按导演 ID + 导演名 + 演员 ID + 演员名 分组
- 计算 `COUNT(*)` 作为合作次数
- 计算 `AVG(t.average_rating)` 作为合作电影的平均评分

### 步骤 6: 应用 HAVING 过滤
- `COUNT(*) >= 3`：合作 3 次以上
- `AVG(t.average_rating) >= 7.5`：平均评分 >= 7.5

### 步骤 7: 排序
- 按合作次数降序排列
- 合作次数相同时按平均评分降序排列

### 步骤 8: 输出
- 导演名、演员名、合作次数、平均评分
- 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT）
