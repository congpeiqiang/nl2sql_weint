查询计划：参演电影数量最多的前13位演员

1. 从 titles 表（别名 t）筛选 title_type = 'movie' 的电影作品
2. 通过 principals.title_id = titles.id 连接 principals 表（别名 p），仅保留电影作品的参与者记录
3. 在 principals 中筛选 category_id IN ('actor', 'actress')，即只统计演员（含男女演员）
4. 通过 principals.name_id = names.id 连接 names 表（别名 n），获取演员姓名
5. 按演员分组（GROUP BY n.id, n.primary_name），计算每位演员参演的电影数量 COUNT(DISTINCT p.title_id)
6. 按参演电影数量降序排序（ORDER BY movie_count DESC）
7. 取前13位演员（LIMIT 13，通过 run_sql 的 limit 参数控制）

涉及表：
- names (n): 演员信息，取 primary_name
- principals (p): 参与者关联，取 title_id, name_id, category_id
- titles (t): 作品信息，取 title_type 用于过滤电影

JOIN 关系：
- principals.name_id = names.id
- principals.title_id = titles.id

过滤条件：
- p.category_id IN ('actor', 'actress')  # 演员定义
- t.title_type = 'movie'  # 只统计电影

聚合：
- COUNT(DISTINCT p.title_id) AS movie_count  # 参演电影数量

排序与限制：
- ORDER BY movie_count DESC
- 取前13位
