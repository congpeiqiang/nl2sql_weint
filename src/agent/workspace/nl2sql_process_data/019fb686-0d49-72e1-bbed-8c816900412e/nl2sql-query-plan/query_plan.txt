查询计划：找出合作 3 次以上的导演-演员组合，且合作电影平均评分 >= 7.5

1. 从 titles 表筛选 title_type='movie' 且 average_rating IS NOT NULL 的电影作品（t 别名）
2. 通过 principals pd 关联导演：pd.title_id = t.id 且 pd.category_id = 'director'
3. 通过 principals pa 关联演员：pa.title_id = t.id 且 pa.category_id IN ('actor', 'actress')
4. 通过 names d 关联导演人物：pd.name_id = d.id，获取导演名 d.primary_name
5. 通过 names a 关联演员人物：pa.name_id = a.id，获取演员名 a.primary_name
6. 按导演(d.id, d.primary_name) + 演员(a.id, a.primary_name) 分组
7. 计算每组合作次数 COUNT(*) 和平均评分 AVG(t.average_rating)
8. HAVING 过滤：COUNT(*) >= 3 且 AVG(t.average_rating) >= 7.5
9. 输出：导演名、演员名、合作次数、平均评分
10. 排序：合作次数 DESC，平均评分 DESC
11. 通过 run_sql 的 limit 参数控制返回行数（不写 SQL LIMIT 子句）
