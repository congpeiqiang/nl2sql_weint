QUERY PLAN: 查询炉台D330等径阶段的温度数据（温度随时间变化记录）
================================================================

目标模型: aix_crystal_comm_data (单表，无JOIN)

1. 筛选: WHERE device_code = 'D330'（炉台D330）
2. 筛选: WHERE proc_stage = <等径对应取值>（工艺阶段=等径；在SQL生成阶段先用
   SELECT DISTINCT proc_stage 探查确认该字段对"等径"的实际取值，如 '等径' 或其他编码）
3. SELECT 列表（温度字段 + 时间字段 + 上下文字段）:
   - collect_time          (采集时间，作为温度随时间变化的时间轴)
   - act_therm_field_temp  (实际热场温度 SP)
   - act_liq_lvl_temp      (实际液面温度 ℃)
   - liq_lvl_pyro          (液面高温计 ℃)
   - main_vac_t1_temp      (主真空管1温度 ℃)
   - main_vac_t2_temp      (主真空管2温度 ℃)
   - set_liq_lvl_temp      (设定液面温度 ℃)
   - proc_stage            (工艺阶段，用于确认筛选生效)
   - device_code           (设备编码，用于确认炉台)
4. 排序: ORDER BY collect_time ASC（按时间升序，形成温度随时间变化的时间序列）
5. 行数控制: SQL 中不写 LIMIT，由 run_sql 的 limit 参数控制（默认cap 1000）

执行前校验:
- dry_run 验证 SQL 语法与字段存在性
- 确认 proc_stage 等径取值与 device_code='D330' 有数据返回
