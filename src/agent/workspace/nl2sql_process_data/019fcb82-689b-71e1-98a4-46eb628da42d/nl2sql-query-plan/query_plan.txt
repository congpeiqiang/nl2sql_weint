查询计划：查询 1990 年代（1990-1999）电影的平均评分

1. 从 titles 表中筛选 title_type = 'movie' 的行（只保留电影类型）
2. 进一步筛选 start_year >= 1990 AND start_year <= 1999 的行（限定1990年代）
3. 对筛选后的结果计算 AVG(average_rating)，得到平均评分
4. 返回单行结果：1990年代电影的平均评分

注意事项：
- 无需 JOIN，单表查询
- AVG 函数会自动忽略 NULL 值的 average_rating
- start_year 的范围过滤已隐含排除了 NULL 值
- 不需要 GROUP BY，因为只返回一个聚合值
- 不需要 ORDER BY 和 LIMIT
