查询计划：找出评分衰退最严重的电视剧系列，计算首季平均评分和末季平均评分的下降幅度

1. 从 titles 表筛选电视剧系列：WHERE s.title_type = 'tvSeries'（s 为系列别名）
2. 通过 episodes 表关联剧集：JOIN episodes e ON s.id = e.parent_id（episodes.parent_id = 系列 id）
3. 通过 episodes 关联剧集标题：JOIN titles ep ON e.id = ep.id（episodes.id = 剧集 id，ep 为剧集别名）
4. 筛选有效评分与季号：WHERE ep.average_rating IS NOT NULL AND e.season_number IS NOT NULL
5. 按系列 + 季号分组，计算每季平均评分：
   GROUP BY s.id, s.primary_title, e.season_number
   SELECT s.id, s.primary_title, e.season_number, AVG(ep.average_rating) AS season_avg_rating
   （得到 season_ratings 中间结果）
6. 对每个系列，确定首季（MIN(season_number)）和末季（MAX(season_number)）的平均评分：
   - first_season_rating = 该系列 season_number = MIN(season_number) 时的 season_avg_rating
   - last_season_rating = 该系列 season_number = MAX(season_number) 时的 season_avg_rating
7. 计算总季数 total_seasons = COUNT(DISTINCT season_number)
8. 过滤至少 3 季的系列（HAVING COUNT(*) >= 3），保证首末季衰退分析有意义
9. 计算下降幅度：decline_rate_pct = (first_season_rating - last_season_rating) / first_season_rating * 100
10. 按 decline_rate_pct DESC 排序，取前 N 行（通过 run_sql limit 参数控制，不写 SQL LIMIT）

关键 JOIN 列：
- episodes.parent_id = titles.id（系列）
- episodes.id = titles.id（剧集）
