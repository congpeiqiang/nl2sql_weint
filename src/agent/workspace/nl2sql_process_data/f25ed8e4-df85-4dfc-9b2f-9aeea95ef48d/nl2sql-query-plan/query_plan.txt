查询计划：每个类型中评分最高的电影

1. 从 titles 表筛选 title_type='movie' 且 average_rating IS NOT NULL 且 num_votes > 10000 的电影
2. 通过 titles_genres 表连接 titles 和 genres：
   - titles_genres.title_id = titles.id
   - titles_genres.genre_id = genres.id
3. 使用窗口函数 ROW_NUMBER() OVER (PARTITION BY genres.id ORDER BY titles.average_rating DESC) 为每个类型内的电影按评分降序编号
4. 筛选 rn = 1 的行，即每个类型中评分最高的电影
5. 选择输出列：genres.display_name（类型名）、titles.primary_title（电影标题）、titles.average_rating（评分）
6. 按类型名排序输出
