查询计划：参演电影平均评分最高的前10位演员

目标：找出参演电影平均评分最高的前10位演员，要求参演电影数>=5，且每部参演电影的投票数>50000。返回演员姓名、参演电影数、平均评分。

1. 从 titles 表（别名 t）筛选电影作品：
   - t.title_type = 'movie'（只统计电影）
   - t.num_votes > 50000（每部参演电影投票数必须大于50000）
   - 保留 t.id, t.average_rating, t.num_votes

2. 通过 principals 表（别名 p）关联 titles：
   - JOIN 条件：p.title_id = t.id
   - 筛选演员：p.category_id IN ('actor', 'actress')
   - 保留 p.name_id, p.title_id

3. 通过 names 表（别名 n）关联 principals：
   - JOIN 条件：p.name_id = n.id
   - 保留 n.id, n.primary_name

4. 按演员分组聚合：
   - GROUP BY n.id, n.primary_name
   - 计算参演电影数：COUNT(DISTINCT p.title_id)
   - 计算平均评分：AVG(t.average_rating)

5. 分组后筛选（HAVING）：
   - COUNT(DISTINCT p.title_id) >= 5（参演电影数至少5部）

6. 排序与限制：
   - ORDER BY 平均评分 DESC（平均评分从高到低）
   - 取前10位（LIMIT 10）

7. 返回字段：
   - n.primary_name AS 演员姓名
   - COUNT(DISTINCT p.title_id) AS 参演电影数
   - ROUND(AVG(t.average_rating), 2) AS 平均评分
