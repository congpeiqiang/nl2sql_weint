查询计划：1990年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的电影行
2. 进一步筛选 start_year 在 1990 到 1999 之间（1990年代）
3. 排除 average_rating 为 NULL 的行（保证评分有效）
4. 对筛选后的行计算 AVG(t.average_rating) 作为平均评分
5. 返回单行结果：平均评分

说明：
- 单表聚合查询，无需 JOIN
- 平均评分指标 = AVG(average_rating)
- 电影类型过滤 = title_type = 'movie'
- 年代过滤 = start_year BETWEEN 1990 AND 1999
