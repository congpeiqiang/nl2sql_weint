1. 从 principals 表取导演记录 pd，筛选 pd.category_id = 'director'
2. 通过 pd.title_id = t.id 连接 titles 表 t，筛选 t.title_type = 'movie' 且 t.average_rating IS NOT NULL
3. 通过 pa.title_id = t.id 连接 principals 表 pa（演员参与者），筛选 pa.category_id IN ('actor', 'actress')
4. 通过 pd.name_id = d.id 连接 names 表 d，获取导演名 d.primary_name
5. 通过 pa.name_id = a.id 连接 names 表 a，获取演员名 a.primary_name
6. 按导演(d.id, d.primary_name)和演员(a.id, a.primary_name)分组
7. 计算合作次数 COUNT(*) 和平均评分 AVG(t.average_rating)
8. HAVING 过滤：COUNT(*) >= 3 且 AVG(t.average_rating) >= 7.5
9. 按合作次数降序、平均评分降序排序
10. 通过 run_sql 的 limit 参数控制返回行数
