查询计划：找出每个类型（genre）中评分最高的电影

1. 从 titles 表筛选电影：t.title_type = 'movie'，且为保证评分可信度加 num_votes > 10000，并排除评分 NULL（average_rating IS NOT NULL）
2. 通过 titles_genres 关联表连接 genres：titles_genres.title_id = titles.id，titles_genres.genre_id = genres.id
3. 使用窗口函数 ROW_NUMBER() OVER (PARTITION BY genres.id ORDER BY titles.average_rating DESC) 为每个类型内的电影按评分降序编号
4. 外层查询筛选 rn = 1，即每个类型中评分最高的电影
5. 选择输出列：genres.display_name（类型名）、titles.primary_title（电影标题）、titles.average_rating（评分）
6. 按类型名排序输出
7. 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT）
