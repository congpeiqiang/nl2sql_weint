查询计划：随机删除 playlisttrack 表的一条记录

背景：Chinook_Aliyun（PostgreSQL）中 playlisttrack 是最大的明细表（8715 行），
复合主键 (playlistid, trackid)，纯多对多关联数据，删除关联行不触碰主表/系统关键数据。

1. 在 playlisttrack 中按 random() 随机排序，取 1 行（不写 LIMIT，用 run_sql 的 limit 参数控制），
   记录该行的 playlistid 与 trackid 作为待删记录内容（用于报告）
2. 使用记录的复合主键构造精准删除条件：WHERE playlistid = X AND trackid = Y
3. 执行 DELETE FROM playlisttrack，确认受影响行数 = 1
4. 执行验证查询：SELECT playlistid, trackid FROM playlisttrack
   WHERE playlistid = X AND trackid = Y，应返回 0 行
5. 汇总报告：删除的表名、删除的记录内容、删除成功确认
