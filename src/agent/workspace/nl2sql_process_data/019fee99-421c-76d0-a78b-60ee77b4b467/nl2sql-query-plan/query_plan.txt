查询计划：找出评分 >= 8.5 但投票数 < 5000 的电影，按评分降序排列

1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的行（只查电影，排除短片/剧集/游戏等）
2. 进一步筛选 average_rating >= 8.5（评分不低于 8.5）
3. 进一步筛选 num_votes < 5000（投票数少于 5000）
4. 选择输出列：primary_title（电影标题）、average_rating（评分）、num_votes（投票数）
5. 按 average_rating DESC 降序排序（评分从高到低）
6. 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT 子句）

说明：
- 单表查询，无需 JOIN
- 评分和投票数已合并到 titles 表（average_rating, num_votes 字段）
- 该查询对应业务概念"宝藏片"（被忽视的好片）
