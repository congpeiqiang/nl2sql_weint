查询计划：1990年代（1990-1999）电影的平均评分

1. 从 titles 表查询数据
2. 筛选条件：
   - title_type = 'movie'（只查询电影类型）
   - start_year BETWEEN 1990 AND 1999（限定1990年代）
   - start_year IS NOT NULL（排除年份为NULL的记录）
   - average_rating IS NOT NULL（排除无评分的电影）
3. 对筛选后的结果计算 AVG(average_rating) 作为平均评分
4. 返回单行结果：平均评分

无需 JOIN，无需 GROUP BY，无需 ORDER BY，无需 LIMIT（聚合查询返回单行）
