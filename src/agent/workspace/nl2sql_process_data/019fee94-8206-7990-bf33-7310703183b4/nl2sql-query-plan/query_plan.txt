查询计划：找出同时是演员和导演的人，分别计算他们作为演员和作为导演的作品平均评分，要求两种角色参演作品数均 >= 3

1. 构建 actor_works CTE：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id IN ('actor', 'actress')（演员定义，包含男女演员）
   - 筛选 t.title_type = 'movie'（只统计电影作品）
   - 筛选 t.average_rating IS NOT NULL（排除无评分作品）
   - 按 p.name_id 分组
   - 计算 AVG(t.average_rating) AS actor_avg_rating 和 COUNT(*) AS actor_movie_count
   - HAVING COUNT(*) >= 3（演员作品数 >= 3）

2. 构建 director_works CTE：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id = 'director'（导演定义）
   - 筛选 t.title_type = 'movie'（只统计电影作品）
   - 筛选 t.average_rating IS NOT NULL（排除无评分作品）
   - 按 p.name_id 分组
   - 计算 AVG(t.average_rating) AS director_avg_rating 和 COUNT(*) AS director_movie_count
   - HAVING COUNT(*) >= 3（导演作品数 >= 3）

3. 合并两个 CTE：
   - JOIN actor_works a 和 director_works d ON a.name_id = d.name_id（找出同时满足两种角色条件的人）
   - JOIN names n ON a.name_id = n.id（获取人名）

4. SELECT 输出：
   - n.primary_name（人名）
   - a.actor_movie_count（演员作品数）
   - ROUND(a.actor_avg_rating, 2) AS actor_avg_rating（演员作品平均评分）
   - d.director_movie_count（导演作品数）
   - ROUND(d.director_avg_rating, 2) AS director_avg_rating（导演作品平均评分）

5. 通过 run_sql 的 limit 参数控制返回行数（SQL 中不写 LIMIT）
