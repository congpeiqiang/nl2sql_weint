查询计划：统计 Comedy 类型的电影数量

1. 从 titles 表（别名 t）出发，筛选 title_type = 'movie' 的作品（电影）
2. 通过 titles_genres 表（别名 tg）关联：t.id = tg.title_id（作品-类型多对多关联）
3. 通过 genres 表（别名 g）关联：tg.genre_id = g.id
4. 在 genres 表上筛选 g.id = 'comedy'（Comedy 类型，字符串比较）
5. 对满足条件的电影去重计数：COUNT(DISTINCT t.id) AS comedy_movie_count
6. 返回单行单列结果（电影数量）
