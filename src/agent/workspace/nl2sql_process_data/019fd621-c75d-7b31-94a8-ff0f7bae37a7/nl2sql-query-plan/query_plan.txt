查询目标：找出每个电影类型中评分最高的电影，显示类型名、电影标题和评分。

1. 从 titles t 筛选 title_type='movie' 且 average_rating IS NOT NULL 且 num_votes > 10000 的电影（保证评分可信度）
2. 通过 titles_genres tg (tg.title_id = t.id) 关联作品与类型
3. 通过 genres g (g.id = tg.genre_id) 关联类型，获取类型显示名 g.display_name
4. 使用窗口函数 ROW_NUMBER() OVER (PARTITION BY g.id ORDER BY t.average_rating DESC) 为每个类型内的电影按评分降序编号
5. 外层查询筛选 rn = 1，即每个类型中评分最高的电影
6. 输出 g.display_name AS genre, t.primary_title AS movie_title, t.average_rating AS rating
7. 按 g.display_name 排序
8. 通过 run_sql 的 limit 参数控制返回行数（不写 LIMIT 子句）
