查询计划：评分最高的 10 部电视剧系列

1. 从 titles 表筛选 title_type = 'tvSeries' 的行（电视剧系列）
2. 应用评分可信度过滤：num_votes > 10000（保证评分可信度）
3. 排除评分为 NULL 的行：average_rating IS NOT NULL
4. 选择字段：primary_title（标题）、average_rating（评分）
5. 按 average_rating DESC 降序排序（评分从高到低）
6. 取前 10 行（LIMIT 10）

说明：
- 单表查询，无需 JOIN
- 数据源：mysql
- 使用 run_sql 的 limit 参数控制返回 10 行，SQL 中不写 LIMIT 子句
