查询计划：统计数据库中每个表的记录条数

目标：返回数据库中所有17个表的表名和对应记录条数。

步骤：
1. 对每个表单独执行 COUNT(*) 统计记录条数
   - categories: SELECT COUNT(*) FROM categories
   - episodes: SELECT COUNT(*) FROM episodes
   - genres: SELECT COUNT(*) FROM genres
   - jobs: SELECT COUNT(*) FROM jobs
   - names: SELECT COUNT(*) FROM names
   - names_knownfortitles: SELECT COUNT(*) FROM names_knownfortitles
   - names_primaryprofessions: SELECT COUNT(*) FROM names_primaryprofessions
   - principals: SELECT COUNT(*) FROM principals
   - principals_characters: SELECT COUNT(*) FROM principals_characters
   - professions: SELECT COUNT(*) FROM professions
   - titleakaattributes: SELECT COUNT(*) FROM titleakaattributes
   - titleakas: SELECT COUNT(*) FROM titleakas
   - titleakas_titleakaattributes: SELECT COUNT(*) FROM titleakas_titleakaattributes
   - titleakas_titleakatypes: SELECT COUNT(*) FROM titleakas_titleakatypes
   - titleakatypes: SELECT COUNT(*) FROM titleakatypes
   - titles: SELECT COUNT(*) FROM titles
   - titles_genres: SELECT COUNT(*) FROM titles_genres

2. 使用 UNION ALL 将每个表的计数结果合并为一个结果集
   - 每行包含：表名（字符串字面量）+ 记录条数（COUNT(*)）

3. 输出格式：两列（table_name, row_count）
