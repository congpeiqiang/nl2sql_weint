# 查询计划：参演最多不同类型电影的演员 Top 10

## 目标
对每位演员统计其参演过的电影（title_type='movie'）中出现的**去重类型数**（COUNT(DISTINCT genre_id)），按类型数降序取前 10，显示演员名与类型数。

## 步骤

1. **起点表**：`principals p`（核心参与者表，约5000万行）
   - 先应用过滤条件缩小范围：
     - `p.category_id IN ('actor','actress')`（演员定义，须包含男女演员）
   - 这样只保留演员参与记录

2. **连接作品表**：`titles t` ON `p.title_id = t.id`
   - 应用作品过滤：`t.title_type = 'movie'`（只统计电影，排除短片/剧集/游戏等）
   - 排名类查询按业务规则加 `t.num_votes > 10000`（评分可信度过滤）
   - 先筛选 movie 再向下连接，减少中间结果

3. **连接类型关联表**：`titles_genres tg` ON `t.id = tg.title_id`
   - 得到每部电影对应的类型标签（genre_id 为字符串如 action/comedy）

4. **连接人物表**：`names n` ON `p.name_id = n.id`
   - 用于取演员显示名 `n.primary_name`

5. **分组聚合**：
   - `GROUP BY n.id, n.primary_name`
   - 度量：`COUNT(DISTINCT tg.genre_id) AS genre_count`
   - 说明：genre_id 本身是字符串标识，无需再 JOIN genres 表取名字；去重计数直接基于 titles_genres.genre_id

6. **排序**：`ORDER BY genre_count DESC, n.primary_name ASC`（类型数降序，同值时按名字排序保证稳定）

7. **取 Top 10**：不写 LIMIT 子句，通过 run_sql 的 limit 参数传 10

## 关键约束
- 演员 = category_id IN ('actor','actress')（业务规则二）
- 电影 = title_type='movie'（业务规则九/陷阱3.1）
- 类型数 = COUNT(DISTINCT genre_id)（指标定义：类型多样性）
- 多表 JOIN 必须使用别名（陷阱4.1）
- 不使用 SELECT *（陷阱5.2）
- 不写 LIMIT（任务规范：run_sql limit 参数控制）
