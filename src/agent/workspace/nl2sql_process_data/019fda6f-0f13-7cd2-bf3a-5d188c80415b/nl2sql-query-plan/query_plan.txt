查询计划：2000年到2023年每年电视剧的平均评分，按年份排列

1. 从 titles 表（别名 t）筛选 title_type = 'tvSeries'（电视剧系列）的行
2. 进一步筛选 start_year 在 2000 到 2023 之间（BETWEEN 2000 AND 2023）
3. 排除 start_year 为 NULL 的行（WHERE t.start_year IS NOT NULL）
4. 排除 average_rating 为 NULL 的行（WHERE t.average_rating IS NOT NULL）
5. 按 start_year 分组（GROUP BY t.start_year）
6. 对每组计算平均评分 AVG(t.average_rating)，保留两位小数 ROUND(..., 2)
7. 输出列：t.start_year AS year, ROUND(AVG(t.average_rating), 2) AS avg_rating
8. 按 start_year 升序排列（ORDER BY t.start_year ASC）
9. 无 JOIN 需求（单表查询）
