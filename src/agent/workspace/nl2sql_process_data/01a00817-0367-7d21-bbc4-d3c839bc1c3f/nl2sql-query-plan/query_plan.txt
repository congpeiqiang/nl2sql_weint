查询目标：Chinook_Aliyun（PostgreSQL / chinook 库）中共有多少张表，并列出所有表名。

程序化查询计划：
1. 从 information_schema.tables 中读取表元数据（该视图覆盖当前数据库的全部表）
2. 过滤条件：table_schema NOT IN ('pg_catalog', 'information_schema')，排除 PostgreSQL 系统 schema，仅保留业务表
3. SELECT 列表：table_name（表名）；如需数量可用 COUNT(*) 或由返回行数统计
4. 可选 ORDER BY table_name ASC 使结果有序、便于阅读
5. 不在 SQL 中写 LIMIT（由 run_sql 的 limit 参数控制，避免与工具自动追加的 cap 冲突）
6. 执行通道：dbmcp_run_sql(db_name='Chinook_Aliyun')（直连通道，该库未在语义层建模）

预期结果：11 张业务表（album, artist, customer, employee, genre, invoice, invoiceline, mediatype, playlist, playlisttrack, track），均在 public schema
