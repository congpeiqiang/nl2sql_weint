查询计划：找出同时是演员和导演的人，分别计算其作为演员和导演的作品平均评分，两种角色作品数均 >= 3

1. 构建"演员作品"子集：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id IN ('actor', 'actress') 且 t.title_type = 'movie' 且 t.average_rating IS NOT NULL
   - 按 p.name_id 分组
   - 计算 actor_movie_count = COUNT(*)，actor_avg_rating = AVG(t.average_rating)
   - 保留 HAVING COUNT(*) >= 3 的人

2. 构建"导演作品"子集：
   - 从 principals p JOIN titles t ON p.title_id = t.id
   - 筛选 p.category_id = 'director' 且 t.title_type = 'movie' 且 t.average_rating IS NOT NULL
   - 按 p.name_id 分组
   - 计算 director_movie_count = COUNT(*)，director_avg_rating = AVG(t.average_rating)
   - 保留 HAVING COUNT(*) >= 3 的人

3. 内连接两个子集（actor_works JOIN director_works ON name_id）：
   - 只保留同时满足演员作品数>=3 且 导演作品数>=3 的人

4. 通过 names n ON name_id = n.id 获取人物姓名 primary_name

5. 输出列：n.primary_name, actor_movie_count, actor_avg_rating, director_movie_count, director_avg_rating

6. 可选：按导演平均评分降序排序
