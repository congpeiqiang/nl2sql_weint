查询电视剧系列评分衰退最严重的 Top 10 查询计划

1. CTE season_ratings: 从 titles s (series) JOIN episodes e ON s.id = e.parent_id JOIN titles ep ON e.id = ep.id
   - 筛选 s.title_type = 'tvSeries' 且 ep.average_rating IS NOT NULL 且 e.season_number IS NOT NULL
   - 按 s.id, s.primary_title, e.season_number 分组
   - 计算每季平均评分 season_avg_rating = ROUND(AVG(ep.average_rating), 2)

2. CTE series_stats: 从 season_ratings 按 series_id, series_title 分组
   - 计算 total_seasons = COUNT(*)
   - 计算首季评分 first_season_rating（season_number 最小时的 season_avg_rating）
   - 计算末季评分 last_season_rating（season_number 最大时的 season_avg_rating）
   - HAVING COUNT(*) >= 3（至少3季才有意义）

3. 主查询: 从 series_stats 选择 series_title, total_seasons, first_season_rating, last_season_rating
   - 计算 decline_rate_pct = ROUND((first_season_rating - last_season_rating) / first_season_rating * 100, 2)
   - 按 decline_rate_pct DESC 排序
   - 取前 10 行（通过 run_sql limit 参数控制）

4. 业务规则应用:
   - 仅统计 tvSeries 类型
   - 至少3季
   - 评分衰退率 = (首季评分 - 末季评分) / 首季评分
