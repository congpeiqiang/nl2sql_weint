查询计划：1990年代电影平均评分

1. 从 titles 表（别名 t）中筛选数据
2. 过滤条件：title_type = 'movie'（只查电影）
3. 过滤条件：start_year BETWEEN 1990 AND 1999（限定1990年代）
4. 过滤条件：start_year IS NOT NULL（排除年份为NULL的记录）
5. 过滤条件：average_rating IS NOT NULL（排除无评分的记录）
6. 对筛选后的记录计算 AVG(average_rating) 得到平均评分
7. 返回单行结果：1990年代所有电影的平均评分

说明：
- 单表查询，不需要 JOIN
- 不需要 GROUP BY（整体聚合）
- 不需要 ORDER BY（单行结果）
- 不需要 LIMIT（单行结果）
- 数据源方言：MySQL
