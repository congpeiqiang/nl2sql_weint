查询计划：1990年代电影的平均评分

目标：计算1990年代（1990-1999）电影的平均评分

步骤：
1. 从 titles 表（别名 t）中筛选 title_type = 'movie' 的电影记录
2. 进一步筛选 start_year BETWEEN 1990 AND 1999，限定为1990年代
3. 排除 start_year 为 NULL 的记录（数据质量处理）
4. 排除 average_rating 为 NULL 的记录（确保评分有效）
5. 对筛选后的记录计算 AVG(t.average_rating) 作为平均评分
6. 返回单行结果：平均评分值

说明：
- 仅涉及 titles 单表，无需 JOIN
- 无 GROUP BY（整体平均）
- 无 ORDER BY / LIMIT（单行聚合结果）
