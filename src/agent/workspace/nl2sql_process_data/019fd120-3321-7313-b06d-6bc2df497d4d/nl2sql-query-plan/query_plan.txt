查询计划：每一年电视剧的平均评分趋势（2000-2023）

1. 从 titles 表（别名 t）中筛选电视剧系列：t.title_type = 'tvSeries'
2. 进一步筛选年份范围：t.start_year BETWEEN 2000 AND 2023
3. 排除无评分记录：t.average_rating IS NOT NULL
4. 按年份分组：GROUP BY t.start_year
5. 计算每组的平均评分：AVG(t.average_rating) AS avg_rating
6. 按年份升序排序：ORDER BY t.start_year ASC
7. 返回列：t.start_year AS year, ROUND(AVG(t.average_rating), 2) AS avg_rating

说明：
- 单表查询，无需 JOIN
- 使用 ROUND 保留2位小数，便于展示评分趋势
- 通过 run_sql 的 limit 参数控制返回行数（24年数据，limit=30 足够）
