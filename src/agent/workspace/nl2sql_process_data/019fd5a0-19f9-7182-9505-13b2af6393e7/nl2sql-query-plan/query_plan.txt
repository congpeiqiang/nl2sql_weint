查询计划：找出合作 3 次以上的导演-演员组合，且他们合作电影的平均评分 >= 7.5

1. 从 titles 表筛选电影作品：
   - 条件：t.title_type = 'movie'（只查电影）
   - 条件：t.num_votes > 10000（评分可信度过滤）
   - 条件：t.average_rating IS NOT NULL（排除无评分电影）

2. 自关联 principals 表，识别导演和演员：
   - 导演参与者 pd：pd.category_id = 'director'，通过 pd.title_id = t.id 关联到电影
   - 演员参与者 pa：pa.category_id IN ('actor', 'actress')，通过 pa.title_id = t.id 关联到同一部电影

3. 连接人物表获取姓名：
   - names d：通过 pd.name_id = d.id 关联导演姓名
   - names a：通过 pa.name_id = a.id 关联演员姓名

4. 按导演-演员组合分组：
   - GROUP BY d.id, d.primary_name, a.id, a.primary_name

5. 聚合计算：
   - 合作次数：COUNT(*)（该导演-演员组合共同参与的电影数）
   - 平均评分：AVG(t.average_rating)（合作电影的平均评分）

6. 分组后筛选：
   - HAVING COUNT(*) >= 3（合作3次以上）
   - HAVING AVG(t.average_rating) >= 7.5（平均评分>=7.5）

7. 排序：
   - ORDER BY collaboration_count DESC, avg_rating DESC（按合作次数降序，再按平均评分降序）

8. 结果列：
   - director_name（导演名）
   - actor_name（演员名）
   - collaboration_count（合作次数）
   - avg_rating（平均评分，保留2位小数）

9. 行数限制：通过 run_sql 的 limit 参数控制，SQL 中不写 LIMIT 子句
