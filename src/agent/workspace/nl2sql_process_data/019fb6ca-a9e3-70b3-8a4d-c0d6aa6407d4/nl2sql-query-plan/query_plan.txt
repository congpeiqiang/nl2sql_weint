查询计划：职业生涯跨度最长的前10位演员

1. 从 names 表（别名 n）开始，获取演员的 primary_name 和 id
2. 通过 principals 表（别名 p）连接：p.name_id = n.id，筛选出演员（p.category_id IN ('actor', 'actress')）
3. 通过 titles 表（别名 t）连接：t.id = p.title_id，获取作品年份
4. 筛选条件：t.start_year IS NOT NULL（排除无年份的作品）
5. 按演员分组：GROUP BY n.id, n.primary_name
6. 计算每个演员的职业生涯跨度：MAX(t.start_year) - MIN(t.start_year) AS career_span
7. 按职业生涯跨度降序排序：ORDER BY career_span DESC
8. 取前10行（通过 run_sql 的 limit 参数控制，不在 SQL 中写 LIMIT）
