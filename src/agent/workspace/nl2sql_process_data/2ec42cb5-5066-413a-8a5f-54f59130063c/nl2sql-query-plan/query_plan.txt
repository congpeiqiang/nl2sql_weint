查询计划：每个类型中评分最高的电影

1. 从 titles 表筛选 title_type='movie' 且 average_rating IS NOT NULL 且 num_votes > 10000 的电影
   - 使用别名 t
   - 过滤条件：t.title_type = 'movie', t.average_rating IS NOT NULL, t.num_votes > 10000

2. 通过 titles_genres 关联表连接 titles 和 genres
   - JOIN titles_genres tg ON tg.title_id = t.id
   - JOIN genres g ON g.id = tg.genre_id

3. 使用窗口函数 ROW_NUMBER() 按类型分组，按评分降序排列
   - ROW_NUMBER() OVER (PARTITION BY tg.genre_id ORDER BY t.average_rating DESC) AS rn

4. 筛选每个类型中评分最高的电影（rn = 1）

5. 选择输出字段：
   - g.display_name AS genre_name (类型名)
   - t.primary_title AS movie_title (电影标题)
   - t.average_rating AS rating (评分)

6. 按类型名排序输出
   - ORDER BY g.display_name ASC
