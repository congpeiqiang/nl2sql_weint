查询计划：查询1990年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）中筛选数据
2. 过滤条件：t.title_type = 'movie'（只查电影类型）
3. 过滤条件：t.start_year >= 1990 AND t.start_year <= 1999（限定1990年代）
4. 过滤条件：t.start_year IS NOT NULL（排除年份为NULL的记录，业务规则要求）
5. 过滤条件：t.average_rating IS NOT NULL（排除评分为NULL的记录，确保AVG计算准确）
6. 对满足条件的记录计算 AVG(t.average_rating)，得到1990年代电影的平均评分
7. 返回单行结果：平均评分值

说明：
- 单表查询，无需 JOIN
- 无 GROUP BY，整体聚合
- 无 ORDER BY 和 LIMIT（聚合查询返回单行）
- 数据源方言：MySQL
