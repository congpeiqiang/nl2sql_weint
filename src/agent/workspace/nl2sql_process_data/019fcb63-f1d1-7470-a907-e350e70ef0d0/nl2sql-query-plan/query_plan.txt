查询计划：查询1990年代（1990-1999）电影的平均评分

1. 从 titles 表中筛选 title_type = 'movie' 的记录（只查电影）
2. 进一步筛选 start_year BETWEEN 1990 AND 1999（限定1990年代）
3. 排除 average_rating IS NULL 的记录（确保评分数据有效）
4. 对筛选后的记录计算 AVG(average_rating)，得到1990年代电影的整体平均评分
5. 返回结果（单行单列的聚合值）

注意事项：
- 无需 JOIN，单表查询
- 无需 GROUP BY，整体聚合
- 无需 ORDER BY 或 LIMIT
- start_year 可能为 NULL，但 BETWEEN 条件已隐式排除 NULL 值
