查询计划：查询1990年代（1990-1999）电影的平均评分

1. 从 titles 表（别名 t）开始查询
2. 筛选条件：title_type = 'movie'（仅电影类型）
3. 筛选条件：start_year >= 1990 AND start_year <= 1999（1990年代）
4. 筛选条件：average_rating IS NOT NULL（排除无评分记录）
5. 计算 AVG(average_rating) 得到平均评分
6. 返回单行结果：平均评分值

说明：
- 本查询为单表聚合查询，无需 JOIN
- 无需 GROUP BY，因为只计算整体平均值
- 无需 ORDER BY 和 LIMIT，因为只返回一个聚合值
- 根据业务规则，电影类型必须过滤 title_type='movie'
- 根据 NULL 值处理规则，需排除 average_rating 为 NULL 的记录
