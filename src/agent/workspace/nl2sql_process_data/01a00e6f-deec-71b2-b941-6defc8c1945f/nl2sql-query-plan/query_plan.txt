# 查询计划：找出"宝藏片"（评分高但相对冷门的电影）

## 业务定义（来自知识库）
- 宝藏片 = 被忽视的好片：average_rating >= 8.5 且 num_votes < 5000
- 宝藏片指数 Hidden Gem Score = average_rating / LOG10(num_votes + 1)，衡量"高评分但低关注度"
- 只查电影：title_type = 'movie'
- 评分与投票数均已在 titles 表（反规范化），无需 JOIN

## 执行步骤
1. 从 titles 表筛选 title_type = 'movie' 的行（只保留电影，排除短片/剧集/游戏等）
2. 进一步筛选高评分：average_rating >= 8.5，并排除 NULL（average_rating IS NOT NULL）
3. 进一步筛选冷门/低关注：num_votes < 5000（按术语表"宝藏片"定义）
4. 排除无年份记录：start_year IS NOT NULL
5. 计算宝藏片指数：average_rating / LOG10(num_votes + 1) 作为辅助列 hidden_gem_score
6. 输出列：primary_title（标题）、start_year（年份）、average_rating（评分）、num_votes（投票数）、hidden_gem_score（宝藏片指数）
7. 排序：average_rating DESC（评分从高到低），同分时 num_votes ASC（更冷门优先）
8. 结果行数通过 run_sql 的 limit 参数控制（取前 30 条），SQL 内不写 LIMIT 子句
