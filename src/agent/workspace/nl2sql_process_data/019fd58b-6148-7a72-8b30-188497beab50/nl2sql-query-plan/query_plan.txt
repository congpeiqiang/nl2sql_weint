查询计划：电视剧系列评分衰退最严重的 Top 10

目标：找出电视剧系列（tvSeries）中，后续季相比第一季评分下降幅度最大的前10个系列。

步骤分解：

1. **CTE season_ratings（每季平均评分）**
   - 从 titles s（系列表）筛选 title_type = 'tvSeries'
   - JOIN episodes e ON s.id = e.parent_id（系列 → 剧集关联）
   - JOIN titles ep ON e.id = ep.id（剧集关联 → 剧集标题）
   - 过滤条件：ep.average_rating IS NOT NULL, e.season_number IS NOT NULL
   - GROUP BY s.id, s.primary_title, e.season_number
   - 计算每季平均评分：ROUND(AVG(ep.average_rating), 2) AS season_avg_rating
   - 计算每季集数：COUNT(DISTINCT e.id) AS episode_count

2. **CTE series_stats（系列统计）**
   - 从 season_ratings 按 series_id, series_title 分组
   - 计算总季数：COUNT(*) AS total_seasons
   - 找到最小季号（第一季）和最大季号（末季）
   - 提取第一季评分：MAX(CASE WHEN season_number = MIN(season_number) THEN season_avg_rating END)
   - 提取末季评分：MAX(CASE WHEN season_number = MAX(season_number) THEN season_avg_rating END)
   - HAVING COUNT(*) >= 3（至少3季）

3. **最终查询**
   - 从 series_stats 选择：series_title, total_seasons, first_season_rating, last_season_rating
   - 计算评分下降幅度：ROUND((first_season_rating - last_season_rating) / first_season_rating * 100, 2) AS decline_rate_pct
   - 按 decline_rate_pct DESC 排序
   - 取前10行（通过 run_sql 的 limit 参数控制）

关键JOIN路径：
- titles (series) ←→ episodes ←→ titles (episode)
- episodes.parent_id = titles.id (系列)
- episodes.id = titles.id (剧集)
