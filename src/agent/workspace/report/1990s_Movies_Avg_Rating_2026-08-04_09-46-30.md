# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:46:30
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映电影的平均评分情况。查询范围为 IMDb 数据库中 `title_type = 'movie'` 且 `start_year` 在 1990 至 1999 年之间的电影作品，排除无评分记录的作品。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 年代范围 | 1990 - 1999 |
| 电影类型 | movie（电影） |
| 平均评分 | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **查询逻辑**：
  1. **过滤电影类型**：`title_type = 'movie'`，排除短片、电视剧、游戏等其他作品类型。
  2. **年代范围**：`start_year BETWEEN 1990 AND 1999`，限定为 1990 年代。
  3. **NULL 处理**：`average_rating IS NOT NULL`，排除无评分记录的作品。
  4. **聚合计算**：`AVG(average_rating)` 计算平均评分。
- **执行策略**：策略B（快速通道）— 单表简单聚合查询，使用 `titles` 表。
