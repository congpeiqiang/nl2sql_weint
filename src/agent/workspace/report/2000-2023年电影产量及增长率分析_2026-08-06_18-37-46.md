## 1. 概述

## 3. 生成 SQL

```sql
SELECT
  start_year AS year,
  COUNT(*) AS movie_count,
  ROUND(
    (COUNT(*) - LAG(COUNT(*)) OVER (ORDER BY start_year)) * 100.0
    / NULLIF(LAG(COUNT(*)) OVER (ORDER BY start_year), 0),
    2
  ) AS growth_rate
FROM titles
WHERE title_type = 'movie'
  AND start_year IS NOT NULL
  AND start_year BETWEEN 2000 AND 2023
GROUP BY start_year
ORDER BY start_year;
```

## 4. 分析解读

### 4.1 整体趋势
- **2000-2014 年持续增长**：电影产量从 2000 年的 1,453 部稳步增长至 2014 年的 15,766 部，15 年间增长超过 10 倍。
- **2007-2008 年爆发式增长**：2007 年增长率高达 +70.58%，2008 年继续 +50.49%，是 24 年间增长最迅猛的时期。
- **2015-2016 年明显回落**：2015 年产量下降 16.59%，2016 年进一步下降 35.40%，跌至 8,495 部。
- **2017 年后恢复增长**：2018 年大幅反弹（+53.63%），此后逐年攀升。
- **2020 年疫情影响**：产量小幅下降 10.48%，随后 2021-2023 年持续回升。
- **2023 年产量峰值**：达到 20,923 部，为 24 年间最高。

### 4.2 关键节点
| 节点 | 说明 |
|------|------|
| 2007-2008 | 爆发式增长期（+70.58%、+50.49%） |
| 2015-2016 | 显著回落期（-16.59%、-35.40%） |
| 2020 | 疫情冲击（-10.48%） |
| 2023 | 历史峰值（20,923 部） |

### 4.3 结论
- 电影产业整体呈**长期上升趋势**，24 年间产量增长约 14 倍。
- 增长并非线性，存在明显的**周期性波动**，与行业环境、经济周期和外部事件（如疫情）密切相关。
- 2023 年产量已创历史新高，且增长率趋于平稳（+0.96%），市场可能进入**成熟稳定期**。
