# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-05 16:49:22
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 IMDb 数据库中 **1990 年代（1990-1999）上映电影的平均评分**。该指标反映了 90 年代电影的整体质量水平，可用于与其他年代对比，洞察电影质量的历史演变趋势。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 1990 年代电影平均评分 | **6.15 分**（范围 1.0-10.0） |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

**关键业务规则：**
- **"电影"** 定义为 `title_type = 'movie'`（titles 表含 9 种作品类型，需过滤）
- **"1990 年代"** 对应 `start_year BETWEEN 1990 AND 1999`
- **NULL 处理**：排除 `average_rating IS NULL` 的记录，避免影响平均值

## 4. 分析解读

- **平均评分**：1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。
- **业务含义**：6.15 分意味着 90 年代电影整体质量稳定，多数作品获得观众中等偏上的认可。这一水平与 IMDb 全库电影的平均水平相当。
- **数据价值**：该指标可作为年代对比的基准。若与其他年代（如 2000 年代、2010 年代）的平均评分对比，可洞察电影质量随时间的演变趋势。
