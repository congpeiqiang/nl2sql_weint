# 数据库电视剧系列数量分析报告

> 生成时间：2026-08-05 12:02:01

## 1. 概述

本报告统计了 IMDb 数据库中**电视剧系列（TV Series）**的总数量。电视剧系列指多季多集的电视剧作品，与单个剧集（tvEpisode）相区分。

## 2. 核心数据

| 指标 | 数值 |
|------|:---:|
| 电视剧系列总数 | **232,074 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS tv_series_count FROM titles WHERE title_type = 'tvSeries'
```
