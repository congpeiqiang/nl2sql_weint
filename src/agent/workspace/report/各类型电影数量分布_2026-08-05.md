## 3. 生成 SQL

```sql
SELECT g.display_name AS genre, COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON t.id = tg.title_id
JOIN genres g ON tg.genre_id = g.id
WHERE t.title_type = 'movie'
GROUP BY g.display_name
ORDER BY movie_count DESC
```

## 4. 分析解读

### 4.1 头部梯队（数量 > 10 万）
- **Drama（剧情片）** 以 **154,043 部** 高居榜首，是数量最多的电影类型
- **Documentary（纪录片）** 紧随其后，达 **113,966 部**
- 两者合计约 26.8 万部，占全部类型电影数量的显著比例

### 4.2 中部梯队（1 万 ~ 7 万）
- **Comedy（喜剧）** 排名第三，有 **66,885 部**
- **Thriller（惊悚）**、**Action（动作）**、**Horror（恐怖）** 均在 3.5 万 ~ 3.9 万之间
- **Romance（爱情）**、**Crime（犯罪）** 超过 2 万部

### 4.3 尾部梯队（< 1 万）
- **Game-Show（游戏秀）** 数量最少，仅 **13 部**
- **Talk-Show（脱口秀）**、**Reality-TV（真人秀）** 也较少，分别为 200 和 552 部

### 4.4 关键洞察
- 剧情片和纪录片占据绝对主导地位，反映了 IMDb 收录内容的广泛性
- 传统主流类型（喜剧、惊悚、动作、恐怖）构成第二梯队
- 电视节目类类型（Game-Show、Talk-Show、Reality-TV）数量极少，因为本查询仅统计了电影（movie）
