## 3. 生成 SQL

```sql
SELECT g.display_name AS genre,
       COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON tg.title_id = t.id
JOIN genres g ON g.id = tg.genre_id
WHERE t.title_type = 'movie'
GROUP BY g.id, g.display_name
ORDER BY movie_count DESC
```

## 4. 分析解读

- **Drama（剧情片）** 是数量最多的电影类型，共 **154,043 部**，远超其他类型。
- **Documentary（纪录片）** 以 **113,966 部** 位居第二。
- **Comedy（喜剧）** 以 **66,885 部** 排名第三。
- 前三名类型（Drama、Documentary、Comedy）合计约 33.5 万部，占主导地位。
- 排名靠后的类型如 **Game-Show（13部）**、**Talk-Show（200部）** 数量极少，这些类型更多出现在电视节目中。
