# 电影数量最多的5个电影类型

> 生成时间：2026-08-08_12-02-01
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 IMDb 数据库中电影数量最多的 5 个电影类型。通过关联 `titles`、`titles_genres`、`genres` 三张表，筛选出 `title_type='movie'` 的电影，按类型分组统计数量并降序排列，取前 5 名。

## 2. 核心数据

| 排名 | 电影类型 | 电影数量 |
|:---:|:---:|:---:|
| 1 | Drama（剧情） | 154,043 |
| 2 | Documentary（纪录片） | 113,966 |
| 3 | Comedy（喜剧） | 66,885 |
| 4 | Thriller（惊悚） | 38,600 |
| 5 | Action（动作） | 36,731 |

## 3. 生成 SQL

```sql
SELECT g.display_name AS genre,
       COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON tg.title_id = t.id
JOIN genres g ON g.id = tg.genre_id
WHERE t.title_type = 'movie'
GROUP BY g.id, g.display_name
ORDER BY movie_count DESC
```

## 4. 分析解读

- **Drama（剧情片）** 以约 15.4 万部电影高居榜首，远超其他类型，是 IMDb 中数量最庞大的电影类型。
- **Documentary（纪录片）** 以约 11.4 万部位居第二，反映出纪录片在影视作品中的高产量。
- **Comedy（喜剧）** 以约 6.7 万部位列第三，是主流商业类型中数量最多的。
- **Thriller（惊悚）** 与 **Action（动作）** 数量接近（约 3.8 万 vs 3.7 万），分列第四、第五。
- 前 5 大类型合计约 41 万部电影，其中 Drama 与 Documentary 两个类型就占据了前五总量的一半以上，体现了剧情与纪实类作品在 IMDb 中的主导地位。
