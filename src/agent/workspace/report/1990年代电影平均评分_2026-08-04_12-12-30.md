# 1990 年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 12:12:30
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询并分析了 1990 年代（1990-1999 年）IMDb 数据库中所有电影的平均评分。该指标反映了这一时期电影的整体质量水平和观众评价趋势。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **数据范围** | 1990-1999 年 |
| **筛选条件** | `title_type = 'movie'`，排除 NULL 评分 |
| **平均评分** | **6.15**（满分 10 分） |

### 可视化图表

![1990年代电影平均评分仪表盘](./1990年代电影平均评分_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year >= 1990
  AND start_year <= 1999
  AND average_rating IS NOT NULL
```

## 4. 分析解读

- **评分水平**：1990 年代电影平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平，说明该时期电影整体质量尚可。
- **评分分布**：6.15 分意味着大部分电影的评分集中在 5-7 分区间，属于"及格但不突出"的范围。
- **数据可靠性**：查询使用 `AVG()` 函数并排除了 NULL 评分记录，确保结果仅基于有实际评分数据的电影。
- **历史背景**：1990 年代是电影工业快速发展期，大量商业片与独立电影并存，6.15 的平均分反映了作品质量的多样性。
