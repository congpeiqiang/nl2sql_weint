## 1. 概述

## 3. 生成 SQL

```sql
SELECT 
  t.start_year AS year,
  COUNT(*) AS movie_count,
  ROUND((COUNT(*) - LAG(COUNT(*)) OVER (ORDER BY t.start_year)) * 100.0 / LAG(COUNT(*)) OVER (ORDER BY t.start_year), 2) AS growth_rate
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 2000 AND 2023
  AND t.start_year IS NOT NULL
GROUP BY t.start_year
ORDER BY t.start_year ASC
```

## 4. 分析解读

### 整体趋势

1. **产量大幅增长**：从 2000 年的 1,453 部增长到 2023 年的 20,923 部，**增长约 14 倍**，反映了全球电影产业的快速扩张。

2. **增长高峰（2007-2008）**：2007 年增长率高达 **+70.58%**，2008 年达 **+50.49%**，是 24 年间增长最快的时期。这与全球电影制作技术普及、流媒体平台兴起前的制作热潮相关。

3. **负增长年份**：
   - **2015-2016 年**：连续两年负增长（-16.59%、-35.40%），2016 年产量跌至 8,495 部，是 2008 年以来的最低点。可能与行业调整、制作成本上升有关。
   - **2020 年**：受**新冠疫情**影响，产量下降 10.48%，全球电影制作被迫中断。

4. **疫情后强劲反弹**：2021 年产量增长 17.46%，2022 年增长 10.18%，2023 年达到历史峰值 20,923 部。
