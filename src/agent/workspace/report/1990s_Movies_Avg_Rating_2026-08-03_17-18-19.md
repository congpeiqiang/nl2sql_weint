# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 17:18:19
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映电影的平均评分情况。查询范围为 `titles` 表中 `title_type = 'movie'`（仅电影，排除电视剧、短片等其他类型）且 `start_year` 在 1990 至 1999 年之间的记录，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 查询范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15**（精确值 6.153） |

### 图表展示

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie' AND start_year BETWEEN 1990 AND 1999
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **策略选择**：本次查询采用策略 B（快速通道）——单表查询 + 简单筛选 + AVG 聚合，无需复杂多表关联。
- **筛选逻辑**：仅统计 `title_type = 'movie'` 的电影，排除了电视剧、短片、纪录片等其他类型，确保数据口径准确。
