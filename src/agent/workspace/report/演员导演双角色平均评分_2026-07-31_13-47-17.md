# 同时是演员和导演的人 — 作品平均评分分析报告

> 生成时间：2026-07-31_13-47-17
> 数据来源：imdb 数据库（principals、titles、names 表）

## 1. 概述

本报告分析 imdb 数据库中**同时担任演员和导演**的人物，分别计算他们作为演员和作为导演的作品平均评分，并筛选出**两种角色参演作品数均 ≥ 3** 的人。

**核心业务规则：**
- "演员"同时包含 `actor` 和 `actress`（IMDb 按性别区分）
- "导演"使用 `category_id = 'director'`
- 过滤 `average_rating IS NOT NULL`（避免 NULL 影响均值）
- 两种角色作品数均要求 ≥ 3

## 4. 生成 SQL

查询逻辑分三步：

1. **演员作品子集**：从 `principals` JOIN `titles`，筛选 `category_id IN ('actor','actress')` 且 `title_type='movie'` 且评分非空，按人分组，保留作品数 ≥ 3 的人
2. **导演作品子集**：同样逻辑，筛选 `category_id='director'`，保留作品数 ≥ 3 的人
3. **内连接**两个子集，找出同时满足两种角色作品数均 ≥ 3 的人，关联 `names` 表获取人物姓名

```sql
-- 演员子集
SELECT p.person_id, COUNT(*) AS actor_count, AVG(t.average_rating) AS actor_avg
FROM principals p
JOIN titles t ON p.title_id = t.title_id
WHERE p.category_id IN ('actor','actress')
  AND t.title_type = 'movie'
  AND t.average_rating IS NOT NULL
GROUP BY p.person_id
HAVING COUNT(*) >= 3;

-- 导演子集
SELECT p.person_id, COUNT(*) AS director_count, AVG(t.average_rating) AS director_avg
FROM principals p
JOIN titles t ON p.title_id = t.title_id
WHERE p.category_id = 'director'
  AND t.title_type = 'movie'
  AND t.average_rating IS NOT NULL
GROUP BY p.person_id
HAVING COUNT(*) >= 3;

-- 内连接两个子集并关联 names 表
SELECT n.primary_name, a.actor_count, a.actor_avg, d.director_count, d.director_avg
FROM actor_subset a
JOIN director_subset d ON a.person_id = d.person_id
JOIN names n ON a.person_id = n.person_id
ORDER BY d.director_avg DESC;
```
