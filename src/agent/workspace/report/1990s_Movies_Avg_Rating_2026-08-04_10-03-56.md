# 1990年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 10:03:56
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影在 IMDb 平台上的平均评分情况。统计范围限定为 `title_type = 'movie'` 的电影作品，排除短片、电视剧、游戏等其他类型，并剔除年份或评分缺失的记录。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15 分**（IMDb 评分范围 1.0-10.0） |

### 图表展示

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的整体平均评分处于 IMDb 评分体系的中等偏上水平（满分 10 分）。
- **查询逻辑**：
  - 仅统计 `title_type = 'movie'` 的电影作品，确保数据口径一致
  - 限定 `start_year` 在 1990-1999 之间，精确覆盖整个 1990 年代
  - 排除 `start_year` 和 `average_rating` 为 NULL 的记录，保证统计准确性
- **参考意义**：该数值可作为衡量 1990 年代电影整体质量的基准，也可用于与其他年代（如 1980 年代、2000 年代）的电影平均评分进行横向对比。
