# 投票数超过 100 万的电影数量报告

> 生成时间：2026-08-06 19:43:49
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 IMDb 数据库中**投票数（num_votes）超过 100 万**的电影数量。投票数是衡量电影受欢迎程度的重要指标，超过 100 万票意味着该电影具有极高的关注度和广泛的观众基础。

## 2. 核心数据

| 指标 | 值 |
|------|-----|
| 投票数超过 100 万的电影数量 | **22 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie' AND num_votes > 1000000
```

## 4. 分析解读

- **共有 22 部电影**的投票数超过 100 万。
- 筛选条件：
  - `title_type = 'movie'` — 仅统计电影类型（排除电视剧、短片等）
  - `num_votes > 1000000` — 投票数超过 100 万（100万 = 1,000,000）
- 这些电影代表了 IMDb 上最受关注、讨论度最高的作品。
