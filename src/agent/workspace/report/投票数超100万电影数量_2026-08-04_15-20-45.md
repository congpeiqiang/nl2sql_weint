# 投票数超过100万的电影数量分析

> 生成时间：2026-08-04 15:20:45
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询了 IMDb 数据库中投票数（num_votes）超过 100 万的电影数量，旨在了解最受观众关注和评价的顶级电影作品。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **投票数阈值** | > 1,000,000 |
| **作品类型** | 电影（movie） |
| **符合条件的电影数量** | **22 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie'
  AND num_votes > 1000000
```

**查询说明：**
- 筛选 `title_type = 'movie'` 确保只统计电影
- `num_votes > 1000000` 限定投票数超过 100 万
- 使用 `COUNT(*)` 统计符合条件的电影总数

## 4. 分析解读

- **22 部**电影获得了超过 100 万的投票，这些是 IMDb 历史上最受关注和最具影响力的作品
- 根据 IMDb 业务规则，投票数超过 20 万的影片已被归类为"极高可信度"和"现象级影片"
- 超过 100 万投票的电影代表了观众参与度的最高层级，通常包括：
  - 经典大片（如《肖申克的救赎》《教父》《黑暗骑士》等）
  - 全球现象级作品（如《阿凡达》《复仇者联盟》系列等）
  - 文化影响力极强的电影
- 这些电影的评分具有极高的统计可信度，因为样本量巨大
