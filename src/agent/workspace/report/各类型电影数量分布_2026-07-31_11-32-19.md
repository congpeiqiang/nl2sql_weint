# 各类型电影数量分布报告

> 生成时间：2026-07-31_11-32-19
> 数据来源：imdb 数据库

## 1. 概述

本报告统计了 imdb 数据库中**每种电影类型（Genre）的电影数量**，并按数量从多到少排列。数据基于 `titles`、`titles_genres`、`genres` 三表关联，仅统计 `title_type='movie'` 的电影。

共统计出 **26 种电影类型**，总计覆盖约 **60 万部电影**（含多类型归属）。

## 4. 生成SQL

```sql
SELECT g.display_name AS genre, COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON t.id = tg.title_id
JOIN genres g ON tg.genre_id = g.id
WHERE t.title_type = 'movie'
GROUP BY g.display_name
ORDER BY movie_count DESC
```

## 5. 分析解读

### 头部集中效应明显
- **Drama（剧情片）** 以 154,043 部高居榜首，占所有类型电影数量的约 **25%**，是第二名 Documentary 的 1.35 倍。
- **Documentary（纪录片）** 以 113,966 部位居第二，两者合计占比超过 **44%**。

### 长尾分布
- 排名前 10 的类型贡献了绝大部分电影数量，而 **Game-Show（游戏秀）** 仅 13 部，**Talk-Show（脱口秀）** 仅 200 部，属于极小众类型。
- 从 **Reality-TV（552 部）** 到 **Game-Show（13 部）** 的尾部类型，数量急剧下降。

### 类型多样性
- 26 种类型覆盖了从主流剧情片到小众游戏秀的广泛范围，反映了 imdb 数据库的丰富性和多样性。

## 6. 附录

### 数据说明
- 一部电影可能属于多个类型，因此各类型电影数量之和大于电影总数。
- 使用 `COUNT(DISTINCT t.id)` 确保每部电影在每种类型下只计数一次。
- 仅统计 `title_type='movie'` 的电影，不含电视剧、短片等其他类型。
