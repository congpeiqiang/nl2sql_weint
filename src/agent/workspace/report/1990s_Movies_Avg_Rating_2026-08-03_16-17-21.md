# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 16:17:21
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告分析 1990 年代（1990-1999）上映电影的平均评分情况。通过聚合 `titles` 表中 `title_type='movie'` 且 `start_year` 在 1990-1999 范围内的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15 分**（精确值 6.153262857446869） |
| 评分范围 | 0 - 10 分 |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的整体平均评分处于中等偏上水平（满分 10 分）。
- **查询逻辑**：仅统计 `title_type='movie'` 的电影，排除电视剧等其他类型；限定 `start_year` 在 1990-1999 之间；排除 `average_rating` 为 NULL 的记录，确保平均值计算准确。
- **单表聚合**：该查询仅涉及 `titles` 单表，无需 JOIN，执行效率高。
