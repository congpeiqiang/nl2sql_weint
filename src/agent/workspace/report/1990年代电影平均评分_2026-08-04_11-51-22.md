# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 11:51:22
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询了 IMDb 数据库中 1990 年代（1990-1999 年）上映电影的平均评分，旨在了解该时期电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **查询范围** | 1990-1999 年上映的电影 |
| **筛选条件** | `title_type = 'movie'`，`start_year BETWEEN 1990 AND 1999`，`average_rating IS NOT NULL` |
| **平均评分** | **6.15**（满分 10 分） |

### 评分仪表盘

![1990年代电影平均评分仪表盘](./1990年代电影平均评分_chart.svg)

> 仪表盘显示 6.15 分位于 0-10 分量表的中等偏上区间（蓝色区域），表明 1990 年代电影整体评分处于中上水平。

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year >= 1990
  AND t.start_year <= 1999
  AND t.average_rating IS NOT NULL
```

**SQL 说明：**
- `title_type = 'movie'`：仅统计电影类型，排除电视剧、短片等
- `start_year BETWEEN 1990 AND 1999`：精确匹配 1990 年代
- `average_rating IS NOT NULL`：排除无评分记录，确保统计准确性

## 4. 分析解读

- **评分水平**：6.15 分在 IMDb 10 分制中属于**中等偏上**水平，说明 1990 年代电影整体质量较好
- **评分区间定位**：在仪表盘上，6.15 分位于 6-7 分区间（蓝色中段），高于中位数 5 分
- **业务规则**：查询严格过滤了 `title_type = 'movie'`，确保结果仅反映电影作品，不含电视剧、纪录片等其他类型
- **数据完整性**：通过 `IS NOT NULL` 条件排除了未评分作品，避免拉低或拉高平均值
