## 1. 概述

## 3. 生成 SQL

```sql
SELECT start_year, AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'tvSeries'
  AND start_year BETWEEN 2000 AND 2023
GROUP BY start_year
ORDER BY start_year
```

## 4. 分析解读

- **整体趋势**：电视剧平均评分呈**上升趋势**。
  - 2000 年代初约 **6.4-6.6 分**
  - 2010 年代后稳定在 **6.8 分**左右
  - **2019 年达到峰值 6.86 分**
- **最低点**：2001 年（6.36 分）
- **最高点**：2019 年（6.86 分）
- **2021 年**出现小幅回落（6.72 分），但 2022-2023 年回升至 6.82-6.83 分。
