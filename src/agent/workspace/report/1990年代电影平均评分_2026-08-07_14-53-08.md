# 1990年代上映的电影平均评分分析报告

> 生成时间：2026-08-07_14-53-08
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 **1990 年代（1990-1999 年）** 上映的电影的平均评分。通过查询 IMDb 数据库中的 `titles` 表，筛选出 `title_type = 'movie'` 且上映年份在 1990 至 1999 年之间的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.153 分** |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **1990 年代上映的电影平均评分为 6.153 分**，处于 IMDb 评分体系（0-10 分）的中等偏上水平。
- 该平均值基于所有 1990 年代上映且具有评分的电影计算，未对投票数设置阈值，因此包含大量小众或低关注度影片，拉低了整体均值。
- 若仅关注高投票数（如投票数 ≥ 5000）的影片，平均评分通常会显著更高。
