## 3. 生成 SQL

```sql
SELECT primary_title, runtime_minutes
FROM titles
WHERE title_type = 'movie' AND runtime_minutes > 180
ORDER BY runtime_minutes DESC
```

## 4. 分析解读

### 4.1 片长分布特征

- **极端长片**：排名前 3 的电影（Logistics 51,420 分钟、Ambiancé 43,200 分钟、Carnets Filmés 28,643 分钟）片长远超常规电影，属于实验性/艺术装置类作品。
  - Logistics 片长约 **35.7 天**，是史上最长的电影之一
  - Ambiancé 片长约 **30 天**
- **超长纪录片**：Modern Times Forever（14,400 分钟 ≈ 10 天）、Beijing 2003（9,000 分钟 ≈ 6.25 天）等属于超长纪录片/实验影像。

### 4.2 数据特点

- 片长跨度极大：从 1,452 分钟到 51,420 分钟，相差约 **35 倍**
- 大部分超长电影属于**实验电影、纪录片或艺术装置**，而非传统商业电影
- 传统商业电影中，片长超过 180 分钟的多为史诗级作品（如《指环王》系列）
