# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 16:26:44

## 1. 概述

本报告分析 1990 年代（1990-1999）上映电影的平均评分情况。通过查询 IMDb 数据库中的 `titles` 表，筛选出 `title_type='movie'` 且 `start_year` 在 1990 至 1999 年之间的电影，计算其 `average_rating` 的平均值。

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **数据过滤**：查询严格限定为 `title_type='movie'`（电影），排除了电视剧、短片等其他类型；同时处理了 `start_year` 和 `average_rating` 的 NULL 值，确保统计准确性。
- **单表聚合**：该查询仅涉及 `titles` 单表，无需 JOIN，通过 AVG 聚合函数直接计算，性能高效。
