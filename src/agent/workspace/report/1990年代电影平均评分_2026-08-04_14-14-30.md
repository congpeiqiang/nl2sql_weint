# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 14:14:30
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映电影的平均评分，数据来源于 IMDb 数据库。查询范围限定为 `title_type = 'movie'` 的作品，排除了电视剧、短片等其他类型。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **作品类型** | 电影（movie） |
| **平均评分** | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

- **类型过滤**：仅统计 `title_type = 'movie'` 的作品，不包含电视剧、短片、纪录片等其他类型
- **年代特征**：1990 年代是电影产业的重要时期，诞生了大量经典作品，6.15 的平均分反映了该时期电影的整体质量水平
