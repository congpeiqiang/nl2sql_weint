# 电影类型为 movie 的电影总数统计报告

> 生成时间：2026-08-08 08:45:12
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计 IMDb 数据库中电影类型（`title_type`）为 **movie** 的电影总数。该指标反映了数据库中电影类作品的整体规模，是理解数据分布的基础性统计。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 电影类型（title_type） | movie |
| 电影总数 | **469,181** 部 |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie'
```

- **电影总数**：数据库中 `title_type = 'movie'` 的电影共有 **469,181** 部，这是一个相当庞大的规模。

- **数据表**：查询基于 `titles` 表，通过 `title_type` 字段过滤出电影类型为 movie 的记录。
- **执行效率**：SQL 已通过 `dry_run` 验证后执行，查询耗时约 1 秒，效率较高。
