# Comedy 类型电影数量报告

> 生成时间：2026-08-06 19:46:16
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 IMDb 数据库中 **Comedy（喜剧）类型**的电影数量。Comedy 是电影中最受欢迎的类型之一，以幽默、轻松的情节为特点。

## 2. 核心数据

| 指标 | 值 |
|------|-----|
| Comedy 类型电影数量 | **66,885 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON tg.title_id = t.id
JOIN genres g ON tg.genre_id = g.id
WHERE t.title_type = 'movie' AND g.id = 'comedy'
```

## 4. 分析解读

- **Comedy 类型共有 66,885 部电影**，数量相当可观。
- 该查询使用了**策略A（标准流水线）**，涉及三张表的关联：
  - `titles` — 电影主表
  - `titles_genres` — 电影与类型的关联表（多对多）
  - `genres` — 类型表
- 使用 `COUNT(DISTINCT t.id)` 确保去重计数，避免因多类型关联导致的重复统计。
- 筛选条件：`title_type = 'movie'`（仅电影）+ `g.id = 'comedy'`（Comedy 类型）。
