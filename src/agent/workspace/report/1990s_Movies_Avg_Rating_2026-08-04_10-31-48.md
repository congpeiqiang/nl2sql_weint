# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 10:31:48
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映电影的平均评分情况。通过 IMDb 数据库中的电影数据，计算该年代所有电影的平均评分，以评估这一时期的电影整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|-----|
| 年代范围 | 1990 - 1999 |
| 平均评分 (avg_rating) | **7.02** 分 |
| 评分满分 | 10 分 |

**结论：** 1990 年代电影的平均评分为 **7.02 分**（满分 10 分），处于中等偏上水平。

## 3. 生成 SQL

本查询通过 **策略C（Cube 通道）** 执行，利用预定义的 `movie_analytics` 数据立方体：

```sql
-- 通过 Cube 查询（query_cube）
-- 度量：avg_rating = AVG(average_rating)
-- 维度：decade = FLOOR(start_year / 10) * 10
-- 过滤：decade = 1990

SELECT avg_rating
FROM movie_analytics
WHERE decade = 1990
```
