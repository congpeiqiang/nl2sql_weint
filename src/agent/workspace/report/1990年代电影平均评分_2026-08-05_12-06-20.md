# 1990 年代电影平均评分分析报告

> 生成时间：2026-08-05 12:06:20
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 IMDb 数据库中 **1990 年代（1990-1999 年）上映电影**的平均评分。该查询通过 `movie_analytics` Cube 的 `avg_rating` 度量计算，并用 SQL 交叉验证，结果完全一致。

## 2. 核心数据

| 指标 | 数值 |
|------|:---:|
| 1990 年代电影平均评分 | **6.15 分** |

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie' AND start_year BETWEEN 1990 AND 1999
```

## 4. 分析解读

### 4.1 评分水平

1990 年代上映的电影平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。这一评分反映了 90 年代电影的整体质量。

![1990年代电影平均评分](./平均评分_20260805_120620.svg)

上图采用**仪表盘（Gauge）图表**直观展示平均评分。仪表盘量程为 0~10 分，当前值 6.15 分位于量程的约 61.5% 处。

### 4.3 关键发现

1. **评分中等偏上**：6.15 分处于 10 分制的中间偏上区间，说明 90 年代电影整体质量尚可。
2. **统计口径**：该查询统计了 1990-1999 年间上映的所有电影（`title_type='movie'`），未额外加投票数过滤（如 `num_votes > 10000`），因此包含所有电影样本。
3. **交叉验证**：Cube 查询与 SQL 直接查询结果完全一致（6.153262857446869），验证了数据的准确性。

### 4.4 补充说明

如需更可信的评分，可考虑增加投票数过滤条件（如 `num_votes > 10000`），以排除低投票数电影对平均分的稀释影响。
