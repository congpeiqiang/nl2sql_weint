## 3. 生成 SQL

```sql
SELECT primary_title, average_rating, num_votes
FROM titles
WHERE title_type = 'movie'
  AND average_rating >= 8.5
  AND num_votes < 5000
ORDER BY average_rating DESC
```

## 4. 分析解读

### 关键发现

1. **高评分低投票现象显著**：存在大量评分 ≥ 8.5 但投票数极低的电影，其中多部电影评分高达 10.0 但投票数不足 10 票。

2. **投票数极低**：大部分高评分电影的投票数在 5-100 票之间，属于极小众作品。

3. **评分可信度问题**：根据 IMDb 业务规则，低投票数（<1000）的评分可信度较低，评分偏差可能较大。这些 10.0 满分的电影可能仅由极少数观众评分，不代表广泛共识。

4. **"宝藏片"特征**：这类电影通常是小众独立制作、纪录片或地区性作品，缺乏主流曝光度。

### 图表解读

- **散点图**：展示了评分与投票数的关系。可以看出，评分越高的电影投票数往往越低，呈现明显的负相关趋势。
- **柱状图**：展示了评分分布，10.0 满分的电影数量最多（7部），随后评分递减，数量也递减。
