# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 17:14:37
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映电影的平均评分情况。通过聚合 IMDb 数据库中 `titles` 表的 `average_rating` 字段，计算该年代所有电影的平均评分，以评估这一时期的整体电影质量水平。

| **电影类型** | movie（电影） |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **整体水平**：1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。
- **评分含义**：6.15 分表明该年代电影整体质量尚可，但并非特别突出。这一数值受大量低评分电影拉低影响，因为 IMDb 数据库中包含大量小众、低成本或质量一般的电影。
- **对比参考**：IMDb 评分体系中，7 分以上通常被认为是"优秀"电影，6 分左右属于"尚可"水平。1990 年代平均 6.15 分说明该年代既有大量经典佳作（如《肖申克的救赎》《辛德勒的名单》等），也有大量普通作品拉低均值。
- **数据说明**：查询仅统计 `title_type='movie'` 的电影，排除了电视剧、短片等其他类型；同时排除了 `start_year` 和 `average_rating` 为 NULL 的记录，确保统计准确性。
