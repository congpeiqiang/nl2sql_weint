# 2020 年之后（含 2020）电影总数统计

> 生成时间：2026-08-14 14:59:19
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本次查询统计了 IMDb 数据库中 2020 年及之后（含 2020 年）的电影总数，筛选条件为 `title_type = 'movie'` 且 `start_year >= 2020`。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 2020 年及之后电影总数 | **130,469** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie'
  AND start_year >= 2020
```

## 4. 分析解读

- IMDb 数据库中 2020 年及之后共收录了 **130,469** 部电影
- 该数据涵盖了 2020 年至 2026 年期间的电影作品
- 需要注意的是，IMDb 数据库中的"电影"（movie）类型包含了院线电影、独立电影、短片等多种形式的作品，实际院线上映的电影数量可能少于该统计值
- 2020 年受全球疫情影响，电影产量有所下降，但随后几年逐步恢复
