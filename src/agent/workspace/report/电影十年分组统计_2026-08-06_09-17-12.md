# 按十年分组统计电影平均评分与数量

> 生成时间：2026-08-06 09:17:12
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告基于 IMDb 数据库，按十年（decade）分组统计电影（`title_type = 'movie'`）的平均评分和数量。年代计算采用业务规则 `FLOOR(start_year / 10) * 10`（如 1994 → 1990），并过滤 `start_year IS NOT NULL` 的记录。

## 3. 生成 SQL

```sql
SELECT FLOOR(start_year / 10) * 10 AS decade,
       AVG(average_rating) AS avg_rating,
       COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie' AND start_year IS NOT NULL
GROUP BY FLOOR(start_year / 10) * 10
ORDER BY decade
```

## 4. 分析解读

### 4.1 电影数量趋势

- **早期阶段（1890-1940）**：电影数量较少，从 1890 年代的 1 部逐步增长到 1920 年代的 6,062 部，1940 年代因战争影响回落至 1,392 部。
- **稳步增长期（1950-1990）**：电影数量在 5,000~11,000 部之间波动，1970-1990 年代稳定在 1.1 万部左右。
- **爆发式增长期（2000 至今）**：2000 年代跃升至 41,878 部，2010 年代达到峰值 136,906 部，2020 年代（截至数据）为 130,462 部。数字电影制作和流媒体平台的兴起是主要驱动力。

### 4.2 平均评分趋势

- **整体波动范围**：平均评分在 3.26~6.39 之间波动。
- **评分最高**：1960 年代（6.39）和 1950 年代（6.37），这一时期被认为是电影艺术的黄金时代。
- **评分最低**：1900 年代（3.26）和 1890 年代（3.50），早期电影技术不成熟，评分普遍偏低。
- **现代稳定期**：2000 年代至今，平均评分稳定在 6.2~6.3 之间，说明现代电影质量整体较为均衡。

### 4.3 关键发现

1. **数量与评分呈反向关系**：电影数量爆发式增长的同时，平均评分并未显著提升，说明大量新增电影拉低了整体质量水平。
2. **2030 年代数据异常**：仅 7 部电影且平均评分为 NULL，属于数据边界情况，可忽略。
3. **黄金时代**：1950-1960 年代是平均评分最高的时期，电影艺术质量达到巅峰。
