# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 17:01:21
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计 1990 年代（1990-1999 年）上映电影的平均评分，用于评估该年代电影的整体质量水平。查询基于 IMDb 数据库的 `titles` 表，筛选出 `title_type='movie'` 且上映年份在 1990-1999 年之间的电影，并计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计年代 | 1990 - 1999 |
| 平均评分 | **6.15**（满分 10 分） |
| 精确值 | 6.153262857446869 |

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **整体水平**：1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。
- **数据过滤逻辑**：
  - `title_type = 'movie'`：仅统计电影，排除电视剧等其他类型。
  - `start_year BETWEEN 1990 AND 1999`：限定上映年份在 1990-1999 之间。
  - `average_rating IS NOT NULL`：排除无评分记录的数据，确保平均值计算准确。
- **参考意义**：该数值可作为衡量 1990 年代电影整体质量的基准，也可用于与其他年代（如 2000 年代、2010 年代）进行横向对比。
