# 1990 年代上映电影平均评分分析报告

> 生成时间：2026-08-07_16-41-35
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影平均评分情况。通过查询 IMDb 数据库中的 `titles` 表，筛选出 `title_type = 'movie'` 且 `start_year` 在 1990 至 1999 年之间的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 时间范围 | 1990 - 1999 年 |
| 作品类型 | 电影（movie） |
| 平均评分 | **6.15 分** |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 5. 分析解读

- **平均评分 6.15 分**：在 0-10 的评分体系中处于中等偏上水平，说明 1990 年代上映的电影整体质量较为均衡。
- **数据口径**：仅统计 `title_type = 'movie'` 的电影作品，不包含电视剧、纪录片等其他类型；同时排除了 `average_rating` 为 NULL 的记录。
- **评分范围**：IMDb 评分通常集中在 1-10 分之间，6.15 分属于中等偏上的水平，反映了 1990 年代电影的整体口碑。
