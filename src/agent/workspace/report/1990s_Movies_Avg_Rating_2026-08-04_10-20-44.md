# 1990 年代电影平均评分分析报告

> 生成时间：2026-08-04 10:20:44
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告分析 1990 年代（1990-1999）上映电影的平均评分情况。通过聚合查询 `titles` 表中 `title_type = 'movie'` 且 `start_year` 在 1990 至 1999 年之间的记录，计算其 `average_rating` 的平均值，以评估该年代电影的整体质量水平。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.1533** |

1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie' AND start_year BETWEEN 1990 AND 1999
```

## 4. 分析解读

- **整体水平**：1990 年代电影平均评分约 6.15 分，属于 IMDb 评分体系中的中等偏上水平（IMDb 全库平均约 6 分左右）。
- **数据特征**：该查询为单表聚合操作，仅涉及 `titles` 表的 `average_rating`、`start_year`、`title_type` 三个字段，无需 JOIN，执行效率高。
- **业务口径**：仅统计 `title_type = 'movie'`（电影），排除了电视剧、短片等其他类型，确保口径准确。
