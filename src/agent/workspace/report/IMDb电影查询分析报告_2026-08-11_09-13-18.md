## 3. 生成 SQL

### 3.1 Top 10 电影评分

```sql
SELECT primary_title AS title, average_rating
FROM titles
WHERE title_type = 'movie'
  AND average_rating IS NOT NULL
  AND num_votes > 10000
ORDER BY average_rating DESC
```

> 说明：根据 IMDb 业务规则，排名类查询应用 `num_votes > 10000` 过滤，排除低投票数影片评分虚高的情况，确保排名可信度。通过 `run_sql` 的 `limit=10` 参数控制返回 10 行。

### 3.2 2020 年后电影数量

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie'
  AND start_year >= 2020
```

### 3.3 Tom Hanks 出生年份

```sql
SELECT birth_year FROM names WHERE primary_name = 'Tom Hanks'
```
