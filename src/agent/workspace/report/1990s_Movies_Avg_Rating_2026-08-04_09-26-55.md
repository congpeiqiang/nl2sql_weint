# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:26:55
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影的平均评分情况。查询基于 IMDb 数据库中的 `titles` 表，筛选条件为 `title_type = 'movie'` 且 `start_year` 在 1990 至 1999 年之间。

## 2. 核心数据

**1990 年代电影的平均评分为：6.1533**（满分 10 分）

| 指标 | 数值 |
|------|------|
| 平均评分 | 6.1533 |
| 评分范围 | 0 - 10 |
| 年代范围 | 1990 - 1999 |

![1990年代电影平均评分](./平均评分_20260803_180714.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **整体水平**：1990 年代电影的平均评分为 **6.15 分**，处于中等偏上水平（满分 10 分）。
- **评分基准**：IMDb 评分体系中，6 分以上通常被认为是"值得观看"的作品，6.15 的平均分表明 1990 年代电影整体质量较为稳定。
- **数据说明**：该平均值基于所有 1990-1999 年间上映的电影（含评分数据），未按投票数或知名度进行加权筛选。
