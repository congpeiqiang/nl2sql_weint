## 1. 概述

## 4. 生成 SQL

```sql
SELECT
    start_year AS year,
    ROUND(AVG(average_rating), 2) AS avg_rating
FROM titles
WHERE title_type = 'tvSeries'
  AND start_year BETWEEN 2000 AND 2023
  AND start_year IS NOT NULL
  AND average_rating IS NOT NULL
GROUP BY start_year
ORDER BY start_year ASC
```

## 5. 分析解读

### 整体趋势
- **上升趋势明显**：电视剧平均评分从 2000 年的 6.59 逐步攀升至 2019 年的峰值 6.86，整体呈上升态势。
- **峰值年份**：2019 年达到最高平均评分 6.86。
- **低谷年份**：2001 年评分最低，为 6.36。

### 阶段划分
1. **2000-2009 年（平稳期）**：评分在 6.36~6.64 之间波动，整体偏低。
2. **2010-2019 年（黄金期）**：评分稳步上升，从 6.76 攀升至 6.86，是电视剧质量提升最快的十年。
3. **2020-2023 年（稳定期）**：评分稳定在 6.72~6.83 之间，略有回落但保持高位。

### 关键发现
- 24 年间电视剧平均评分提升了约 **0.27 分**（从 6.59 到 6.83）。
- 2010 年后电视剧质量显著提升，可能与流媒体平台崛起、制作水准提高有关。
- 2021 年出现小幅回落（6.72），可能是疫情后内容供给变化所致。
