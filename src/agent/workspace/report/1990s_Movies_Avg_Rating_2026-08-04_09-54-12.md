# 1990年代（1990-1999）电影平均评分分析报告

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映电影的平均评分情况。通过查询 IMDb 数据库中 `titles` 表，筛选出 `title_type='movie'` 且 `start_year` 在 1990 至 1999 年之间的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 时间范围 | 1990 - 1999 年 |
| 电影类型 | movie（电影） |
| **平均评分** | **6.1533** |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均评分为 6.1533 分（满分 10 分），处于中等偏上水平。
- **评分分布**：该数值反映了 1990 年代上映电影的整体口碑水平，属于 IMDb 评分体系中的"尚可"区间（6-7 分通常被认为是质量不错的电影）。
- **数据说明**：查询排除了 `average_rating` 为 NULL 的记录，确保统计的准确性。
