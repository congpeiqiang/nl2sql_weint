# 各年代电影平均评分与数量分析报告

> 生成时间：2026-08-06 12:18:19
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 IMDb 数据库中每个年代（decade）的电影数量与平均评分，覆盖从 1890s 到 2030s 共 15 个年代区间。数据基于 `titles` 表中 `title_type='movie'` 且 `start_year` 非空的记录。

## 3. 生成 SQL

```sql
SELECT FLOOR(t.start_year / 10) * 10 AS decade,
       COUNT(*) AS movie_count,
       AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie' AND t.start_year IS NOT NULL
GROUP BY FLOOR(t.start_year / 10) * 10
ORDER BY decade ASC
```

## 4. 分析解读

### 4.1 电影数量趋势

- **爆发式增长**：2010s（约 13.7 万部）和 2020s（约 13 万部）的电影数量远超此前所有年代，反映了电影产业和流媒体平台的快速增长。
- **早期缓慢发展**：1890s-1900s 电影数量极少（1 部和 33 部），属于电影工业萌芽期。
- **稳步增长期**：1910s-1990s 电影数量在 1,000-12,000 部之间波动，其中 1970s-1990s 稳定在 1.1 万部左右。

### 4.2 平均评分趋势

- **黄金时代**：1950s（6.37）和 1960s（6.39）的平均评分最高，这一时期被认为是电影艺术的黄金时代。
- **评分回升**：从 1970s 的 5.87 低点后，评分逐步回升至 2000s 的 6.28，并稳定在 6.2-6.3 区间。
- **早期数据偏差**：1890s-1900s 评分较低（3.26-3.50），但样本量极小，参考价值有限。
- **2030s 数据**：仅 7 部电影且无评分数据，属于边缘情况。

### 4.3 综合观察

- 电影数量与平均评分呈**负相关**趋势：数量爆发式增长的同时，评分趋于稳定在 6.2-6.3 区间，说明大规模产出并未显著拉低整体质量。
- 1950s-1960s 是"小而精"的黄金时代，而 2010s-2020s 是"大而稳"的繁荣时代。
