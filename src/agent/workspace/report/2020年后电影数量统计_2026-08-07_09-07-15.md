# 2020 年之后（含 2020）电影数量统计报告

> 生成时间：2026-08-07 09:07:15
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 imdb 数据库中 **2020 年及之后**（`start_year >= 2020`）上映的电影数量。电影通过 `title_type = 'movie'` 进行识别，并排除了 `start_year` 为 NULL 的记录。

## 2. 核心数据

| 统计维度 | 数值 |
|---------|------|
| 2020 年及之后上映的电影数量 | **130,469 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*)
FROM titles
WHERE title_type = 'movie'
  AND start_year >= 2020;
```

## 4. 分析解读

- 2020 年及之后（含 2020）共有 **130,469 部电影**。
- 该统计基于 `titles` 表，通过 `title_type='movie'` 过滤出电影类型，并限定 `start_year >= 2020`。
- 查询采用策略 B（快速通道）——单表简单筛选 + COUNT 计数，执行高效。
