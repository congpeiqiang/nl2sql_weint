# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 11:18:44
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告查询并分析了 IMDb 数据库中 **1990 年代（1990-1999 年）** 上映电影的平均评分，旨在了解该年代电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **查询范围** | 1990-1999 年上映的电影 |
| **筛选条件** | title_type = 'movie'，average_rating IS NOT NULL |
| **平均评分** | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND average_rating IS NOT NULL
```

## 4. 分析解读

- **评分水平**：1990 年代电影平均评分为 **6.15/10**，处于中等偏上水平，说明该年代整体电影质量尚可。
- **评分区间定位**：在 0-10 分的评分体系中，6.15 分位于"及格"与"良好"之间，略高于中间值 5 分。
- **年代特征**：1990 年代是电影工业快速发展期，涌现了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等），但大量中低质量影片拉低了整体均值。
