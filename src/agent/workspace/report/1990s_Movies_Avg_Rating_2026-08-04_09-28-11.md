# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:28:11
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年上映）电影的平均评分情况。通过 IMDb 数据库中的 `titles` 表，筛选出 `title_type='movie'` 且上映年份在 1990-1999 年之间的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15** |

![1990年代电影平均评分](./平均评分_20260803_180714.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15**：1990 年代上映的电影整体平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **数据范围**：统计仅包含 `title_type='movie'` 的电影，排除了电视剧、短片等其他类型。
- **评分有效性**：仅统计了 `average_rating` 非空的记录，确保评分数据的有效性。
- **年代特征**：6.15 的平均分反映了 1990 年代电影的整体质量水平，这一时期的电影在影史中具有重要地位。
