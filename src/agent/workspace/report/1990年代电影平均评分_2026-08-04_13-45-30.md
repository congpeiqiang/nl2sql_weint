# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 13:45:30
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本次查询旨在统计 1990 年代（1990-1999 年）期间上映电影的平均评分（average_rating），筛选条件为作品类型为电影（title_type = 'movie'）且有有效评分数据。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **作品类型** | 电影（movie） |
| **平均评分** | **6.15**（精确值：6.153262857446869） |
| **评分范围** | 0 - 10 分 |

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND average_rating IS NOT NULL
```

- **年代特征**：1990 年代是电影工业快速发展期，既有大量商业大片（如《泰坦尼克号》《侏罗纪公园》），也有众多独立电影和艺术片，评分分布较为均衡。
