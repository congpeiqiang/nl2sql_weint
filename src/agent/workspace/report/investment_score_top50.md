## Investment Score 公式

```
Investment Score = 
  0.35 × (average_rating / 10) +           # 评分因子（权重35%）
  0.25 × (LOG(num_votes+1) / LOG(MAX_VOTES+1)) +  # 热度因子（权重25%）
  0.20 × (1 - ABS(runtime_minutes-120)/120) +      # 片长合理性（权重20%）
  0.20 × (CASE WHEN is_adult=0 THEN 1 ELSE 0.3 END) # 内容普适性（权重20%）
```
