# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:40:55
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影的平均评分情况。通过聚合 IMDb 数据库中该年代所有电影（`title_type='movie'`）的 `average_rating` 字段，得出整体平均评分水平。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 年代范围 | 1990 - 1999 |
| 电影类型 | movie |
| **平均评分** | **6.15 分**（精确值 6.153262857446869） |

### 图表展示

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **整体水平**：1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。
- **数据口径**：仅统计 `title_type='movie'` 的电影，排除了电视剧、短片等其他类型；同时排除了 `average_rating` 为 NULL 的记录，确保聚合结果准确。
- **参考意义**：该数值可作为衡量 1990 年代电影整体质量的基准，也可用于与其他年代（如 1980 年代、2000 年代）进行横向对比。
