# 电视类型数量统计报告

> 生成时间：2026-08-07 09:40:58
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 imdb 数据库中电视相关的类型数量。基于 `titles` 表的 `title_type` 字段，筛选出所有以 `tv` 开头的电视相关类型，去重后统计数量。

## 2. 核心数据

**共有 7 种电视类型。**

| 电视类型 | 说明 |
|---------|------|
| tvSeries | 电视剧系列 |
| tvEpisode | 剧集 |
| tvMovie | 电视电影 |
| tvMiniSeries | 迷你剧 |
| tvSpecial | 电视特辑 |
| tvPilot | 试播集 |
| tvShort | 电视短片 |

## 3. 生成 SQL

```sql
SELECT COUNT(DISTINCT title_type) AS tv_type_count
FROM titles
WHERE title_type LIKE 'tv%'
```

## 4. 分析解读

- imdb 数据库中共有 **7 种电视类型**，涵盖电视剧系列、剧集、电视电影、迷你剧、电视特辑、试播集和电视短片。
- 查询采用策略 B（快速通道）——单表简单 COUNT 查询，执行高效。
