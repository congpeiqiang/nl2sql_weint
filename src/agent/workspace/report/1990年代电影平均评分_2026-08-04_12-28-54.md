# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 12:28:54
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映电影的平均评分，数据来源于 IMDb 数据库。仅统计有评分记录的电影（排除 average_rating 为 NULL 的记录）。

## 2. 核心数据

| 指标 | 值 |
|------|-----|
| **平均评分** | **6.15**（满分 10 分） |
| 查询范围 | 1990-1999 年上映的电影 |
| 数据类型 | title_type = 'movie' |
| 过滤条件 | average_rating IS NOT NULL |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 5. 分析解读

- **整体评分水平**：1990 年代电影平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平
- **评分分布特征**：该均值反映了 1990 年代电影的整体质量，涵盖了从经典佳作到一般作品的完整分布
- **时代背景**：1990 年代是电影工业快速发展期，涌现了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等），但也有大量平庸之作拉低了整体均值
- **数据质量**：仅统计有评分记录的电影，排除了未评分作品，确保结果的可靠性
