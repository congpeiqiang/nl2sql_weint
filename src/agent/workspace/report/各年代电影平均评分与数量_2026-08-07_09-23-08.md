# 各年代电影平均评分与数量统计报告

> 生成时间：2026-08-07 09:23:08
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告按十年分组统计了 imdb 数据库中电影的平均评分和数量。年代通过 `FLOOR(start_year / 10) * 10` 计算（如 1994→1990），仅统计 `title_type='movie'` 的电影，并排除 `start_year` 和 `average_rating` 为 NULL 的记录。

## 3. 生成 SQL

```sql
SELECT FLOOR(t.start_year / 10) * 10 AS decade,
       AVG(t.average_rating) AS avg_rating,
       COUNT(*) AS movie_count
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
GROUP BY FLOOR(t.start_year / 10) * 10
ORDER BY decade ASC
```

## 4. 分析解读

- **电影数量**：2000 年代后电影数量急剧增长，2010 年代达到峰值（75,972 部），2020 年代（截至统计时）为 66,750 部。
- **平均评分**：整体稳定在 6.0-6.4 之间，其中 **1960 年代平均评分最高（6.39）**，1950 年代次之（6.37）。
- **早期数据**：1890-1900 年代电影数量极少（1-32 部），平均评分偏低（3.26-3.50），样本量小导致评分参考意义有限。
- **趋势**：电影产量自 2000 年代起爆发式增长，但平均评分保持相对稳定，未随产量增长而明显波动。
