# 投票数超 100 万的电影数量分析报告

> 生成时间：2026-08-05 12:18:53
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 IMDb 数据库中**投票数（num_votes）超过 100 万**的电影数量。该查询通过 `titles` 表进行简单计数，过滤条件为 `title_type = 'movie'` 且 `num_votes > 1000000`。

## 2. 核心数据

| 指标 | 数值 |
|------|:---:|
| 投票数超 100 万的电影数量 | **22 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie' AND num_votes > 1000000
```

## 4. 分析解读

### 4.1 数据规模

数据库中仅有 **22 部电影**的投票数超过 100 万，说明达到这一投票量级的电影非常稀少，属于极高人气作品。
