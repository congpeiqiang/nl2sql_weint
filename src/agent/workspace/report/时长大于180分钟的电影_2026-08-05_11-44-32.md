## 3. 生成 SQL

```sql
SELECT primary_title, runtime_minutes
FROM titles
WHERE title_type = 'movie' AND runtime_minutes > 180
ORDER BY runtime_minutes DESC
```

## 4. 分析解读

### 4.1 数据分布特征

- **片长跨度极大**：最短 1452 分钟（约 24 小时），最长 51420 分钟（约 35.7 天），相差约 35 倍。
- **头部集中效应明显**：前 3 部电影（Logistics、Ambiancé、Carnets Filmés）片长均超过 28000 分钟，占据了绝对主导地位。

### 4.2 超长电影类型分析

这些超长电影多为**实验性/艺术电影**，而非传统商业电影：

- **Logistics**（51420 分钟 ≈ 35.7 天）：瑞典实验电影，是 IMDb 上片长最长的电影之一。
- **Ambiancé**（43200 分钟 = 30 天）：瑞典实验电影，计划于 2020 年上映。
- **Modern Times Forever**（14400 分钟 = 10 天）：芬兰实验电影，展示赫尔辛基一座建筑的衰败过程。
- **Beijing 2003**（9000 分钟 ≈ 6.25 天）：中国实验电影。
