# 1990年代上映电影平均评分分析报告

> 生成时间：2026-07-31_11-21-47
> 数据来源：imdb 数据库

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影平均评分情况。查询基于 IMDb 数据集，仅统计 `title_type = 'movie'` 的电影，并排除无评分记录（`average_rating IS NULL`）的数据。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 时间范围 | 1990 - 1999 年 |
| 平均评分 | **6.15 分** |

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代上映的电影整体平均评分为 6.15 分（满分 10 分制）。
- **数据范围**：仅统计了类型为 `movie` 的电影，排除了电视剧、短片等其他类型。
- **数据质量**：排除了没有评分记录的电影，确保平均值反映真实评分情况。
- **年代特征**：6.15 分处于中等偏上水平，说明 1990 年代电影整体质量较为均衡。
