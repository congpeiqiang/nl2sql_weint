# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-03 16:01:31
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映电影的平均评分，用于了解该年代电影的整体质量水平。

**核心结论：** 1990 年代电影的平均评分约为 **6.15 分**（满分 10 分）。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 平均评分 | **6.15** |
| 评分范围 | 1.0 - 10.0（IMDb 加权平均分） |
| 统计口径 | 仅统计 `title_type = 'movie'` 的电影 |

### 图表展示

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15**：处于 IMDb 评分的中等偏上水平，说明 1990 年代电影整体质量较为稳定。
- **筛选条件说明**：
  - `title_type = 'movie'`：仅统计电影，排除短片、电视剧、游戏等其他类型。
  - `start_year BETWEEN 1990 AND 1999`：限定 1990 年代上映的作品。
  - 排除 `start_year` 和 `average_rating` 为 NULL 的记录，确保数据质量。
- **性能优化**：该查询为单表聚合查询，无性能隐患，dry_run 验证通过后直接执行成功。
