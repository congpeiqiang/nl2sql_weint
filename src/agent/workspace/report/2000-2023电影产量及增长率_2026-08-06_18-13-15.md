## 1. 概述

## 3. 生成 SQL

```sql
WITH yearly_counts AS (
  SELECT t.start_year AS year, COUNT(DISTINCT t.id) AS movie_count
  FROM titles t
  WHERE t.title_type = 'movie'
    AND t.start_year BETWEEN 2000 AND 2023
    AND t.start_year IS NOT NULL
  GROUP BY t.start_year
)
SELECT year, movie_count,
  ROUND((movie_count - LAG(movie_count) OVER (ORDER BY year)) * 100.0 
        / NULLIF(LAG(movie_count) OVER (ORDER BY year), 0), 2) AS growth_rate
FROM yearly_counts
ORDER BY year ASC
```

## 4. 分析解读

### 整体趋势
- **持续增长期（2000-2014）**：电影产量从 1,453 部稳步增长至 15,766 部，15 年间增长超过 10 倍。
- **增长高峰**：2007 年（+70.58%）和 2008 年（+50.49%）增长最为迅猛，两年间产量从 3,565 部跃升至 9,151 部。
- **产量下滑期（2015-2016）**：2015 年（-16.59%）和 2016 年（-35.40%）出现明显下降，2016 年产量跌至 8,495 部，为统计期内低谷。
- **快速恢复（2017-2023）**：2017 年后产量快速回升，2018 年（+53.63%）增长显著，2023 年达到 20,923 部，为统计期内最高。

### 关键洞察
1. **2007-2008 年爆发式增长**：可能与数字电影制作技术普及、流媒体平台兴起有关。
2. **2015-2016 年下滑**：可能与行业调整、制作成本上升等因素相关。
3. **2020 年疫情冲击**：2020 年产量下降 10.48%，但 2021 年迅速反弹（+17.46%）。
4. **近年高位稳定**：2022-2023 年产量维持在 2 万部以上，增速放缓至个位数。
