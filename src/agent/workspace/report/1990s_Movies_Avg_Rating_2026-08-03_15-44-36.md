# 1990 年代（1990-1999）电影平均评分报告

> 生成时间：2026-08-03 15:44:36
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计 1990 年代（1990-1999）上映电影的平均评分，用于评估该年代电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|-----|
| **平均评分** | **6.15** |

### 图表

![1990年代电影平均评分](./0_20260803_154432.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **过滤条件**：
  - `title_type = 'movie'`：仅统计电影，排除短片、电视剧、游戏等其他作品类型。
  - `start_year BETWEEN 1990 AND 1999`：限定上映年份在 1990-1999 之间。
  - `average_rating IS NOT NULL`：排除无评分的记录，确保平均值准确。
- **结论**：1990 年代电影整体质量处于中等偏上水平，平均评分 6.15 分。
