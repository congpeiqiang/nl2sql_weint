# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 13:11:06
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询了 IMDb 数据库中 1990 年代（1990-1999 年）所有电影的平均评分，旨在了解该时期电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **查询范围** | 1990-1999 年 |
| **作品类型** | 电影（movie） |
| **平均评分** | **6.15**（满分 10 分） |
| **评分区间** | 0-10 分 |

### 评分仪表盘

![1990年代电影平均评分仪表盘](./1990年代电影平均评分_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND average_rating IS NOT NULL
```

## 4. 分析解读

- **评分水平**：1990 年代电影平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平，说明该时期电影整体质量尚可。
- **评分分布**：从仪表盘可以看出，6.15 分位于 5-7 分的蓝色区间内，属于"中等良好"水平，距离"优秀"（8+ 分）还有一定差距。
- **时代背景**：1990 年代是电影工业快速发展期，大量商业片涌入市场，拉低了整体平均分，但同时也诞生了众多经典佳作。
