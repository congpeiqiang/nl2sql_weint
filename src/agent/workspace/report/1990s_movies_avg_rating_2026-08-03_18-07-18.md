# 1990年代电影平均评分分析报告

> 生成时间：2026-08-03 18:07:18
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 **1990-1999 年**（1990年代）上映电影的平均评分，按年份分组计算 `AVG(average_rating)`。筛选条件为 `title_type = 'movie'`（仅电影，排除短片、电视剧等），并排除无评分记录。

## 2. 核心数据

| 年份 | 平均评分 |
|------|---------|
| 1990 | 5.78 |
| 1991 | 6.15 |
| 1992 | 6.13 |
| 1993 | 6.28 |
| 1994 | 6.15 |
| 1995 | 6.12 |
| 1996 | **6.42** |
| 1997 | 6.31 |
| 1998 | 6.13 |
| 1999 | 6.22 |

## 3. 生成 SQL

```sql
SELECT t.start_year, AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
GROUP BY t.start_year
ORDER BY t.start_year ASC
```

## 4. 分析解读

- **整体水平**：1990年代电影平均评分在 **5.78 ~ 6.42** 之间波动，整体处于中等偏上水平。
- **最高年份**：**1996年** 平均评分最高（**6.42**），是1990年代的评分巅峰。
- **最低年份**：**1990年** 平均评分最低（**5.78**），明显低于其他年份。
- **趋势特征**：1990年处于低谷后，1991年起回升并稳定在 6.1~6.4 区间；1996年达到峰值后略有回落，但整体保持平稳。
