# 1990年代电影平均评分分析报告

> 生成时间：2026-08-04 15:04:41
> 数据来源：IMDb 数据库

## 1. 概述

本报告分析了 1990 年代（1990-1999 年）期间上映的电影的平均评分情况。通过查询 IMDb 数据库中所有标记为电影类型（title_type = 'movie'）且有评分记录的作品，计算其平均评分。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| **平均评分** | **6.15** |
| 评分范围 | 0-10 分 |
| 时间范围 | 1990-1999 年 |
| 数据类型 | 电影（movie） |

## 3. 生成 SQL

```sql
SELECT
  ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

**查询说明：**
- 筛选条件：title_type = 'movie'（仅电影类型）
- 时间范围：start_year BETWEEN 1990 AND 1999（1990年代）
- 排除条件：average_rating IS NOT NULL（仅统计有评分的作品）
- 计算方式：AVG() 平均值函数，ROUND() 保留两位小数

1990 年代电影的平均评分为 **6.15 分**（满分 10 分），这个分数处于中等偏上水平：

- **评分区间定位**：6.15 分位于 6-7 分区间，属于"良好"级别
- **相对位置**：高于及格线（5 分），但距离优秀线（7.5 分）还有一定差距
- **整体质量**：反映出 1990 年代电影整体质量较为稳定，观众评价较为正面
