# 1990 年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 11:05:31
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询并分析了 IMDb 数据库中 1990 年代（1990-1999 年）上映电影的平均评分情况。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **数据类型** | 电影（movie） |
| **平均评分** | **6.15** |
| **评分范围** | 0 - 10 分 |

## 3. 生成 SQL

```sql
SELECT ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year IS NOT NULL
  AND t.start_year >= 1990
  AND t.start_year <= 1999
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的整体平均评分处于中等偏上水平，在 10 分制中超过及格线。
- **数据覆盖全面**：该结果涵盖了 1990 年代所有有评分记录的电影，包括低投票数的影片。
- **评分分布**：由于包含了大量低投票数的小众影片，平均分被拉低。如果只看高可信度评分（投票数 > 10000），平均分可能会有所不同。
- **年代特征**：1990 年代是电影产业的黄金时期，诞生了大量经典作品，6.15 的平均分反映了该时期电影产量大、质量参差不齐的特点。
