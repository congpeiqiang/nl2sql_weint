# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:28:38
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映的所有电影（`title_type='movie'`）的平均 IMDb 评分，旨在了解该年代电影的整体质量水平。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15 分**（精确值 6.153） |
| 评分范围 | 0 - 10 分 |

![1990年代电影平均评分](./1990s_Movies_Avg_Rating_chart.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均 IMDb 评分处于中等偏上水平（IMDb 评分通常以 6 分为基准线）。
- **数据口径**：仅统计 `title_type='movie'` 的电影，排除了电视剧、短片等其他类型；同时排除了 `average_rating` 为 NULL 的记录，确保统计准确性。
- **年代特征**：6.15 分的平均分反映了 1990 年代电影整体质量稳定，处于 IMDb 评分体系的中等区间。
