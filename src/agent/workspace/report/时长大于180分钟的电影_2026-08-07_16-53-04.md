## 3. 生成 SQL

```sql
SELECT primary_title, runtime_minutes
FROM titles
WHERE title_type = 'movie' AND runtime_minutes > 180
ORDER BY runtime_minutes DESC
```

**执行逻辑说明：**
- **表**：`titles`（作品表）
- **过滤条件**：
