# 1990年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 13:58:03
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询了 IMDb 数据库中 **1990 年代（1990-1999 年）** 上映电影的平均评分（average_rating），旨在了解该年代电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **电影类型** | movie（仅电影，排除电视剧、短片等） |
| **平均评分** | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year >= 1990
  AND t.start_year <= 1999
  AND t.average_rating IS NOT NULL
```

**关键业务规则应用：**
- ✅ 过滤 `title_type = 'movie'`（只统计电影，排除电视剧、短片等）
- ✅ 时间范围 `start_year BETWEEN 1990 AND 1999`
- ✅ 处理 NULL 值：`average_rating IS NOT NULL`（确保评分计算准确）

## 4. 分析解读

### 4.1 评分水平分析

1990 年代电影平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。这一评分反映了：

- **整体质量稳定**：6.15 分说明 1990 年代电影整体质量较为均衡，既有大量经典佳作，也有不少平庸之作拉低均值
- **评分分布特征**：IMDb 评分通常呈正态分布，大部分电影集中在 5-7 分区间，6.15 的均值符合这一规律
