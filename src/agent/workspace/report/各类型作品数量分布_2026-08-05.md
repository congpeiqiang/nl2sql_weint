# 各类型作品数量分布报告

> 生成时间：2026-08-05 14:43:34
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告统计 IMDb 数据库中**每种作品类型（title_type）的作品数量**，并按数量降序排列，以了解不同类型作品在数据库中的分布情况。

## 2. 核心数据

| 作品类型 (title_type) | 数量 |
|----------------------|------|
| tvEpisode（剧集） | 8,562,923 |
| short（短片） | 889,676 |
| movie（电影） | 469,181 |
| video（录像带/数字发行） | 243,965 |
| tvSeries（电视剧系列） | 232,074 |
| tvMovie（电视电影） | 96,397 |
| tvMiniSeries（迷你剧） | 59,729 |
| tvSpecial（电视特辑） | 48,708 |
| videoGame（电子游戏） | 39,366 |
| tvShort | 7,092 |
| tvPilot | 1 |

## 3. 生成 SQL

```sql
SELECT title_type, COUNT(*) AS movie_count
FROM titles
GROUP BY title_type
ORDER BY movie_count DESC
```

## 4. 分析解读

### 4.1 数量分布特征

- **剧集（tvEpisode）独占鳌头**：数量高达 **856 万+**，占全部作品类型的绝对主导地位，远超其他类型。
- **短片（short）位居第二**：约 89 万，约为剧集的十分之一。
- **电影（movie）排名第三**：约 47 万，是传统意义上的"电影"主体。

### 4.2 长尾分布

从 tvSeries（23 万）到 tvPilot（仅 1 条），数量呈明显的**长尾分布**。前 3 大类型（tvEpisode、short、movie）合计占比超过 90%，而 tvShort、tvPilot 等类型数量极少。

### 4.3 关键洞察

- 数据库以**剧集类内容**为主，这与 IMDb 作为影视数据库收录大量单集记录的特性一致。
- 传统"电影"（movie）仅排第三，说明 IMDb 的覆盖面远超院线电影，包含大量短片、录像带、电视内容等。
- tvPilot 仅 1 条记录，可能是数据录入的特殊情况。
