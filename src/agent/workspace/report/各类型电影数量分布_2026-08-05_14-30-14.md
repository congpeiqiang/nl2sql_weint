# 各类型电影数量分布报告

> 生成时间：2026-08-05 14:30:14
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告统计 IMDb 数据库中**每种作品类型（title_type）的数量**，并按数量降序排列，以了解不同类型作品的规模分布情况。

## 2. 核心数据

| 类型 | 电影数量 |
|------|---------|
| tvEpisode（剧集） | 8,562,923 |
| short（短片） | 889,676 |
| movie（电影） | 469,181 |
| video（录像带/数字发行） | 243,965 |
| tvSeries（电视剧系列） | 232,074 |
| tvMovie（电视电影） | 96,397 |
| tvMiniSeries（迷你剧） | 59,729 |
| tvSpecial（电视特辑） | 48,708 |
| videoGame（电子游戏） | 39,366 |
| tvShort（电视短片） | 7,092 |
| tvPilot（试播集） | 1 |

**共 11 种类型，总计约 1,060 万部作品。**

## 3. 生成 SQL

```sql
SELECT title_type AS 类型, COUNT(id) AS 电影数量
FROM titles
GROUP BY title_type
ORDER BY COUNT(id) DESC
```

## 4. 分析解读

### 4.1 数量分布特征

- **tvEpisode（剧集）** 以约 **856 万部** 的数量遥遥领先，占总量的 **80.7%**，是 IMDb 中数量最庞大的作品类型。
- **short（短片）** 以约 **89 万部** 位居第二，占比约 **8.4%**。
- **movie（电影）** 以约 **47 万部** 位列第三，占比约 **4.4%**。

### 4.2 头部集中效应

前三大类型（tvEpisode、short、movie）合计占比超过 **93%**，呈现出明显的头部集中效应。其余 8 种类型合计仅占约 7%。

### 4.3 长尾分布

- **tvPilot（试播集）** 仅 1 部，属于极长尾数据。
- 中间类型（video、tvSeries、tvMovie 等）数量在数万到数十万之间，形成平滑的递减曲线。
