# 各电影类型数量分布分析报告

> 生成时间：2026-08-03_10-00-42
> 数据来源：imdb 数据库（titles / titles_genres / genres 表）

## 1. 概述

本报告统计了 IMDb 数据库中**长片电影（title_type = 'movie'）**的类型分布情况，共识别出 **26 种电影类型**，并统计了每种类型对应的电影数量。

**统计口径说明：**
- 仅统计 `title_type = 'movie'`（长片电影），不包含短片、电视剧、游戏等其他作品类型
- 使用 `COUNT(DISTINCT t.id)` 去重计数，确保每部电影只计数一次（一部电影可能属于多个类型）

## 3. 生成 SQL

```sql
SELECT g.display_name AS genre,
  COUNT(DISTINCT t.id) AS movie_count
FROM titles t
JOIN titles_genres tg ON tg.title_id = t.id
JOIN genres g ON g.id = tg.genre_id
WHERE t.title_type = 'movie'
GROUP BY g.id, g.display_name
ORDER BY movie_count DESC
```

### 关键发现

1. **头部集中明显**：Drama（剧情，154,043 部）和 Documentary（纪录片，113,966 部）是数量最多的两大类型，均超过 10 万部，合计占比超过总量的一半。

2. **长尾分布**：Game-Show（游戏秀，13 部）、Talk-Show（脱口秀，200 部）、Reality-TV（真人秀，552 部）数量最少，这些类型在长片电影中较为罕见。

3. **主流类型梯队**：Comedy（喜剧，66,885 部）、Thriller（惊悚，38,600 部）、Action（动作，36,731 部）、Horror（恐怖，35,146 部）构成第二梯队，均在 3 万部以上。

4. **数据跨度大**：从最多的 Drama（154,043 部）到最少的 Game-Show（13 部），数量相差超过 1 万倍，体现了电影类型分布的极度不均衡。
