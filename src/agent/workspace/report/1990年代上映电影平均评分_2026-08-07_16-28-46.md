## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映的电影的平均评分。查询范围为 IMDb 数据库中的 `titles` 表，仅统计 `title_type = 'movie'`（电影）类型的作品，并排除无评分记录的数据。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15 分**（精确值 6.153） |
| 评分范围 | 0 - 10 分 |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

**执行逻辑说明：**
- **表**：`titles`（作品表）
- **过滤条件**：
  - `title_type = 'movie'` — 只统计电影（排除电视剧、短片、游戏等）
  - `start_year BETWEEN 1990 AND 1999` — 限定 1990 年代上映
  - `average_rating IS NOT NULL` — 排除无评分的记录
- **聚合**：`AVG(average_rating)` 计算平均评分
