# 电影阵容强度（Cast Strength）分析报告

## 分析目标
按阵容强度分档（强≥0.6、中0.3-0.6、弱<0.3），统计各档电影的平均评分和数量。

## 阵容强度指数定义
**Cast Strength = (个人平均评分 > 7.0 的演员数) / 总参演演员数**

- 演员定义：category_id IN ('actor', 'actress')
- "个人平均评分"：该演员参演的所有电影的平均评分
- 过滤条件：title_type = 'movie', num_votes > 1000, average_rating IS NOT NULL

## 统计结果

| 档位 | 电影数量 | 平均评分 |
|------|:-------:|:--------:|
| **强 (Strong)** ≥ 0.6 | 4,135 | 7.56 |
| **中 (Medium)** 0.3~0.6 | 2,718 | 7.28 |
| **弱 (Weak)** < 0.3 | 27,091 | 5.94 |

## 分析结论

1. **强阵容电影（4,135部）**：平均评分最高（7.56），说明阵容强的电影整体质量确实更高
2. **中阵容电影（2,718部）**：平均评分7.28，介于强和弱之间
3. **弱阵容电影（27,091部）**：数量最多但平均评分最低（5.94），说明阵容弱的电影整体评分偏低
4. **整体趋势**：阵容强度与电影评分呈正相关——阵容越强，平均评分越高
