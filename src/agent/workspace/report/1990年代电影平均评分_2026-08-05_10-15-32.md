# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-05 10:15:32
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影的平均评分情况。查询基于 IMDb 数据库中的 `titles` 表，筛选条件为 `title_type='movie'` 且 `start_year` 在 1990 至 1999 年之间，并排除评分为 NULL 的记录。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 时间范围 | 1990 - 1999 |
| 平均评分 | **6.1533**（约 6.15 分） |

![1990年代电影平均评分](./1990年代电影平均评分_gauge_chart_20260804_150607.svg)

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **评分区间解读**：IMDb 评分体系中，6 分以上通常被认为是"值得一看"的作品，6.15 分表明 1990 年代电影整体质量较为均衡。
- **数据口径**：仅统计 `title_type='movie'` 的电影（不含电视剧、短片等其他类型），并排除了无评分记录的数据，确保统计准确性。
