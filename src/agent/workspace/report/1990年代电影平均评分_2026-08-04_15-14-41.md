# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 15:14:41
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告查询了 1990 年代（1990-1999 年）上映电影的平均评分，旨在了解该时期电影的整体质量水平。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **作品类型** | 电影（movie） |
| **平均评分** | **6.15** |
| **评分范围** | 0 - 10 分 |

## 3. 生成 SQL

```sql
SELECT
  ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

**查询说明：**
- 筛选 `title_type = 'movie'` 确保只统计电影
- `start_year BETWEEN 1990 AND 1999` 限定 1990 年代
- `average_rating IS NOT NULL` 排除无评分记录
- 使用 `ROUND(..., 2)` 保留两位小数

## 4. 分析解读

- **6.15 分**处于 IMDb 10 分制的中等偏上水平，说明 1990 年代电影整体质量尚可
- 1990 年代是好莱坞商业大片蓬勃发展的时期，诞生了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等）
- 平均值受到大量中低评分电影的拉低影响，头部高质量电影的评分可能远高于此均值
- 如需更深入了解，可进一步分析：
  - 按年份拆分的评分趋势
  - 高评分（≥8.0）电影的数量和占比
  - 与其他年代的评分对比
