# 各类型作品数量分布报告

> 生成时间：2026-08-07_18-55-43
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 IMDb 数据库中 `titles` 表按作品类型（`title_type`）分类的数量分布，并按数量从多到少排列。共统计出 **11 种**作品类型。

## 2. 核心数据

| 作品类型 (title_type) | 数量 |
|----------------------|------|
| tvEpisode（剧集） | 8,562,923 |
| short（短片） | 889,676 |
| movie（电影） | 469,181 |
| video（录像/数字发行） | 243,965 |
| tvSeries（电视剧系列） | 232,074 |
| tvMovie（电视电影） | 96,397 |
| tvMiniSeries（迷你剧） | 59,729 |
| tvSpecial（电视特辑） | 48,708 |
| videoGame（电子游戏） | 39,366 |
| tvShort（电视短片） | 7,092 |
| tvPilot（试播集） | 1 |

## 3. 生成 SQL

```sql
SELECT title_type, COUNT(*) AS movie_count
FROM titles
GROUP BY title_type
ORDER BY movie_count DESC
```

## 4. 分析解读

- **tvEpisode（剧集）** 数量遥遥领先，约 **856 万条**，占总量的绝大部分，这是因为每部电视剧系列都包含大量单集记录。
- **short（短片）** 和 **movie（电影）** 分别以约 89 万和 47 万条位居第二、第三。
- **tvPilot（试播集）** 仅 1 条，数量最少。
- 该查询为单表简单聚合，采用**策略B（快速通道）**执行，已通过 dry_run 验证。
