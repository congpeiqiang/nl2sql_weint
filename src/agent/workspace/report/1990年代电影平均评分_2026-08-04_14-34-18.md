# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 14:34:18
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本次查询旨在统计 IMDb 数据库中 **1990 年代（1990-1999 年）** 上映电影的**平均评分（average_rating）**，仅统计电影类型（movie），排除电视剧、短片等其他类型。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **数据类型** | 电影（movie） |
| **平均评分** | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND start_year IS NOT NULL
  AND average_rating IS NOT NULL
```

**筛选条件说明：**

| 条件 | 说明 |
|------|------|
| `title_type = 'movie'` | 仅统计电影类型，排除电视剧、短片等 |
| `start_year BETWEEN 1990 AND 1999` | 限定 1990 年代 |
| `start_year IS NOT NULL` | 排除年份缺失的记录 |
| `average_rating IS NOT NULL` | 排除无评分的记录 |

## 4. 分析解读

- **1990 年代电影平均评分为 6.15 分**（满分 10 分），处于中等偏上水平。
- 该评分反映了 1990 年代 IMDb 数据库中所有有评分记录的电影的整体质量分布。
- 1990 年代是电影产业的黄金时期之一，诞生了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等），但由于统计范围包含所有电影（含大量低分作品），整体均值被拉低至 6.15。
- 评分采用 **策略B（快速通道）** 完成查询，属于单表聚合查询，无需复杂 JOIN。
