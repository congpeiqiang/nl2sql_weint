## 1. 概述

本文档汇总说明 IMDb 数据库中定义的所有业务术语，涵盖角色分类、评分可信度、创作者分析指标等。

---

## 2. 角色与人员分类

| 术语 | 含义 | 计算/筛选方式 |
|------|------|-------------|
| **演员** | 表演者 | `category_id IN ('actor', 'actress')` |
| **主要演员** | 主演 | `category_id IN ('actor','actress') AND ordering <= 3` |
| **导演** | 影片导演 | `category_id = 'director'` |
| **主创团队** | 核心创作人员 | `ordering <= 3` |
| **跨界者** | 多角色从业者 | 同时拥有 actor+director 等身份 |

## 3. 作品分类

| 术语 | 含义 | 说明 |
|------|------|------|
| **短片** | 短篇作品 | `runtime_minutes < 40` |
| **标准片** | 常规长度 | `runtime_minutes 40-90` |
| **长片** | 较长作品 | `runtime_minutes 90-150` |
| **超长片** | 超长作品 | `runtime_minutes > 150` |
| **宝藏片** | 被忽视的好片 | `rating >= 8.5 AND votes < 5000` |

---

## 4. 评分可信度等级

| 投票数阈值 | 可信度 | 适用场景 |
|-----------|--------|---------|
| `< 1000` | 低 | 评分偏差大，不建议用于排名 |
| `>= 1000` | 基本可信 | 一般分析可用 |
| `>= 10000` | 较可信 | 推荐用于排行榜 |
| `>= 50000` | 高可信 | 经典影片级别 |
| `>= 200000` | 极高 | 现象级影片 |

> **推荐做法：** 排名类查询应加 `num_votes > 10000` 过滤

## 5. 创作者分析指标

### 5.1 黄金期（创作巅峰期）

**定义：** 连续 3 年平均评分 > 个人整体平均评分

**计算步骤：**
1. 计算某位创作者职业生涯所有作品的平均评分（个人整体平均）
2. 遍历其职业生涯，找出连续 3 年的作品
3. 计算这 3 年的平均评分
4. 如果该值大于个人整体平均评分，则这 3 年即为该创作者的「黄金期」

**示例：** 假设某导演职业生涯整体平均评分为 **7.5 分**：

| 时间段 | 作品平均评分 | 是否黄金期 |
|--------|------------|-----------|
| 1990-1992 | 6.8 | ❌ |
| 1995-1997 | 8.2 | ✅ 黄金期 |
| 2000-2002 | 7.3 | ❌ |
| 2005-2007 | 7.8 | ✅ 黄金期 |

该导演的黄金期为 **1995-1997 年** 和 **2005-2007 年**。

### 5.2 其他分析指标

| 术语 | 含义 | 计算方式 |
|------|------|---------|
| **年代 (decade)** | 十年跨度 | `FLOOR(start_year / 10) * 10` |
| **职业生涯跨度** | 从业年数 | `MAX(start_year) - MIN(start_year)` |
| **活跃密度** | 年均产出 | `COUNT(DISTINCT title_id) / career_span` |
| **多面手得分** | 角色多样性 | `COUNT(DISTINCT category_id)` |
| **热度指数** | 相对热度 | `num_votes / 同类型平均投票数` |
| **评分衰退率** | 质量下滑幅度 | `(首季评分 - 末季评分) / 首季评分` |

## 6. 剧集状态判断

| 条件 | 状态 |
|------|------|
| `end_year IS NULL` | 仍在播 |
| `end_year IS NOT NULL AND end_year >= YEAR(CURDATE()) - 2` | 近期完结 |
| `end_year IS NOT NULL AND end_year < YEAR(CURDATE()) - 2` | 已完结 |

---

## 7. NULL 值处理规则

| 字段 | 说明 |
|------|------|
| `start_year` | 可能为 NULL，查询时建议 `WHERE start_year IS NOT NULL` |
| `end_year` | 电视剧系列专用，电影通常为 NULL |
| `runtime_minutes` | 电视剧集通常为 NULL，电影一般有值 |
| `death_year` | NULL 表示人物仍健在 |
| `region` / `language`（titleakas） | 可为 NULL |
