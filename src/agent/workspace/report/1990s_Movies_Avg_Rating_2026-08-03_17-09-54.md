# 1990 年代电影平均评分分析报告

> 生成时间：2026-08-03 17:09:54
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999）上映电影的平均评分情况。统计范围为 IMDb 数据库中 `title_type = 'movie'` 且 `start_year` 在 1990 至 1999 年之间的电影作品，排除无评分记录的电影。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 统计范围 | 1990-1999 年上映的电影 |
| 平均评分 | **6.15** 分（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

### 查询逻辑说明

- **表**：`titles`（作品表）
- **筛选条件**：
  - `title_type = 'movie'` — 仅统计电影（排除短片、电视剧、游戏等）
  - `start_year BETWEEN 1990 AND 1999` — 限定 1990 年代
  - `average_rating IS NOT NULL` — 排除无评分的电影
- **聚合**：`AVG(average_rating)` 计算平均评分

## 4. 分析解读

- **1990 年代电影的平均评分为 6.15 分**（满分 10 分），处于中等偏上水平。
- 该评分反映了 1990 年代电影的整体质量水平，属于 IMDb 评分体系中的"尚可"区间（6-7 分通常被认为是质量不错的电影）。
- 1990 年代是电影工业的黄金时期，涌现了大量经典作品，但平均评分 6.15 说明该年代电影质量分布较为均衡，既有大量高分经典，也有不少评分一般的作品。
