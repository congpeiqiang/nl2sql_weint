## 3. 分析解读

### 3.1 头部集中效应

- **Drama** 以 274,833 部电影遥遥领先，占绝对主导地位
- 前三名（Drama、Documentary、Comedy）合计约 **55 万部**，是其余 24 种类型总和的数倍

### 3.2 类型分层

| 层级 | 数量范围 | 类型 |
|:---:|:---|:---|
| 第一梯队 | > 10 万 | Drama、Documentary、Comedy |
| 第二梯队 | 1 万 ~ 10 万 | Action、Romance、Thriller、Horror、Crime、Adventure、Mystery、Biography、Family、Fantasy、History、Sci-Fi、Music、Animation、Musical、War |
| 第三梯队 | < 1 万 | Sport、Adult、Western、News、Film-Noir、Reality-TV、Talk-Show、Game-Show |

### 3.3 尾部类型

Game-Show（13 部）、Talk-Show（222 部）、Reality-TV（599 部）等电视节目类型的电影数量极少，说明这些类型主要出现在电视剧而非电影领域。

## 4. 附录

### 4.1 执行 SQL

```sql
SELECT g.genre_id AS genre, COUNT(*) AS movie_count
FROM titles t
JOIN titles_genres tg ON t.title_id = tg.title_id
JOIN genres g ON tg.genre_id = g.genre_id
WHERE t.title_type = 'MOVIE'
GROUP BY g.genre_id
ORDER BY movie_count DESC
```
