# 2020 年之后（含 2020）电视剧数量统计报告

> 生成时间：2026-07-31_10-41-00
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计 imdb 数据库中，上映年份在 2020 年及之后（含 2020）的电视剧数量。统计口径为 `title_type = 'tvSeries'`（仅统计电视剧类型）。

## 2. 核心数据

| 统计维度 | 数值 |
|---------|------|
| 统计范围 | 2020 年及之后（start_year >= 2020） |
| 作品类型 | tvSeries（电视剧） |
| **电视剧总数** | **69,666 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS tv_series_count
FROM titles
WHERE title_type = 'tvSeries' AND start_year >= 2020
```

## 4. 分析解读

- **统计口径**：电视剧对应 IMDb 中的 `tvSeries` 类型（`titles.title_type = 'tvSeries'`），确保口径准确。
- **时间范围**：`start_year >= 2020` 表示 2020 年及之后上映的电视剧。
- **结果**：2020 年之后（含 2020）共有 **69,666 部电视剧**。
