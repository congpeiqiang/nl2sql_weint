# 各类型作品数量分布分析报告

> 生成时间：2026-08-11_09-54-00
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计 IMDb 数据库中 `titles` 表所有作品按 `title_type` 分组的数量，从多到少排列，共 11 种作品类型。

## 2. 核心数据

| 类型 | 数量 |
|------|------:|
| tvEpisode（剧集） | 8,562,923 |
| short（短片） | 889,676 |
| movie（电影） | 469,181 |
| video（录像带/数字发行） | 243,965 |
| tvSeries（电视剧系列） | 232,074 |
| tvMovie（电视电影） | 96,397 |
| tvMiniSeries（迷你剧） | 59,729 |
| tvSpecial（电视特辑） | 48,708 |
| videoGame（电子游戏） | 39,366 |
| tvShort（电视短片） | 7,092 |
| tvPilot（试播集） | 1 |

## 3. 生成 SQL

```sql
SELECT title_type AS 类型, COUNT(id) AS 电影数量
FROM titles
GROUP BY title_type
ORDER BY 电影数量 DESC
```

**说明：**
- 统计 `titles` 表中所有作品按 `title_type` 分组的数量
- 共 11 种类型
- 数据按数量从多到少排列

## 4. 分析解读

- **tvEpisode（剧集）独占鳌头**：约 856 万条，占绝对主导地位，远超其他类型。这是因为每部电视剧系列都包含大量单集记录。
- **short（短片）**：约 89 万条，位居第二。
- **movie（电影）**：约 47 万条，是常规意义上的"电影"数量。
- **长尾分布**：从 tvEpisode 到 tvPilot（仅 1 条），数量呈明显的长尾分布，tvPilot（试播集）数量极少。

> 💡 由于 tvEpisode 数量（856万）远超其他类型，图表采用**对数刻度**展示，以便清晰对比各类型数量级差异。
