# 1990 年代（1990-1999）电影平均评分分析报告

> 生成时间：2026-08-04 09:28:20
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告分析 1990 年代（1990-1999 年）上映的电影的平均评分情况。查询基于 IMDb 数据库中的 `titles` 表，筛选出 `title_type='movie'` 且上映年份在 1990 至 1999 年之间的电影，计算其 `average_rating` 的平均值。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 时间范围 | 1990 - 1999 年 |
| 电影类型 | movie（电影） |
| 平均评分 | **6.15** |

### 图表展示

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15 分**：1990 年代电影的平均评分为 6.15 分（满分 10 分），处于中等偏上水平。
- **数据范围**：查询覆盖了 1990 至 1999 年上映的所有电影类型（`title_type='movie'`），并排除了无评分记录（`average_rating IS NOT NULL`）的数据。
- **评分基准**：IMDb 评分体系为 0-10 分，6.15 分表明 1990 年代电影整体质量处于中等偏上水平，符合该年代电影工业的整体表现。
