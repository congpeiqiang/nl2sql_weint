## 1. 概述

本报告统计了 IMDb 数据库中每个类型（genre）下的作品数量，并按数量降序排列。共统计 **28 个类型**，覆盖了从剧情片到黑色电影等各类影视作品。

## 3. 生成 SQL

```sql
SELECT g.id AS genre, COUNT(tg.title_id) AS movie_count
FROM titles_genres tg
JOIN genres g ON tg.genre_id = g.id
GROUP BY g.id
ORDER BY movie_count DESC
```

## 4. 分析解读

### 4.1 头部集中度
- **drama（剧情）** 以 3,526,786 部作品高居榜首，远超其他类型，是第二名 comedy（2,443,737）的约 1.4 倍。
- 前 5 大类型（drama、comedy、talk-show、short、news）合计约 1,017 万部，占全部作品数量的较大比重。

### 4.2 长尾分布
- 排名靠后的类型如 **film-noir（黑色电影）** 仅 876 部，与榜首相差约 4000 倍，呈现明显的长尾分布特征。
- war（战争）、western（西部）、musical（歌舞）等类型数量也相对较少。

### 4.3 类型特征
- 剧情、喜剧、爱情等**主流叙事类型**数量庞大，反映了影视行业的内容供给结构。
- 脱口秀、新闻、纪录片等**非虚构/电视节目类型**也占据相当规模，说明该统计涵盖了电视节目与电影作品。
