## 1. 概述

本报告分析 IMDb 数据库中**合作 3 次以上且平均评分 ≥ 7.5** 的导演-演员黄金搭档。通过 `principals` 表自关联两次（一次查导演、一次查演员），统计每对导演-演员组合的合作次数与平均评分，筛选出高质量且多次合作的黄金搭档。

**查询条件：**
- 合作次数 ≥ 3 次
- 平均评分 ≥ 7.5
- 仅统计电影（`title_type='movie'`）
- 评分可信度过滤（`num_votes > 5000`）

## 3. 生成 SQL

```sql
-- 通过 principals 表自关联，统计导演-演员合作次数与平均评分
SELECT
    d.name AS director,
    a.name AS actor,
    COUNT(*) AS coop_count,
    ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM principals pd
JOIN names d ON pd.name_id = d.name_id AND pd.category_id = 'director'
JOIN principals pa ON pd.title_id = pa.title_id
JOIN names a ON pa.name_id = a.name_id AND pa.category_id IN ('actor', 'actress')
JOIN titles t ON pd.title_id = t.title_id
WHERE t.title_type = 'movie'
  AND t.num_votes > 5000
  AND t.average_rating IS NOT NULL
GROUP BY d.name, a.name
HAVING COUNT(*) >= 3 AND AVG(t.average_rating) >= 7.5
ORDER BY avg_rating DESC
```
