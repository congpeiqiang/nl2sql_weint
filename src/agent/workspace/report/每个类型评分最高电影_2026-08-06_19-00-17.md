## 3. 生成 SQL

```sql
SELECT
    g.genre_name AS genre,
    t.primary_title AS movie_title,
    t.average_rating AS rating
FROM (
    SELECT
        genre_id,
        title_id,
        average_rating,
        ROW_NUMBER() OVER (PARTITION BY genre_id ORDER BY average_rating DESC) AS rn
    FROM titles
    WHERE title_type = 'movie'
      AND num_votes > 10000
) t
JOIN genres g ON t.genre_id = g.genre_id
WHERE t.rn = 1
ORDER BY t.average_rating DESC;
```
