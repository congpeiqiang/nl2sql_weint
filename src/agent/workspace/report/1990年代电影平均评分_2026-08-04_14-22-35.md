# 1990年代（1990-1999）电影平均评分

> 生成时间：2026-08-04 14:22:35
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本次查询旨在统计 IMDb 数据库中 **1990 年代（1990-1999）** 所有电影作品的平均评分，仅统计 `title_type = 'movie'` 的记录，排除年份或评分为 NULL 的数据。

## 2. 核心数据

| 指标 | 值 |
|------|------|
| **时间范围** | 1990 - 1999 |
| **数据类型** | 电影（movie） |
| **平均评分** | **6.15** |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year >= 1990
  AND t.start_year <= 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
```

## 4. 分析解读

- **平均评分 6.15**（满分 10 分）：1990 年代电影整体评分处于中等偏上水平，说明该年代的电影质量整体较好。
- 1990 年代是电影史上的黄金时期之一，诞生了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等），6.15 的平均分反映了大量电影参与评分后的综合结果。
- 评分采用 IMDb 加权平均算法，并非简单算术平均，因此更能反映观众的真实评价。
