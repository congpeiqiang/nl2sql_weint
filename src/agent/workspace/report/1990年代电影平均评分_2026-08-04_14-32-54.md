# 1990年代（1990-1999）电影平均评分分析

> 生成时间：2026-08-04 14:32:54
> 数据来源：IMDb 数据库（titles 表）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）上映电影的平均评分，数据来源于 IMDb 数据库中的 `titles` 表，筛选条件为 `title_type = 'movie'` 且 `start_year BETWEEN 1990 AND 1999`。

## 2. 核心数据

| 指标 | 结果 |
|------|------|
| **时间范围** | 1990 - 1999 年 |
| **数据类型** | 电影（movie） |
| **平均评分** | **6.15**（满分 10 分） |

## 3. 生成 SQL

```sql
SELECT AVG(t.average_rating) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.average_rating IS NOT NULL
```

## 5. 分析解读

- **整体评分水平**：1990 年代电影平均评分为 **6.15 分**，处于中等偏上水平（满分 10 分），表明该年代电影整体质量较为稳定。
- **年代背景**：1990 年代是电影工业快速发展的重要时期，涌现了大量经典作品（如《肖申克的救赎》《阿甘正传》《泰坦尼克号》等），但也有大量中小成本影片拉低了整体均值。
- **评分分布特征**：平均评分 6.15 说明大部分电影集中在中等评分区间，高分（8+）和低分（3-）的极端作品占比较小。
