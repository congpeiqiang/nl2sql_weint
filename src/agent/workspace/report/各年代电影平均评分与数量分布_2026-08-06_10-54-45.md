# 各年代电影平均评分与数量分布报告

> 生成时间：2026-08-06_10-54-45
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 IMDb 数据库中每个年代（decade）电影的平均评分和电影数量，用于分析电影产业在不同年代的发展规模与质量变化趋势。数据仅统计 `title_type = 'movie'` 的长片电影，并按 `FLOOR(start_year / 10) * 10` 规则将年份归入对应年代。

## 3. 生成 SQL

```sql
SELECT FLOOR(t.start_year / 10) * 10 AS decade,
       ROUND(AVG(t.average_rating), 2) AS avg_rating,
       COUNT(*) AS movie_count
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year IS NOT NULL
GROUP BY FLOOR(t.start_year / 10) * 10
ORDER BY decade ASC
```

## 4. 分析解读

### 4.1 电影数量趋势
- **早期（1890-1940）**：电影数量较少，处于产业萌芽期，1940 年代因战争影响数量回落至 1,392 部。
- **中期（1950-1990）**：电影产业稳步发展，数量稳定在 4,000-11,000 部区间。
- **爆发期（2000 至今）**：2000 年代达 41,878 部，2010 年代飙升至 136,906 部，2020 年代达 130,462 部，呈现指数级增长，反映数字电影制作与流媒体平台的普及。

### 4.2 平均评分趋势
- 平均评分整体在 **5.5-6.4** 之间波动，相对稳定。
- **1960 年代评分最高（6.39）**，1950 年代（6.37）紧随其后，被视为电影艺术的黄金时期。
- 1970-1980 年代评分略有回落（5.87 / 5.94），可能与商业大片兴起有关。
- 2000 年代后评分稳定在 6.2-6.3 区间，说明虽然产量激增，但整体质量保持平稳。

### 4.3 综合观察
- 电影产量与平均评分**无显著正相关**：产量最高的 2010 年代（136,906 部）评分（6.20）并非最高。
- 早期样本量过小（1890 年代仅 1 部），评分参考意义有限。
