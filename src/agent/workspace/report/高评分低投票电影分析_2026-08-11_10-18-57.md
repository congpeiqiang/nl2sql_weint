## 1. 概述

## 3. 生成 SQL

```sql
SELECT t.primary_title AS movie_title, t.average_rating, t.num_votes
FROM titles t
WHERE t.title_type = 'movie'
  AND t.average_rating >= 8.5
  AND t.num_votes < 5000
ORDER BY t.average_rating DESC
```

**说明：**
- `title_type = 'movie'`：过滤出真正的电影
- `average_rating >= 8.5`：评分不低于 8.5
- `num_votes < 5000`：投票数少于 5000
- `ORDER BY average_rating DESC`：按评分降序排列
- 通过 `run_sql` 的 limit 参数控制返回行数（SQL 中不写 LIMIT）

## 4. 分析解读

- **"宝藏片"特征**：这些电影评分极高（8.5~10.0），但投票数极少（多为个位数到百位数），属于被忽视的小众/冷门好片。
- **评分可信度**：由于投票数极低（投票数 < 1000 属于低可信度区间），其评分可信度相对较低。例如评分 10.0 的电影往往只有 5~14 票，样本量过小。
- **数据分布**：从散点图可见，评分越高的电影投票数往往越少，呈现明显的反比关系——高评分多来自极少数观众的偏好。

> 💡 如需更可靠的排名，可考虑增加 `num_votes > 1000` 过滤条件，以排除低可信度样本。
