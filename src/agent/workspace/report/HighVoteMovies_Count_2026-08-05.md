# 投票数超过 100 万的电影数量分析报告

> 生成时间：2026-08-05 15:38:16
> 数据来源：imdb 数据库（titles 表）

## 1. 概述

本报告统计了 IMDb 数据库中**投票数（num_votes）超过 100 万**的电影数量。该指标反映了电影在观众中的关注度和影响力——投票数超过 100 万意味着该电影获得了极其广泛的观众参与，属于高热度、高影响力的头部作品。

## 2. 核心数据

| 指标 | 数值 |
|------|------|
| 投票数超过 100 万的电影数量 | **22 部** |

## 3. 生成 SQL

```sql
SELECT COUNT(*) AS movie_count
FROM titles
WHERE title_type = 'movie' AND num_votes > 1000000
```

**关键业务规则：**
- **"电影"** 定义为 `title_type = 'movie'`（titles 表包含 9 种作品类型，需过滤）
- **"投票数超过 100 万"** 对应过滤条件 `num_votes > 1000000`

## 4. 分析解读

- **数量规模**：在 IMDb 庞大的电影库中，仅有 **22 部**电影投票数超过 100 万，占比极低，属于金字塔顶端的"现象级"作品。
- **业务含义**：投票数超过 100 万意味着该电影获得了海量观众的评分参与，通常对应全球范围内的高知名度、高票房或高口碑作品（如经典大片、现象级系列电影等）。
- **数据价值**：这 22 部电影可作为"高影响力电影"的基准样本，用于后续分析其题材、年份、评分等特征，洞察高热度电影的共性规律。
