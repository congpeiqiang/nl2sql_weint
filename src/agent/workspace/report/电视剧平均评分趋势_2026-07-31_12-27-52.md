## 1. 概述

本报告统计了 **2000 年到 2023 年** 每年电视剧（`title_type = 'tvSeries'`）的平均评分，按年份升序排列，用于观察电视剧整体评分水平随时间的变化趋势。

## 4. 生成SQL

```sql
SELECT
    start_year AS year,
    ROUND(AVG(average_rating), 2) AS avg_rating
FROM titles
WHERE title_type = 'tvSeries'
  AND start_year BETWEEN 2000 AND 2023
  AND start_year IS NOT NULL
  AND average_rating IS NOT NULL
GROUP BY start_year
ORDER BY start_year ASC;
```

## 5. 分析解读

- **整体趋势**：电视剧平均评分整体呈**上升趋势**，从 2000 年的 6.59 逐步提升到 2019 年的峰值 **6.86**。
- **低谷期**：2001 年（6.36）、2004 年（6.37）、2005 年（6.37）为 24 年中的最低点。
- **快速增长期**：2008 年（6.55）到 2012 年（6.81）之间评分提升明显，进入 6.8 区间。
- **稳定期**：2014 年之后基本稳定在 6.8 左右，2019 年达到峰值 6.86，2021 年小幅回落至 6.72 后回升至 6.83。

## 6. 附录

- 数据来源：`titles` 表，筛选 `title_type = 'tvSeries'`
- 时间范围：`start_year` 在 2000 到 2023 之间
- 指标：`AVG(average_rating)` 每年电视剧的平均评分（保留两位小数）
- 已排除 `start_year` 和 `average_rating` 为 NULL 的记录
