# 1990年代电影平均评分分析

> 生成时间：2026-08-04 11:39:06
> 数据来源：IMDb 数据库（imdb）

## 1. 概述

本报告统计了 1990 年代（1990-1999 年）IMDb 数据库中电影（title_type = 'movie'）按年份分组的平均评分（average_rating），分析十年间评分变化趋势。

## 2. 核心数据

| 年份 | 平均评分 |
|:----:|:-------:|
| 1990 | 5.78 |
| 1991 | 6.15 |
| 1992 | 6.13 |
| 1993 | 6.28 |
| 1994 | 6.15 |
| 1995 | 6.12 |
| 1996 | 6.42 |
| 1997 | 6.31 |
| 1998 | 6.13 |
| 1999 | 6.22 |

![1990年代电影平均评分趋势](./平均评分_20260804_113908.svg)

## 3. 生成SQL

```sql
SELECT
  t.start_year AS year,
  ROUND(AVG(t.average_rating), 2) AS avg_rating
FROM titles t
WHERE t.title_type = 'movie'
  AND t.start_year BETWEEN 1990 AND 1999
  AND t.start_year IS NOT NULL
  AND t.average_rating IS NOT NULL
GROUP BY t.start_year
ORDER BY t.start_year ASC
```

## 4. 分析解读

### 关键发现

- **最高年份**：1996 年，平均评分 **6.42**，为十年之最
- **最低年份**：1990 年，平均评分 **5.78**，显著低于其他年份
- **十年均值**：约 **6.17**，整体处于中等偏上水平

### 趋势分析

1. **快速回升期（1990-1993）**：从 1990 年的低谷 5.78 快速攀升至 1993 年的 6.28，涨幅达 0.50 分
2. **平稳波动期（1993-1995）**：评分在 6.12-6.28 之间小幅波动，表现稳定
3. **峰值期（1996-1997）**：1996 年达到十年最高 6.42，1997 年维持在 6.31 的高位
4. **回落期（1998-1999）**：评分回落至 6.13-6.22，但仍高于 1990 年水平

### 整体判断

1990 年代电影平均评分整体呈**先升后稳**的趋势，1996 年前后是电影质量的黄金期。1990 年的低分可能与当年电影产量较少、样本偏差有关。
