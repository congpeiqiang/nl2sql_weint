## 3. 生成 SQL

```sql
SELECT AVG(average_rating) AS avg_rating
FROM titles
WHERE title_type = 'movie'
  AND start_year BETWEEN 1990 AND 1999
  AND average_rating IS NOT NULL
```

### SQL 说明

- **`title_type = 'movie'`**：仅统计电影，排除电视剧、短片、游戏等其他作品类型
- **`start_year BETWEEN 1990 AND 1999`**：限定 1990 年代上映的作品
- **`average_rating IS NOT NULL`**：排除无评分的记录
- **`AVG(average_rating)`**：计算平均评分

## 4. 分析解读

1990 年代电影的平均评分为 **6.15 分**（满分 10 分），处于中等偏上水平。这一结果反映了 1990 年代作为电影黄金时代的整体质量表现：

- **评分基准**：IMDb 评分体系中，6 分以上通常被认为是"值得观看"的作品，6.15 的平均分说明 1990 年代电影整体质量较为稳定。
- **时代背景**：1990 年代是好莱坞电影工业高速发展的时期，涌现了大量经典作品（如《泰坦尼克号》《阿甘正传》《辛德勒的名单》等），同时也包含大量商业片和低成本影片，拉低了整体平均值。
- **数据特征**：该平均值涵盖了所有 1990 年代上映的电影，包括大量评分较低的小众或商业作品，因此整体均值略低于"经典电影"的评分水平。
