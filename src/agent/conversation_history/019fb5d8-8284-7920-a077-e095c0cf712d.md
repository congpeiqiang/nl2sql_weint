   196	## 图表标签截断解决方案
   197	
   198	### 问题
   199	水平柱状图（BarChart, orientation="horizontal"）的 Y 轴标签（表名）如果过长，会被容器裁剪。
   200	
   201	### 根本原因
   202	Semiotic 的 `margin.left` 默认值较小（约 70px），而长表名（如 `names_knownfortitles`）需要 150px+ 才能完整显示。
   203	
   204	### 推荐方案：动态边距计算
   205	
   206	渲染水平柱状图前，按以下公式计算 `margin.left`：
   207	
   208	```
   209	最长标签字符数 × 7.5 + 20 = margin.left
   210	```
   211	
   212	**经验值对照表：**
   213	
   214	| 最长标签长度 | margin.left | 画布宽度 |
   215	|:---:|:---:|:---:|
   216	| ≤ 10 字符 | 100 | 600 |
   217	| 11~15 字符 | 150 | 700 |
   218	| 16~20 字符 | 200 | 800 |
   219	| 21~25 字符 | 250 | 900 |
   220	| &gt; 25 字符 | 300 | 1000 |
   221	
   222	### 执行规范
   223	
   224	每次渲染水平柱状图时，**必须**：
   225	
   226	1. 遍历数据，找出 `categoryAccessor` 对应的最长字符串
   227	2. 按上表选择对应的 `margin.left` 和 `width`
   228	3. 在 props 中显式设置 `margin.left` 和 `width`
   229	
   230	### 示例
   231	
   232	```javascript
   233	// 数据中 categoryAccessor="name"，最长 name 为 "names_knownfortitles"（19字符）
   234	// → margin.left=200, width=800
   235	
   236	renderChart({
   237	  component: "BarChart",
   238	  props: {
   239	    data: [...],
   240	    categoryAccessor: "name",
   241	    valueAccessor: "value",
   242	    orientation: "horizontal",
   243	    margin: { left: 200, bottom: 40 },
   244	    width: 800,
   245	    height: 450
   246	  }
   247	})
   248	```
   249	
   250	### 备选方案
   251
