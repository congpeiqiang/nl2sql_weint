**只想看一件事**：报告 §1 的「如果只做三件事」——`BG_JOB_ISOLATED_LOOPS=true`（10 分钟）、收回 2026 端口 + 关 nginx `/report/`（15 分钟）、发布会话归属隔离（半天）。

## 三句话结论

1. **并发天花板是个位数（约 3~4 人）**，不是几十。单进程 × 全局 10 个 run 槽位，而**一次问数就吃掉约 3 个槽**（主 run + 子 run + 续跑主 run），单会话还允许 5 个并发问数。
2. **10 个 run 共用同一个事件循环**（`BG_JOB_ISOLATED_LOOPS` 未开），加上 `LANGGRAPH_ALLOW_BLOCKING=true` 关掉了阻塞检测，而 async 路径里有大量同步阻塞调用（wren CLI 最长 600s、每次工具调用新建 MCP 子进程…）→ **一个用户的慢请求会拖死其他所有用户**。
3. **两处可省略请求头即可绕过的认证**（`X-Forwarded-For` / `Cookie`），绕过后的 `internal` 身份能读写删**所有用户**的会话；另有 nginx `/report/` 免登录直出全站报告。
