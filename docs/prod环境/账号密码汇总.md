## 12. 已知事项

1. **docker-compose v1**：生产用 `docker-compose`（不是 `docker compose`），重建容器需 stop/rm/up 三步（v1 的 `up -d` 改配置会报 `ContainerConfig KeyError`）。
2. **前端改动要重构建**：前端源码含 DLP 加密文件，只能在本机解密 + 构建，再传产物到 64 上 build 镜像。后端改动只需重新打包上传。
3. **首次配模型后必须重启后端**：模型是导入时解析的。
4. **报告目录**：`http://192.168.25.64:8080/report/` 由 nginx 直接静态服务 workspace 卷的 `report/` 目录。聊天里 agent 回显的路径是 `D:/workspace1/report/xxx.html`（开发机路径），替换为 `http://192.168.25.64:8080/report/` 即可访问。
5. **tar 解压不删文件**：替换代码前必须先清空目标目录（2026-09-20 事故根因）。发布脚本已处理此问题。
