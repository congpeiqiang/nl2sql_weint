## 9. 已落地应用

### 落地企业：无锡奥特维科技股份有限公司（三期机加车间 MES 系统）

奥特维是光伏智能装备领域科创板上市企业。NL2SQL 系统与三期机加车间 MES 系统同步开发、同步上线，作为 MES 的原生数据查询模块嵌入，提供自然语言数据交互能力。

### 具体场景

车间此前依靠工人手写工单流转，数据零散记录在纸质单据上，管理人员难以实时掌握生产状况。此次 MES 系统从零建设，NL2SQL 模块同步设计、同步上线——数据库建表与语义建模并行推进，MES 上线即具备自然语言查询能力。班组长无需 SQL 基础，直接用自然语言完成多表关联查询和指标计算，实现从"翻纸质工单"到"开口问数据"的跨越。

### 实施过程（约 3 个月，与 MES 并行推进）

- **需求调研与数据梳理（第 1-2 周）**：深入车间调研手写工单的数据流转路径，盘点核心数据实体，整理字段定义和业务规则，形成数据字典初稿。
- **数据库设计与语义建模（第 3-6 周）**：MES 团队输出 DDL 的同时，NL2SQL 团队使用 WrenAI CLI 自动生成 MDL 语义模型，业务专家补充字段别名和计算公式。收集车间高频查询需求，整理典型 NL→SQL 对导入历史查询库。
- **联调部署与知识注入（第 7-10 周）**：在内网完成私有化部署，接入 MES 数据库。编写业务知识库，注入车间特有的业务规则和常见陷阱提示，完成端到端联调。
- **试用迭代与调优（第 11-12 周）**：邀请班组长进行两周试用，每日通过分类学体系复盘查询错误，针对性补充业务知识库，迭代提升准确率。
- **正式上线与培训（第 13 周）**：与 MES 同步上线，编写填空式查询话术模板，对车间管理人员集中培训。

### 创新方法

1. **查询—图表—报告全链路嵌入 MES**：打破"先有系统、后加 AI"的常规模式，数据库设计与语义建模同步进行。系统不仅支持自然语言查询，还能自动推荐并渲染可视化图表，一键生成结构化 Markdown 分析报告，覆盖从提问到决策的全流程。
2. **领域知识闭环迭代**：利用分类学纠错体系，每日归类查询错误并针对性补充业务知识和规则。
3. **话术模板降门槛**：编写填空式查询模板，一线人员即填即用，无需学习任何语法。
4. **语义层先行**：先完成 WrenAI MDL 业务建模，将物理表映射为业务概念，确保系统理解业务语言。
