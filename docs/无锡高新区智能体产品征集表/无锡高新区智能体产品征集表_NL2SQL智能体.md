### 智能体简介

> 300字以内产品概况

NL2SQL多智能体数据查询与分析系统是一款基于**SQL-of-Thought**论文方法论的企业级自然语言转SQL智能体产品。系统采用**DeepAgents多智能体框架** + **LangGraph编排运行时**构建，支持DeepSeek、通义千问等主流大模型。

系统由**主编排智能体**和**NL2SQL子智能体**协作完成全流程：用户输入自然语言查询后，系统自动经历业务知识加载、Schema语义链接、子问题分解、查询计划推理、SQL生成与验证、性能优化审计、分类学纠错等7步结构化推理管线，最终输出可执行SQL并返回查询结果。在此基础上，主智能体自动推荐并渲染数据可视化图表（支持ECharts/Semiotic双引擎），并生成结构化Markdown分析报告。

系统通过**WrenAI语义层引擎**（18个MCP工具）实现MDL建模与语义检索，内置**11项技能**按需加载，支持MySQL/SQLite等10种数据库引擎。采用私有化部署，支持异步子智能体执行与实时进度追踪，适用于企业数据分析、BI报表生成、业务指标查询等场景。

## 二、核心技术参数（必填）

### 1. 可接入模型

- DeepSeek（deepseek-v4-flash，通过 langchain-deepseek 集成）
- 通义千问（qwen3.7-max，通过 OpenAI-compatible 接口集成）
- 支持任意 OpenAI-compatible API 的大模型（自动检测供应商并适配）

### 2. 智能体框架/平台

- **DeepAgents** ≥ 0.6.12（Harness Engineering 智能体架构，提供文件系统后端、技能系统、异步子智能体管理等核心能力）
- **LangGraph API** ≥ 0.11.1（编排运行时，提供线程管理、状态检查点、SSE 流式输出）
- **LangChain MCP Adapters**（MCP 协议适配层，连接 WrenAI 语义层引擎和图表渲染引擎）
- **FastMCP** ≥ 3.4.4（MCP 服务端框架，用于数据库 MCP 服务器）

### 3. 单/多智能体

☑ **多智能体协作（Multi-Agent）**

**协作机制：** 采用**主编排智能体 + 异步子智能体**的委派协作模式。主智能体负责意图识别与任务路由，将数据查询任务通过 `start_async_task` 异步委派给 NL2SQL 子智能体。子智能体在独立线程中执行 SQL-of-Thought 7 步管线，通过 `write_todos` 实时更新进度。后台同步进程将子智能体进度合并写入主智能体状态，前端实时展示执行步骤与耗时。子智能体完成后，主智能体自动继续执行图表渲染和报告生成，实现全链路自动化。

### 4. 知识库/RAG

☑ **使用**

- **知识库类型：** 基于 WrenAI 语义层的结构化知识库（MDL 模型定义 + 业务规则文件 + 历史查询对），非传统向量数据库
- **语义检索工具：** `get_context(question)` — 基于语义相似度检索相关 Schema 片段；`recall_queries(question)` — 检索相似历史 NL→SQL 查询对
- **技能系统：** 11 项 SKILL.md 技能文件按需加载（progressive disclosure），覆盖 SQL-of-Thought 全管线
- **知识加载策略：** Step 1（Knowledge Loader）从知识库提取业务规则、指标定义、字段映射、历史问答、常见陷阱，输出过滤后的 `knowledge.json`
- **更新频率：** 知识库文件随业务需求手动更新，技能文件由开发者维护

### 5. 部署方式

☑ **私有化部署**

- 后端：Python ≥ 3.13，通过 `langgraph_api` (uvicorn) 在本地服务器运行，端口 2026
- 前端：Next.js + TypeScript + Tailwind CSS，独立部署
- 数据库：SQLite 检查点持久化 + MySQL 业务数据库
- 支持多数据库同时接入（`.env` 配置 `_N` 后缀模式）

## 三、功能特性描述（必填）

### 6. 可完成的任务流程

1. **自然语言意图识别与路由**：主智能体自动识别用户意图（数据查询/图表可视化/报告生成/通用问答），路由到对应处理链路
2. **SQL-of-Thought 结构化推理管线**：7 步管线（知识加载 → Schema 语义链接 → 子问题分解 → 查询计划推理 → SQL 生成验证 → 性能优化审计 → 分类学纠错），每步独立技能驱动，支持 3 种执行策略（标准/快速通道/Cube 指标通道）
3. **异步子智能体执行与实时进度追踪**：NL2SQL 子智能体在独立线程中异步执行，后台同步进程每 0.5s 将进度合并写入主状态，前端实时展示每步执行状态与耗时
4. **WrenAI 语义层查询**：通过 18 个 MCP 工具接入 WrenAI 语义层引擎，实现 MDL 建模、语义检索、Cube 指标查询、SQL 方言转换
5. **分类学引导的自动纠错**：9 大类 31 小类错误分类体系，最多 3 轮自动纠错（错误分类 → CoT 诊断 → 纠错计划 → SQL 修复）
6. **数据可视化图表自动推荐与渲染**：基于查询结果自动推荐最佳图表类型，支持 ECharts/Semiotic 双引擎渲染（SVG/HTML 输出）
7. **结构化 Markdown 分析报告生成**：支持数据查询报告、分析报告、图表报告 3 种模板，5 段式标准结构，自动保存至报告目录
8. **多数据库同时接入**：支持 MySQL/SQLite/PostgreSQL/BigQuery/Snowflake 等 10 种数据库引擎，前端下拉框切换数据源
9. **SQL 性能审计**：执行前自动检查 10 条性能规则（SELECT *、无 LIMIT、笛卡尔积、函数包裹列、NOT IN 等），输出优化建议

### 7. 核心优势

- **SQL-of-Thought 方法论**：基于 2025 年最新学术论文，7 步结构化推理显著提升复杂 SQL 准确率，Query Plan 阶段严禁输出 SQL 避免提前锚定
- **三策略智能路由**：复杂查询走标准管线（7 步），简单查询走快速通道（3 步），预定义指标走 Cube 通道（直查），兼顾准确率与响应速度
- **10 条性能规则自动审计**：SQL 执行前自动扫描性能隐患，避免慢查询
- **9 大类 31 小类错误分类学纠错**：结构化错误诊断远优于试错式修复，最多 3 轮自动纠错
- **实时进度可视化**：异步子智能体执行过程中，前端实时展示每步状态与耗时，用户体验透明可控
- **18 个 WrenAI MCP 工具深度集成**：语义层查询、Schema 发现、Cube 指标、历史查询召回，一站式数据查询能力
- **双图表引擎可切换**：ECharts/Semiotic 通过环境变量一键切换，适配不同可视化需求
- **多模型自动适配**：DeepSeek/通义千问/OpenAI-compatible 模型自动检测供应商并适配

### 8. 适配场景

- **企业数据分析报告生成**：自然语言提问 → SQL 查询 → 图表渲染 → Markdown 分析报告，全链路自动化
- **BI 报表与仪表盘**：基于 Cube 指标通道快速查询预定义业务指标，渲染可视化图表
- **业务指标查询**：通过 WrenAI 语义层直接查询业务指标（GMV、DAU、转化率等），无需手写 SQL
- **数据库探索与 Schema 理解**：自动发现表结构、列关系、语义上下文，辅助数据工程师理解数据资产
- **SQL 性能优化审计**：对已有 SQL 进行 10 条规则审计，输出优化建议
- **历史查询复用**：语义检索相似历史 NL→SQL 查询对，提升重复查询效率

### 9. 已落地应用

> 800字左右，图文并茂

**落地公司：** 【请填写落地公司名称】

**具体场景：** 企业级多数据库自然语言查询与分析平台。用户通过对话界面输入自然语言问题（如"查询1990年代电影的平均评分"），系统自动完成从知识加载、Schema理解、SQL生成到图表渲染和报告导出的全流程。

**实施过程：**

1. **语义层建模阶段**：基于 WrenAI 引擎构建 MDL（Model Definition Language）语义模型，将物理数据库表结构映射为业务语义层，定义指标、维度、关系等元数据，使智能体能够理解业务上下文而非仅操作物理表。

2. **知识体系构建阶段**：建立结构化知识库，包含业务规则文档（`rules/*.md`）、指标定义、字段映射关系、历史优质 NL→SQL 查询对、常见陷阱等。NL2SQL 子智能体在 Step 1 通过 Knowledge Loader 技能自动加载并过滤相关知识。

3. **SQL-of-Thought 管线部署**：实现 7 步结构化推理管线，每步由独立 SKILL.md 技能驱动。通过 3 策略路由（标准/快速/Cube）智能选择执行路径。分类学纠错机制（9 大类 31 小类）确保 SQL 质量。

4. **多智能体协作架构**：主智能体负责意图路由与全链路编排，NL2SQL 子智能体在独立线程异步执行查询管线。后台同步进程实时将子智能体进度（步骤状态 + 耗时）合并到主状态，前端进度条实时更新。

5. **全链路自动化**：查询完成后，主智能体自动推荐图表类型 → 渲染可视化图表（ECharts/Semiotic 双引擎）→ 生成结构化 Markdown 分析报告，用户无需手动操作。

**创新方法：**

- **SQL-of-Thought 论文方法论工程化落地**：将学术界最新研究成果转化为生产级系统，7 步管线 + 3 策略路由 + 分类学纠错构成完整方法论闭环。
- **WrenAI 语义层 + MCP 协议深度集成**：18 个 MCP 工具覆盖语义查询全能力，通过 MCP 标准协议实现智能体与语义层引擎的松耦合集成。
- **异步子智能体 + 实时进度同步**：后台同步进程以 0.5s 频率将子智能体进度合并到主状态，前端通过定时轮询实时展示，兼顾非阻塞架构与用户体验。
- **技能系统 Progressive Disclosure**：11 项技能按需加载，仅在系统提示词中注入技能名称和描述，智能体按需读取完整技能文件，避免上下文膨胀。
