# 智能数据助手 — 功能使用介绍（客户版）

> 用途：面向客户介绍"系统能做什么、怎么用"
> 版本：v2.1（2026-08-12）
> 维护说明：持续更新，新增功能请按章节补充并更新版本号与日期

---

## 一、一句话认识它

**智能数据助手 = 会查数据库的 AI 助手。**

您用中文提问，它自动去数据库里把数据找出来，帮您算好、画成图表、写成报告。
您不需要懂 SQL、不需要懂数据库，就像和同事聊天一样。

---

## 二、能做什么（功能介绍）

### 2.1 用大白话查数据

直接输入您想知道的问题，比如：

- "查询1990年代电影的平均评分"
- "票房最高的前10部电影"
- "每个月销售额是多少，趋势怎么样"
- "哪个类型的电影数量最多"

系统会自动理解您的意思，去数据库查询，返回结果。

### 2.2 自动画图表

查询结果会自动配上合适的图表：

- 柱状图、折线图、饼图、散点图等
- 图表是**可交互的**：鼠标悬停看具体数值、可缩放、可切换显示项
- 图表直接显示在对话里，一目了然

### 2.3 自动生成报告

查询 + 图表 + 分析解读，系统自动整合成一份 **Markdown 报告**，方便保存和分享。

### 2.4 多数据库查询

系统可连接多个数据库（如 aix_report、Chinook、imdb、clickhouse 等，支持 MySQL / ClickHouse / PostgreSQL）。
切换数据源后提问，即针对该库查询；数据库列表由管理员在「数据库配置管理」中维护（见 3.6）。

### 2.5 聊天式多轮对话

一个对话里可以连续问多个问题，系统会记住上下文。

## 三、怎么用（操作指南）

### 3.1 开始使用

1. 打开系统网页（浏览器访问）
2. 首次使用会弹出配置窗口，填写 **部署地址** 和 **助手 ID**（由管理员提供）
3. 进入对话界面，在底部输入框提问即可

### 3.2 提问小技巧

| 好的问法 | 说明 |
|---------|------|
| "查询2020年以来电影数量" | 明确"查询""数量"等词，系统更易识别 |
| "对比1990和2000年代平均评分" | 带对比需求 |
| "按年份统计票房并画趋势图" | 明确提出要图 |

> 提示：提问中带上 **查询、统计、多少、排名、平均、趋势、分析、数量** 等词，系统会优先按数据查询处理。

### 3.3 等待过程中的进度条

提问后，对话上方会出现进度条，您可以实时看到：

- 📋 **当前问题**（您问的是什么）
- 🔍 **查询执行步骤**（系统正在做什么，每步耗时多少）
- **图表/报告** 进度

查询进行中，建议**等待本次查询完成**再问下一个查询，结果会更清晰。

### 3.4 查看图表和报告

- 图表直接显示在对话消息里，可交互
- 报告文件保存在系统工作区，可通过文件面板查看
- 生成的报告和图表也可由管理员在服务器目录中找到（`.html` / `.md` 文件）

### 3.5 切换数据库

在对话界面顶部的 **数据库：** 下拉框选择要查询的数据库，切换后提问即针对该库。

- 下拉框中每项标注了类型和通道：**直连**（普通数据库连接）/ **语义层**（已配置 Wren 语义建模）
- 选择会被记住（下次打开自动沿用），每次提问都按当前选中的库执行
- **切换后立即生效，无需重启系统**：在已配置的库之间切换，直接提问即可
- 例外（需管理员重启后端）：某库**首次配置语义层**、或**修改了某库的连接参数**后（见 3.6）

### 3.6 数据库配置管理（管理员）

点击数据库下拉框旁的 **⚙️ 按钮**，打开「数据库配置管理」窗口。在此维护系统能连接哪些数据库：

**查看已配置的数据库**：列表显示每个库的名称、类型、Host、库名、通道（语义层/直连），可编辑或删除。

**新增 / 编辑数据库**，填写：
- **名称（db_name）**：给数据库起个名字（如"生产MySQL"），作为下拉框和提问时使用的标识
- **类型**：MySQL / ClickHouse / PostgreSQL
- **Host / Port**：数据库地址和端口
- **数据库名**：物理库名
- **用户名 / 密码**：登录凭据（密码加密存储在后端，编辑时留空表示保留原密码）
- **Wren 项目（语义层）**：可选。选中后该库走 Wren 语义层查询（工具名 `wrenai_<库名>_*`）；下拉项由系统自动扫描服务器工作区里已就绪的 Wren 项目得出，留空则走直连

**测试连接**：保存前可点「测试连接」，验证地址和凭据是否正确。

> 注意事项：
> - 连接信息只保存在后端，密码加密存储，前端不落库
> - 新增的**直连**库配置后立即可用，无需重启
> - 某库**首次配置 Wren 语义层**后，需管理员**重启后端**才生效（新语义层服务才会启动）
> - 修改了某个已连接库的 Host/密码等参数后，也需重启后端才生效

### 3.7 自定义查询关键词（可选）

点击输入框旁的 **齿轮按钮 ⚙️**，可自定义"哪些词会被当成数据查询"。一般用户无需修改，使用默认即可。

### 3.8 会话管理

- 左侧列表可查看历史对话
- 可新建对话、切换对话、删除对话
- 关闭网页后对话记录自动保留，下次打开可继续

## 四、常见问题

| 问题 | 说明 |
|------|------|
| 提问后没反应？ | 等待几秒，进度条会显示执行过程；复杂查询可能需要较长时间 |
| 查询进行中再提问被提示等待？ | 系统为保护结果清晰，建议等当前查询完成再问下一个 |
| 想画图但没出图？ | 提问时明确说"画图""图表""趋势图"等 |
| 换一个数据库？ | 在界面顶部"数据库："下拉框选择后再提问，切换立即生效 |
| 下拉框里没有想要的库？ | 该库未配置，需管理员在「数据库配置管理」中新增连接（见 3.6） |
| 配了语义层但提问仍报找不到库？ | 首次配置语义层后需重启后端才生效，请联系管理员 |
| 数据不对或看不懂？ | 可追问系统"请详细说明"，或换个说法重新提问 |
