# NL2SQL智能问数 预测\+归因能力升级 正式落地技术方案（适配现有代码库）

## 1\. 项目背景

现有智能问数系统基于NL2SQL实现，仅支持**历史数据自然语言查询**，不具备趋势预判、指标异动分析能力，无法满足业务“查数据、看趋势、找原因”的全链路分析需求。

本次升级基于现有 **D:\\code\_work\_space\\llm\\nl2sql** 代码库做**增量外挂式开发**，不改动原有NL2SQL核心逻辑、SQL生成、权限体系、接口返回结构，新增 **时序预测 \+ 指标智能归因** 能力，支持混合式自然语言问答。

升级后系统可回答四类用户问题：

1. 普通查询：近半年门店营收数据

2. 趋势预测：未来3个月营收走势预测

3. 异动归因：上月发电量下滑原因分析

4. 混合分析：预测未来2个月营收，并分析核心影响因素

## 2\. 核心设计原则（关键约束）

为保证系统稳定、无回归风险，本次升级严格遵守以下原则：

- **零侵入改造**：原有nl2sql核心、LLM调用、数据库查询、鉴权、返回结构完全不动

- **全复用能力**：复用现有LLM客户端、数据查询链路、权限校验、数据口径

- **新老接口隔离**：新增独立对话接口承载预测/归因，老接口完全保留

- **降级容错优先**：解析失败、数据不足、模型异常均自动降级为普通查询

- **可解释无幻觉**：所有AI分析结果附带计算说明、置信度、风险提示

## 3\. 整体系统架构

### 3\.1 架构链路

用户提问 → 新增智能对话接口 → LLM意图解析 → 任务路由分发 → 复用NL2SQL取数 → 预测/归因引擎计算 → LLM结果组装 → 兼容式结果返回

### 3\.2 任务路由体系

|任务类型|识别规则|执行逻辑|
|---|---|---|
|query 普通查询|无预测、无归因语义|直接走原有NL2SQL链路，完全兼容旧逻辑|
|forecast 时序预测|含未来、预测、接下来、预估等|构造时序查询问句→NL2SQL取数→数据校验→Prophet预测|
|attribution 异动归因|含原因、涨跌、变化、影响因素等|构造本期/上期双查询→取对比数据→瀑布维度归因计算|
|forecast\_attribution 混合分析|同时包含预测\+分析原因|先归因挖掘核心因子→带入因子做增强预测→联动解读|

## 5\. 核心模块详细设计

### 5\.1 意图解析模块（task\_router）

基于现有LLM Client完成用户问句结构化解析，输出标准化任务参数，**解析失败自动降级为普通查询**，杜绝服务报错。

核心输出字段：任务类型、目标指标、时间范围、预测步长、时间粒度、拆解维度、过滤条件。

### 5\.2 任务调度模块（task\_dispatcher）

核心适配逻辑：**不调用底层NL2SQL函数参数，而是构造自然语言问句复用原有NL2SQL能力**，完美适配现有代码库。

- 预测任务：自动生成「按日/月统计某指标时序数据」查询语句

- 归因任务：自动生成「本期数据、上期同期数据」两条查询语句

- 混合任务：时序取数\+双期对比取数，一次会话复用数据

### 5\.3 时序预测引擎（forecast）

V1版本采用工业级稳定方案 **Prophet模型**，适配业务指标季节性、缺失值、波动场景。

前置强校验（不满足直接拒绝预测）：

- 数据点数：至少 12 个周期，否则样本不足

- 缺失率：不超过 30%，缺失过多结果不可靠

- 时间字段：必须存在且可排序

- 指标类型：必须为数值型

- 指标能力：MDL 元数据标记 `can_forecast = true`

预测输出结构：

```json
{
  "success": true,
  "history": [
    {"time": "2025-06", "value": 120},
    {"time": "2025-07", "value": 135}
  ],
  "forecast": [
    {"time": "2025-09", "value": 142, "lower": 120, "upper": 164},
    {"time": "2025-10", "value": 148, "lower": 124, "upper": 172}
  ],
  "horizon": 3,
  "granularity": "month",
  "note": "预测基于历史趋势生成，未考虑极端天气、突发故障等因素。"
}
```

异常处理：

- 数据不足 → 返回"历史数据不足，无法预测"

- 数据缺失严重 → 返回"数据缺失较多，预测结果不可靠"

- 模型拟合失败 → 返回"预测计算异常，已返回历史数据"

### 5\.4 归因引擎（attribution）

V1 采用**单维度瀑布归因**，先不做多维度交叉归因，降低 SQL 生成复杂度与口径错误风险。

### 归因输入要求

- 本期数据、上期同期数据

- 指标必须可加或可在维度上汇总

- 维度必须在元数据中配置为合法拆解维度

### 归因计算逻辑

```text
总变动 = 本期值 - 上期值
维度贡献 = 维度本期值 - 维度上期值
贡献率 = 维度贡献 / 总变动
```

### 归因输出示例

```json
{
  "metric": "发电量",
  "total_delta": -100,
  "contributions": [
    {"name": "辐照量下降", "delta": -70, "rate": 0.7},
    {"name": "停机时长增加", "delta": -25, "rate": 0.25},
    {"name": "其他因素", "delta": -5, "rate": 0.05}
  ],
  "note": "以上为维度贡献拆解结果，用于业务解释，不等同于严格因果关系。"
}
```

### 归因异常处理

|异常情况|处理方式|
|---|---|
|上期数据为空|返回"缺少对比周期数据，无法归因"|
|本期数据为空|返回"本期数据不足，无法归因"|
|总变动为 0|返回"指标无明显变化，归因结果参考意义有限"|
|维度不合法|返回"当前维度不支持归因拆解"|

### 5\.5 混合分析引擎（forecast\_attribution）

不是分别跑预测和归因，而是做联动：

```text
第一步：获取历史时序数据和维度对比数据
第二步：执行归因，找出 Top 影响因子
第三步：将 Top 因子作为辅助信息带入预测
第四步：生成"预测结果 + 影响因素解释"
```

输出必须明确区分：预测结果、归因结果、影响说明、风险提示。

### 5\.6 结果组装模块（result\_assembler）

将原始计算结果转换为用户可读内容，包括：自然语言结论、图表配置、风险提示、统计口径说明。

为兼容现有接口，新增分析结果放入 `extra` 扩展字段，原有 `sql`、`data` 字段保持不变。

```json
{
  "sql": "原有 SQL 保持不变",
  "data": "原有查询结果保持不变",
  "extra": {
    "task_type": "forecast_attribution",
    "forecast": {},
    "attribution": {},
    "chart_options": {},
    "explain": "未来3个月发电量整体呈上升趋势，主要受辐照量变化影响。",
    "risk_note": "本结果基于历史数据统计分析生成，仅作业务参考。"
  }
}
```

## 6\. 指标元数据配置方案

为避免所有指标都支持预测、归因，增加指标能力白名单，在 `config/meta_config.py` 中维护。

```python
METRIC_CAPABILITY = {
    "发电量": {
        "can_forecast": True,
        "can_attribution": True,
        "attribution_dimensions": ["辐照量", "停机时长", "地区"],
        "min_forecast_points": 12
    },
    "营收": {
        "can_forecast": True,
        "can_attribution": True,
        "attribution_dimensions": ["渠道", "地区", "产品"],
        "min_forecast_points": 12
    }
}
```

校验逻辑：

- 指标不在白名单 → 返回"指标未配置预测或归因能力"

- `can_forecast = false` → 返回"当前指标暂不支持预测"

- `can_attribution = false` → 返回"当前指标暂不支持归因"

## 8\. 异常与降级体系

|异常环节|异常情况|处理策略|
|---|---|---|
|意图解析|LLM 返回非法 JSON|降级为普通查询|
|意图解析|字段缺失|降级为普通查询|
|NL2SQL|返回空数据|返回"暂无对应数据"|
|NL2SQL|SQL 执行失败|返回查询失败提示|
|预测|数据点数不足|不执行预测，返回历史数据|
|预测|缺失率过高|不执行预测，返回提示|
|归因|上期数据缺失|跳过归因|
|归因|总变动等于 0|返回提示信息|
|模型计算|Prophet 拟合异常|关闭预测能力|
|混合分析|归因计算失败|降级为纯预测|

## 10\. 风险提示文案

### 预测提示

预测结果基于历史趋势和统计模型生成，仅作为业务参考，不代表真实未来结果。实际指标可能受天气、政策、市场、设备故障等因素影响发生偏差。

### 归因提示

归因结果为维度贡献统计拆解，仅用于业务分析，不等同于严格因果结论，存在未纳入统计的隐性影响因素。

### 混合分析提示

本分析结合历史时序预测与维度归因，预测模型参考历史影响因子，但无法覆盖全部不确定性因素，结论仅供业务决策参考。
