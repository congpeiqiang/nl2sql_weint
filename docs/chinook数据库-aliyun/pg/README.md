## 6. 相关文件（本工作区）

| 文件 | 说明 |
|------|------|
| `chinook数据库/pg/chinook_schema.sql` | MySQL DDL → PostgreSQL 转换后的建表脚本（11 表 + FK + 索引） |
| `chinook数据库/pg/chinook_data.sql` | MySQL 数据 → PostgreSQL 转换后的数据脚本（全量） |
| `chinook数据库/pg/setup_chinook.sh` | 建库建角色 + 导入脚本 |
| `chinook数据库/pg/config_chinook.sh` | 授权 + 远程访问配置 + 验证 |
| `chinook数据库/pg/diag.sql` / `verify_advanced.sql` | 诊断/高级验证查询 |
| `scripts/convert_chinook.py` | MySQL → PG 自动转换脚本（可复现） |

> 转换要点：`AUTO_INCREMENT` → `GENERATED BY DEFAULT AS IDENTITY`；反引号去除；
> `N'...'` → `'...'`；日期 `2021/1/1` → `2021-01-01`；`datetime` → `TIMESTAMP`；
> FK/索引改为建表后统一 `ALTER TABLE` + `CREATE INDEX`（避免前向引用）。

## 7. 安全提示
