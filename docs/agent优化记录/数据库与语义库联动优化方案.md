# 数据库与语义库联动优化方案

> 创建时间：2026-08-24
> 状态：待实施

---

## 一、核心逻辑

```
数据库（基础）
  └── 语义库（知识层，1:1 绑定）
        ├── 模型（表结构映射）
        ├── 业务知识（词汇/指标/规则）
        └── MDL（构建产物）
```

有了数据库才能创建语义库，语义库是数据库的「知识层」。

---

## 二、两个入口

### 入口 1：从数据库卡片触发（新）

- 点击「✨ 创建语义库」→ 数据库自动选定
- 适合：刚添加数据库后立即建模

### 入口 2：从语义库面板创建（现有）

- 点击「+ 添加」→ 下拉选择数据库
- 适合：统一管理所有语义库

## 四、语义库面板改为概览模式

```
┌─ 语义库概览 ──────────────────────────────────────────┐
│  全部: 5 | 已构建: 3 | 需更新: 1                       │
│                                                        │
│  📦 imdb-semantic      → imdb (ClickHouse)    [管理]  │
│  📦 finance-semantic   → finance (MySQL)      [管理]  │

│  💡 创建语义库请前往对应数据库卡片，或点击 [+ 添加]    │

```

## 五、改动范围

| 改动 | 文件 | 工作量 |
|------|------|--------|
| 数据库卡片加「语义层」区域 | DbConfigDialog.tsx | 中 |
| 卡片内嵌「创建语义库」+ KnowledgeEditor | DbConfigDialog.tsx | 中 |
| 语义库面板加概览统计 | SemanticLibraryPanel.tsx | 小 |
| 删除数据库时联动提示 | DbConfigDialog.tsx | 小 |
