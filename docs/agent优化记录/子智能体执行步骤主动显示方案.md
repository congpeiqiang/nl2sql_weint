## 1. 问题分析

### 1.1 当前架构

```
Frontend (Next.js + useStream)              Backend (langgraph_api :2026)
───────────────────────────                 ──────────────────────────────
stream.messages ◄───── SSE ──────────────── chat_agent (主智能体)
stream.values.todos                            ├── start_async_task()
stream.isLoading                               │     └── 创建 thread + run ──→ nl2sql_agent (独立线程)
                                               │                                  ├── ProgressTrackerMiddleware
                                               │                                  ├── write_todos (每步完成后调用)
                                               │                                  └── 独立运行中...
                                               │
                                               ├── check_async_task(task_id) ← 仅当主Agent主动调用
                                               │     └── 返回: {steps, progress, current_step, ...}
                                               └── 继续其他工作...
```

### 1.2 核心瓶颈

| 问题 | 说明 |
|------|------|
| 子智能体运行在**独立线程** | nl2sql_agent 有自己的 thread_id，其 state 不在主智能体的 SSE 流中 |
| 进度数据**已有但不推送** | `check_progress.py` 已实现丰富的进度提取（steps, elapsed, current_step），但只在主 Agent 主动调用 `check_async_task` 时才触发 |
| 前端已有渲染基础 | `ToolCallBox` 支持 `artifact.subagent_type + steps` 渲染，`SubAgentIndicator` 已实现，但数据源不通 |

### 1.3 已有基础设施

**后端**（`src/agent/subagents/check_progress.py`）：
- `ProgressTrackerMiddleware`：在子智能体每次 LLM 调用后，将 `write_todos` 的 step_history 写入 `/tmp/nl2sql_progress/{thread_id}.json`
- `_extract_progress()`：从 thread messages + 本地进度文件提取结构化进度数据
- `check_async_task` 增强返回格式：


**前端**（`harness-deep-agents-ui`）：
- `SubAgentIndicator`：可折叠的子智能体卡片（检测 `tool name === "task"` 的调用）
- `ToolCallBox`：当 `artifact.subagent_type` + `artifact.steps` 存在时，渲染执行步骤追踪
- `TodoItem`：从 `stream.values.todos` 渲染任务进度
- LangGraph SDK `@langchain/langgraph-sdk ^1.0.3`：提供 `client.threads.joinStream()` API

## 3. 推荐方案：前端事件驱动订阅（方案 A）

### 3.1 核心思路

利用 LangGraph SDK 的 `client.threads.joinStream(threadId)` API，前端直接订阅子智能体线程的 SSE 流。子智能体每执行完一个节点（包括 `write_todos` 工具调用），LangGraph 自动推送 state 更新。

```
前端 (ChatInterface)
  │
  ├── useStream (主智能体 chat_agent 线程)
  │     └── 检测 start_async_task 的 ToolMessage
  │           → 提取 thread_id (= task_id)
  │
  └── useSubAgentStream (新增 hook)
        └── client.threads.joinStream(subAgentThreadId, { streamMode: "values" })
              │
              ├── 子智能体完成 "Knowledge Loader" → values 事件 → 提取 todos → 渲染 ✅
              ├── 子智能体完成 "Schema Linking"   → values 事件 → 提取 todos → 渲染 ✅
              ├── 子智能体完成 "SQL Generation"   → values 事件 → 提取 todos → 渲染 ✅
              └── 子智能体完成 (status: success)  → 流结束 → 显示最终结果
```

### 3.2 为什么是事件驱动而非轮询

| 维度 | 事件驱动（推荐） | 定时轮询 |
|------|-----------------|----------|
| 更新时机 | 每步完成后**立即**推送 | 最多延迟一个轮询周期 |
| 网络开销 | 仅在有更新时传输数据 | 每 2-3s 发一次请求 |
| 用户体验 | 步骤完成即刻反馈 | 可能看到"半完成"状态 |
| 实现复杂度 | 中（SSE 流管理） | 低（setInterval） |
| 对后端压力 | 极低（SSE 长连接） | 中等（频繁 REST 调用） |

### 3.3 关键 API 说明

```typescript
// LangGraph SDK v1.0.3 - client.threads.joinStream
client.threads.joinStream(threadId: string, options?: {
  lastEventId?: string;         // 断线重连时传入最后一个 event ID
  streamMode?: ThreadStreamMode | ThreadStreamMode[];
  // "values" → 每个节点执行后推送完整 state
  // "updates" → 每个节点执行后推送增量更新
}): AsyncGenerator<{ id?: string; event: StreamEvent; data: any }>
```

**关键点**：
- `joinStream` 不需要 `runId`，直接连接到线程上活跃的 run
- 后台 run（async sub-agent 创建方式）**默认启用所有 stream mode**
- 返回 `AsyncGenerator`，可用 `for await...of` 消费

```typescript
"use client";

import { useEffect, useState, useRef, useCallback, useMemo } from "react";
import type { Client } from "@langchain/langgraph-sdk";
import type { Message } from "@langchain/langgraph-sdk";

// ── 类型定义 ──────────────────────────────────────────────────

export interface SubAgentTodoItem {
  content: string;
  status: "pending" | "in_progress" | "completed";
}

export interface SubAgentProgress {
  taskId: string;
  threadId: string;
  agentName: string;
  status: "running" | "success" | "error";
  todos: SubAgentTodoItem[];
  totalSteps: number;
  completedSteps: number;
  currentStep: string | null;
  elapsed: string;
  latestThinking: string | null;
  finalResult: string | null;
}

// ── 工具函数 ──────────────────────────────────────────────────

/**
 * 从主智能体的消息流中提取 start_async_task 的调用信息。
 * start_async_task 返回的 ToolMessage 包含 task_id（即子智能体的 thread_id）。
 */
function extractAsyncTaskInfo(messages: Message[]): {
  taskId: string;
  threadId: string;
  agentName: string;
} | null {
  // 从后往前找最近的 start_async_task 调用
  for (let i = messages.length - 1; i >= 0; i--) {
    const msg = messages[i] as any;

    // 查找 AI 消息中的 start_async_task tool_call
    if (msg.type === "ai") {
      const toolCalls =
        msg.additional_kwargs?.tool_calls ||
        msg.tool_calls ||
        [];

      for (const tc of toolCalls) {
        const name = tc.function?.name || tc.name;
        if (name === "start_async_task") {
          const args = tc.function?.arguments
            ? JSON.parse(tc.function.arguments)
            : tc.args || {};
          const agentName = args.subagent_type || "nl2sql";
          const toolCallId = tc.id;

          // 在后续消息中查找对应的 ToolMessage（包含 task_id）
          for (let j = i + 1; j < messages.length; j++) {
            const toolMsg = messages[j] as any;
            if (
              toolMsg.type === "tool" &&
              toolMsg.tool_call_id === toolCallId
            ) {
              const content =
                typeof toolMsg.content === "string"
                  ? toolMsg.content
                  : JSON.stringify(toolMsg.content);
              // 从 ToolMessage content 中提取 task_id
              const match = content.match(/task_id[:\s]+([a-f0-9-]+)/i);
              if (match) {
                return {
                  taskId: match[1],
                  threadId: match[1], // task_id 就是 thread_id
                  agentName,
                };
              }
              // 也尝试从 JSON 解析
              try {
                const parsed = JSON.parse(content);
                if (parsed.task_id) {
                  return {
                    taskId: parsed.task_id,
                    threadId: parsed.task_id,
                    agentName,
                  };
                }
              } catch {
                // ignore
              }
            }
          }
        }
      }
    }
  }
  return null;
}

/**
 * 从子智能体的 state 中提取 todos（write_todos 工具的最新调用结果）。
 */
function extractTodosFromState(
  stateValues: Record<string, any>
): SubAgentTodoItem[] {
  const messages = stateValues?.messages || [];

  // 从后往前找最近的 write_todos 结果
  for (let i = messages.length - 1; i >= 0; i--) {
    const msg = messages[i];
    const role = msg.role || msg.type;

    if (role === "tool" && msg.name === "write_todos") {
      // write_todos 的 ToolMessage content 包含 todos 列表
      const content = typeof msg.content === "string" ? msg.content : "";
      // 解析 todos
      const items = [
        ...content.matchAll(
          /\{'content':\s*'([^']*)',\s*'status':\s*'([^']*)'\}/g
        ),
      ];
      if (items.length > 0) {
        return items.map((m: RegExpMatchArray) => ({
          content: m[1],
          status: m[2] as SubAgentTodoItem["status"],
        }));
      }
    }

    // 也检查 AI 消息中的 write_todos tool_calls args
    if (role === "ai" || role === "assistant") {
      const toolCalls = msg.tool_calls || [];
      for (const tc of toolCalls) {
        if (tc.name === "write_todos" && tc.args?.todos) {
          return tc.args.todos.map((t: any) => ({
            content: t.content,
            status: t.status,
          }));
        }
      }
    }
  }
  return [];
}

/**
 * 从消息中提取 AI 最新的思考内容（第一句话）。
 */
function extractLatestThinking(
  stateValues: Record<string, any>
): string | null {
  const messages = stateValues?.messages || [];
  for (let i = messages.length - 1; i >= 0; i--) {
    const msg = messages[i];
    const role = msg.role || msg.type;
    if ((role === "ai" || role === "assistant") && msg.content) {
      const content = typeof msg.content === "string" ? msg.content : "";
      if (content.trim()) {
        const firstSentence = content.split(/[。\n：]/)[0];
        return firstSentence.slice(0, 150);
      }
    }
  }
  return null;
}

/**
 * 计算已运行时间。
 */
function computeElapsed(startTime: number): string {
  const seconds = Math.floor((Date.now() - startTime) / 1000);
  if (seconds < 60) return `${seconds}s`;
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m}m${s}s`;
}

// ── Hook ──────────────────────────────────────────────────────

export function useSubAgentStream(
  client: Client | null,
  mainMessages: Message[]
): SubAgentProgress | null {
  const [progress, setProgress] = useState<SubAgentProgress | null>(null);
  const abortRef = useRef<AbortController | null>(null);
  const startTimeRef = useRef<number>(Date.now());

  // 从主消息流中提取异步任务信息
  const asyncTask = useMemo(
    () => extractAsyncTaskInfo(mainMessages),
    [mainMessages]
  );

  // 定时器更新 elapsed
  useEffect(() => {
    if (!progress || progress.status !== "running") return;
    const timer = setInterval(() => {
      setProgress((prev) =>
        prev
          ? { ...prev, elapsed: computeElapsed(startTimeRef.current) }
          : prev
      );
    }, 1000);
    return () => clearInterval(timer);
  }, [progress?.status]);

  // 核心：订阅子智能体线程流
  useEffect(() => {
    if (!client || !asyncTask) {
      setProgress(null);
      return;
    }

    // 清理之前的流
    abortRef.current?.abort();
    const controller = new AbortController();
    abortRef.current = controller;
    startTimeRef.current = Date.now();

    // 初始化进度
    setProgress({
      taskId: asyncTask.taskId,
      threadId: asyncTask.threadId,
      agentName: asyncTask.agentName,
      status: "running",
      todos: [],
      totalSteps: 0,
      completedSteps: 0,
      currentStep: null,
      elapsed: "0s",
      latestThinking: null,
      finalResult: null,
    });

    let lastEventId: string | undefined;

    const startStreaming = async () => {
      try {
        // 先获取当前 state（捕获已完成的步骤）
        try {
          const currentState = await client.threads.getState(
            asyncTask.threadId
          );
          if (currentState?.values) {
            const todos = extractTodosFromState(currentState.values);
            const completed = todos.filter(
              (t) => t.status === "completed"
            ).length;
            setProgress((prev) =>
              prev
                ? {
                    ...prev,
                    todos,
                    totalSteps: todos.length,
                    completedSteps: completed,
                    currentStep:
                      todos.find((t) => t.status === "in_progress")
                        ?.content || null,
                    latestThinking: extractLatestThinking(
                      currentState.values
                    ),
                  }
                : prev
            );
          }
        } catch (e) {
          console.warn("[useSubAgentStream] getState failed:", e);
        }

        // 订阅子智能体线程的 SSE 流
        const stream = client.threads.joinStream(asyncTask.threadId, {
          lastEventId,
          streamMode: "values",
        });

        for await (const chunk of stream) {
          if (controller.signal.aborted) break;

          // 保存 event ID 用于断线重连
          if (chunk.id) {
            lastEventId = chunk.id;
          }

          if (chunk.event === "values" && chunk.data) {
            const stateValues = chunk.data;
            const todos = extractTodosFromState(stateValues);
            const completed = todos.filter(
              (t) => t.status === "completed"
            ).length;

            setProgress((prev) =>
              prev
                ? {
                    ...prev,
                    todos,
                    totalSteps: todos.length,
                    completedSteps: completed,
                    currentStep:
                      todos.find((t) => t.status === "in_progress")
                        ?.content || null,
                    latestThinking: extractLatestThinking(stateValues),
                    elapsed: computeElapsed(startTimeRef.current),
                  }
                : prev
            );
          }

          // 检测子智能体完成
          if (chunk.event === "end") {
            // 获取最终 state
            try {
              const finalState = await client.threads.getState(
                asyncTask.threadId
              );
              const finalMessages = finalState?.values?.messages || [];
              const lastMsg = finalMessages[finalMessages.length - 1];
              const result =
                lastMsg?.content || lastMsg?.text || "(completed)";

              setProgress((prev) =>
                prev
                  ? {
                      ...prev,
                      status: "success",
                      finalResult: result,
                      currentStep: null,
                    }
                  : prev
              );
            } catch {
              setProgress((prev) =>
                prev ? { ...prev, status: "success" } : prev
              );
            }
            break;
          }

          if (chunk.event === "error") {
            setProgress((prev) =>
              prev
                ? {
                    ...prev,
                    status: "error",
                    finalResult: chunk.data?.error || "Unknown error",
                  }
                : prev
            );
            break;
          }
        }
      } catch (error: any) {
        if (error.name === "AbortError") return;
        console.error("[useSubAgentStream] stream error:", error);
        setProgress((prev) =>
          prev ? { ...prev, status: "error" } : prev
        );
      }
    };

    startStreaming();

    return () => {
      controller.abort();
    };
  }, [client, asyncTask?.threadId]);

  return progress;
}
```

```tsx
"use client";

import React from "react";
import { Loader2, CircleCheck, Circle, PlayCircle, AlertCircle } from "lucide-react";
import type { SubAgentProgress, SubAgentTodoItem } from "@/app/hooks/useSubAgentStream";

// ── 步骤图标 ──────────────────────────────────────────────────

function StepIcon({ status }: { status: SubAgentTodoItem["status"] }) {
  switch (status) {
    case "completed":
      return <CircleCheck size={14} className="shrink-0 text-green-500" />;
    case "in_progress":
      return <Loader2 size={14} className="shrink-0 animate-spin text-blue-500" />;
    default:
      return <Circle size={14} className="shrink-0 text-gray-300" />;
  }
}

// ── 进度条 ────────────────────────────────────────────────────

function ProgressBar({ completed, total }: { completed: number; total: number }) {
  const pct = total > 0 ? Math.round((completed / total) * 100) : 0;
  return (
    <div className="flex items-center gap-2">
      <div className="h-1.5 flex-1 overflow-hidden rounded-full bg-blue-100">
        <div
          className="h-full rounded-full bg-blue-500 transition-all duration-500"
          style={{ width: `${pct}%` }}
        />
      </div>
      <span className="min-w-[3rem] text-right text-xs text-gray-500">
        {pct}%
      </span>
    </div>
  );
}

// ── 主组件 ────────────────────────────────────────────────────

interface SubAgentProgressCardProps {
  progress: SubAgentProgress;
}

export const SubAgentProgressCard = React.memo<SubAgentProgressCardProps>(
  ({ progress }) => {
    const isRunning = progress.status === "running";
    const isError = progress.status === "error";

    return (
      <div className="my-3 w-full max-w-[85%] overflow-hidden rounded-lg border border-blue-200 bg-gradient-to-br from-blue-50/80 to-white p-4 shadow-sm">
        {/* 标题行 */}

          <div className="flex items-center gap-2">
            {isRunning && (
              <Loader2 size={16} className="animate-spin text-blue-500" />
            )}
            {isError && <AlertCircle size={16} className="text-red-500" />}
            {!isRunning && !isError && (
              <CircleCheck size={16} className="text-green-500" />
            )}
            <span className="text-sm font-semibold text-gray-700">
              {progress.agentName}
            </span>
            <span className="text-xs text-gray-400">
              {isRunning
                ? "执行中"
                : isError
                ? "出错"
                : "已完成"}
            </span>
          </div>
          <div className="flex items-center gap-2 text-xs text-gray-400">

              {progress.completedSteps}/{progress.totalSteps} 步

        </div>

        {/* 进度条 */}

        {isRunning && progress.latestThinking && (

              {progress.finalResult.slice(0, 500)}
              {progress.finalResult.length > 500 ? "..." : ""}
            </p>
          </div>
        )}
      </div>
    );
  }
);
```

## 5. 方案 D：后端状态注入（零前端改动）

### 5.1 核心思路

利用前端已有的 `TasksFilesSidebar` 组件（渲染 `stream.values.todos`），通过后台同步进程将子智能体的步骤进度写入主智能体的 `todos` state 字段。前端无需任何改动，进度自动显示在任务进度条中。

```
nl2sql_agent (子智能体)                   chat_agent (主智能体)
  Step 1 完成 → write_todos ─┐              stream.values.todos
  Step 2 完成 → write_todos ─┤── 同步进程 ──→  自动更新
  Step 3 完成 → write_todos ─┘                 │
                                              ▼
                                   前端 TasksFilesSidebar
                                   (已有组件，零改动)
                                   显示: ✅ Knowledge Loader
                                         ✅ Schema Linking
                                         🔄 Query Plan生成
```

### 5.2 关键问题：Todos 合并而非覆盖

**问题**：直接写入子智能体的 todos 会覆盖主智能体自己的 todos（如"分析意图"、"生成图表"等）。

**解法**：同步进程首次运行时快照主智能体的原始 todos，每次同步时**合并**（主智能体 todos + 分隔符 + 子智能体 todos），而非覆盖。

```
主智能体原始 todos              子智能体 todos               合并后写入 state
─────────────────            ──────────────               ──────────────────
[分析意图 ✅,                [Knowledge Loader ✅,         [分析意图 ✅,
 生成图表 ⬜]                Schema Linking 🔄]            生成图表 ⬜,
                                                           ─── 分隔符 ───
                                                          🔍 nl2sql 执行进度 (1/2) 🔄,
                                                            Knowledge Loader ✅,
                                                            Schema Linking 🔄]
```

**前端任务栏效果**：

```
任务 2 / 5   ████████░░░░ 40%

✅ 已完成
  ✓ 分析意图
  ✓   Knowledge Loader

🔄 进行中
  ⏰ 🔍 nl2sql 执行进度 (1/2)
  ⏰   Schema Linking

⬜ 待处理
  ○ 生成图表
```

### 5.3 完整实现代码

**文件位置**：`src/agent/subagents/sync_subagent_todos.py`

```python
"""后台同步子智能体 todos 到主智能体 state（零前端改动方案）。

核心逻辑：
1. 首次运行：快照主智能体的原始 todos（排除之前残留的子智能体 todos）
2. 每 2 秒轮询子智能体的 write_todos 结果
3. 合并：主智能体原始 todos + 分隔符 + 子智能体 todos
4. 写回主智能体 state → 前端 TasksFilesSidebar 自动更新
5. 子智能体完成后，清除子智能体部分，只保留主智能体原始 todos
"""
import asyncio
import logging
import threading
from typing import Optional

_logger = logging.getLogger(__name__)

# 标记：用于识别哪些 todo 是同步注入的子智能体进度
_SUBAGENT_MARKER = "🔍"
_SUBAGENT_PREFIX = "  "  # 两个空格缩进，视觉区分


def launch_sync(main_thread_id: str, sub_thread_id: str, agent_name: str):
    """在守护线程中启动异步同步任务。幂等安全。"""
    threading.Thread(
        target=_run_sync_loop,
        args=(main_thread_id, sub_thread_id, agent_name),
        daemon=True,
        name=f"subagent-sync-{sub_thread_id[:8]}",
    ).start()
    _logger.info(
        "[sync] 启动同步: main=%s, sub=%s, agent=%s",
        main_thread_id[:8], sub_thread_id[:8], agent_name,
    )


def _run_sync_loop(main_thread_id: str, sub_thread_id: str, agent_name: str):
    """守护线程入口：创建新事件循环运行异步同步逻辑。"""
    loop = asyncio.new_event_loop()
    try:
        loop.run_until_complete(
            _async_sync_loop(main_thread_id, sub_thread_id, agent_name)
        )
    except Exception as e:
        _logger.error("[sync] 同步循环异常: %s", e)
    finally:
        loop.close()


async def _async_sync_loop(
    main_thread_id: str, sub_thread_id: str, agent_name: str
):
    """核心异步同步循环。"""
    from langgraph_sdk import get_client

    client = get_client(url=None)  # ASGI 内部调用
    main_todos_snapshot: Optional[list] = None  # 主智能体原始 todos 快照
    last_sub_todos: Optional[list] = None       # 上一次同步的子智能体 todos

    while True:
        await asyncio.sleep(2)
        try:
            # ── 1. 检查子智能体 run 状态 ──
            run_status = await _get_run_status(client, sub_thread_id)
            if run_status is None:
                _logger.warning("[sync] 无法获取 run 状态，退出")
                break

            # ── 2. 首次运行：快照主智能体原始 todos ──
            if main_todos_snapshot is None:
                main_todos_snapshot = await _snapshot_main_todos(
                    client, main_thread_id
                )
                _logger.info(
                    "[sync] 快照主智能体 todos: %d 项",
                    len(main_todos_snapshot),
                )

            # ── 3. 获取子智能体 todos ──
            if run_status in ("success", "error"):
                sub_todos = None  # 子智能体结束
            else:
                sub_todos = await _extract_subagent_todos(client, sub_thread_id)

            # ── 4. 合并写入 ──
            if sub_todos is not None and sub_todos != last_sub_todos:
                merged = _merge_todos(
                    main_todos_snapshot, sub_todos, agent_name
                )
                await client.threads.update_state(
                    thread_id=main_thread_id,
                    values={"todos": merged},
                )
                last_sub_todos = sub_todos
                completed = sum(
                    1 for t in sub_todos if t["status"] == "completed"
                )
                _logger.info(
                    "[sync] 已同步 %d/%d 步",
                    completed, len(sub_todos),
                )

            # ── 5. 子智能体结束：清理并退出 ──
            if run_status in ("success", "error"):
                # 最终写入：只保留主智能体原始 todos
                await client.threads.update_state(
                    thread_id=main_thread_id,
                    values={"todos": main_todos_snapshot},
                )
                _logger.info(
                    "[sync] 子智能体 %s，已清理并退出同步", run_status
                )
                break

        except Exception as e:
            _logger.warning("[sync] 同步失败: %s", e)

    _logger.info("[sync] 退出: %s", sub_thread_id[:8])


# ── 辅助函数 ────────────────────────────────────────────────────


async def _get_run_status(client, thread_id: str) -> Optional[str]:
    """获取线程上最新 run 的状态。"""
    try:
        runs = await client.runs.list(thread_id=thread_id, limit=1)
        if not runs:
            return None
        return runs[0].get("status", "unknown")
    except Exception as e:
        _logger.warning("[sync] get_run_status failed: %s", e)
        return None


async def _snapshot_main_todos(client, main_thread_id: str) -> list:
    """快照主智能体的原始 todos（排除之前可能残留的子智能体 todos）。"""
    try:
        state = await client.threads.get_state(thread_id=main_thread_id)
        todos = (state.get("values") or {}).get("todos") or []
        return [
            t for t in todos
            if not t.get("content", "").startswith(_SUBAGENT_MARKER)
            and not t.get("content", "").startswith(_SUBAGENT_PREFIX)
            and not t.get("id", "").startswith("__subagent_")
        ]
    except Exception as e:
        _logger.warning("[sync] snapshot_main_todos failed: %s", e)
        return []


async def _extract_subagent_todos(client, sub_thread_id: str) -> list:
    """从子智能体线程提取最新的 write_todos 结果。"""
    try:
        state = await client.threads.get_state(thread_id=sub_thread_id)
        messages = (state.get("values") or {}).get("messages", [])

        # 从后往前找最新的 write_todos
        for msg in reversed(messages):
            if not isinstance(msg, dict):
                continue
            role = msg.get("role") or msg.get("type")

            # 方式 1：AI 消息中的 tool_calls args
            if role in ("ai", "assistant"):
                for tc in msg.get("tool_calls") or []:
                    if tc.get("name") == "write_todos":
                        todos = tc.get("args", {}).get("todos", [])
                        if todos:
                            return [
                                {
                                    "content": t.get("content", ""),
                                    "status": t.get("status", "pending"),
                                }
                                for t in todos
                            ]

            # 方式 2：ToolMessage content 解析（fallback）
            if role == "tool" and msg.get("name") == "write_todos":
                import re
                content = msg.get("content", "")
                if isinstance(content, str):
                    items = re.findall(
                        r"\{'content':\s*'([^']*)',\s*'status':\s*'([^']*)'\}",
                        content,
                    )
                    if items:
                        return [
                            {"content": c, "status": s} for c, s in items
                        ]
        return []
    except Exception as e:
        _logger.warning("[sync] extract_subagent_todos failed: %s", e)
        return []


def _merge_todos(
    main_todos: list, sub_todos: list, agent_name: str
) -> list:
    """合并主智能体 todos 和子智能体 todos。

    规则：
    - 主智能体 todos 保持原样在前面
    - 添加分隔符标识子智能体进度区域
    - 子智能体 todos 带缩进前缀
    """
    merged = list(main_todos)

    if not sub_todos:
        return merged

    # 分隔符：显示子智能体名称和进度
    completed = sum(1 for t in sub_todos if t["status"] == "completed")
    total = len(sub_todos)
    has_in_progress = any(t["status"] == "in_progress" for t in sub_todos)

    merged.append({
        "id": "__subagent_header__",
        "content": f"{_SUBAGENT_MARKER} {agent_name} 执行进度 ({completed}/{total})",
        "status": "in_progress" if has_in_progress else "completed",
    })

    # 子智能体 todos（带缩进前缀）
    for i, t in enumerate(sub_todos):
        merged.append({
            "id": f"__subagent_{i}__",
            "content": f"{_SUBAGENT_PREFIX}{t['content']}",
            "status": t["status"],
        })

    return merged
```

```python
_orig_build_start_command = None

def apply_sync_patch():
    """Monkey-patch start_async_task，在创建子智能体后自动启动同步。"""
    from deepagents.middleware import async_subagents as _mod

    global _orig_build_start_command
    if _orig_build_start_command is not None:
        return  # 已 patch
    _orig_build_start_command = _mod._build_start_command

    def _patched_build_start_command(*args, **kwargs):
        result = _orig_build_start_command(*args, **kwargs)
        # 从 result 中提取 thread_id 并启动同步
        try:
            from agent.subagents.sync_subagent_todos import launch_sync
            # result 是 Command，从 update 中提取 task 信息
            update = result.update if hasattr(result, 'update') else {}
            async_tasks = update.get("async_tasks", {})
            for task_id, task_info in async_tasks.items():
                thread_id = task_info.get("thread_id", task_id)
                agent_name = task_info.get("agent_name", "unknown")
                # 获取主智能体的 thread_id
                # （需要从 runtime 或 kwargs 中获取）
                main_thread_id = _get_main_thread_id(kwargs)
                if main_thread_id:
                    launch_sync(main_thread_id, thread_id, agent_name)
        except Exception as e:
            import logging
            logging.getLogger(__name__).warning(
                "[sync_launcher] 启动同步失败: %s", e
            )
        return result

    _mod._build_start_command = _patched_build_start_command


def _get_main_thread_id(kwargs: dict) -> str | None:
    """从 kwargs 或 runtime 中获取主智能体的 thread_id。"""
    # 尝试从 ToolRuntime 中获取
    runtime = kwargs.get("runtime")
    if runtime and hasattr(runtime, "config"):
        config = runtime.config
        return config.get("configurable", {}).get("thread_id")
    return None


apply_sync_patch()
```

### 5.5 Todos 合并的数据流图

```
时间轴 ────────────────────────────────────────────────────────→

T0: 用户发送查询
    主智能体 todos = [{分析意图, pending}, {生成图表, pending}]

T1: 主智能体调用 start_async_task
    → launch_sync() 启动
    → _snapshot_main_todos() 快照:
      main_todos_snapshot = [{分析意图, pending}, {生成图表, pending}]

T2: 主智能体收到 ToolMessage，开始做其他工作
    → 主智能体调用 write_todos([{分析意图, completed}])
    → state.todos = [{分析意图, completed}, {生成图表, pending}]

T3: 子智能体完成 Step 1，调用 write_todos
    → 同步进程检测到变化
    → _merge_todos():
      main_todos_snapshot: [{分析意图, pending}, {生成图表, pending}]
      sub_todos:           [{Knowledge Loader, completed}]
      merged:              [{分析意图, pending},
                            {生成图表, pending},
                            🔍 nl2sql 执行进度 (1/6),
                              Knowledge Loader ✅]
    → update_state(main_thread, merged)

T4: 主智能体也更新了自己的 todos
    → state.todos = [{分析意图, completed},  ← 主智能体更新
                     {生成图表, pending},
                     🔍 nl2sql 执行进度 (1/6),
                       Knowledge Loader ✅]
    注意：主智能体的 update_state 会覆盖整个 todos，
    但同步进程下次运行时会重新读取最新的 main_todos_snapshot

T5: 子智能体完成 Step 2
    → 同步进程重新快照 main_todos_snapshot（此时包含主智能体的最新 todos）
    → 合并后写入

T6: 子智能体完成
    → 同步进程清理：只保留主智能体原始 todos
    → state.todos = [{分析意图, completed}, {生成图表, pending}]
    → 同步进程退出
```

### 5.6 局限性

| 维度 | 说明 | 缓解措施 |
|------|------|---------|
| 显示位置 | 进度在**任务进度条**（输入框上方），不在对话流中 | 如需对话流内显示，切换到方案 A |
| 信息密度 | 只显示步骤名和状态，没有 elapsed、latest_thinking | 可将额外信息编入 content 文本 |
| 主 Agent todos 竞争 | 主智能体和同步进程都可能更新 todos | 同步进程每次重新快照，减少冲突窗口 |
| 更新延迟 | ~2 秒轮询间隔 | 可调小 `asyncio.sleep(1)` 但增加 API 调用 |
| 多子智能体 | 同时运行多个子智能体时需要多个同步进程 | 每个 `launch_sync` 独立运行，互不干扰 |

### 5.7 与方案 A 的关系

方案 D 和方案 A 不是互斥的，可以组合使用：

| 场景 | 推荐方案 |
|------|---------|
| 快速验证 / 不想改前端 | 方案 D（零前端改动） |
| 追求最佳用户体验 | 方案 A（对话流内进度卡片） |
| 两者兼用 | D 提供任务栏进度 + A 提供对话流详情 |

```typescript
// useSubAgentPolling.ts — 当 joinStream 不可用时的备选
export function useSubAgentPolling(
  baseUrl: string,
  taskId: string | null,
  intervalMs = 3000
): SubAgentProgress | null {
  const [progress, setProgress] = useState<SubAgentProgress | null>(null);

  useEffect(() => {
    if (!taskId || !baseUrl) return;

    const poll = async () => {
      try {
        const res = await fetch(
          `${baseUrl}/threads/${taskId}/subagent-progress`
        );
        const data = await res.json();
        setProgress((prev) => ({
          ...prev,
          taskId,
          threadId: taskId,
          agentName: "nl2sql",
          status: data.status,
          todos: parseSteps(data.steps || []),
          totalSteps: (data.steps || []).length,
          completedSteps: (data.steps || []).filter((s: string) =>
            s.startsWith("✅")
          ).length,
          currentStep: data.current_step || null,
          elapsed: data.elapsed || "0s",
          latestThinking: data.latest_thinking || null,
          finalResult: data.result || null,
        }));
      } catch (e) {
        console.warn("[polling] failed:", e);
      }
    };

    poll();
    const timer = setInterval(poll, intervalMs);
    return () => clearInterval(timer);
  }, [baseUrl, taskId, intervalMs]);

  return progress;
}
```

## 7. 关键实现注意事项

### 7.1 `start_async_task` 的 task_id 提取

当前 `start_async_task` 返回的 ToolMessage content 格式为：

### 7.2 SSE 连接稳定性

- `joinStream` 返回的 `AsyncGenerator` 在网络断开时会抛出异常，需要 catch 并可选择重连
- 使用 `lastEventId` 参数实现断线续传
- 建议添加最大重试次数（如 3 次）和退避策略

### 7.3 `write_todos` 数据格式

子智能体的系统提示词要求在每步完成后调用 `write_todos`：

```python
    ...

```

前端的 `extractTodosFromState` 从最新一次 `write_todos` 的 ToolMessage 中提取数据。

### 7.5 性能考虑

- `SubAgentProgressCard` 使用 `React.memo` 避免不必要的重渲染
- `useSubAgentStream` 内部使用 `AbortController` 确保组件卸载时清理 SSE 连接
- `joinStream` 的 SSE 连接对后端压力极小（仅维持长连接，无轮询开销）
- `computeElapsed` 每秒更新一次，使用独立的 `setInterval`，不触发整个组件树重渲染

## 10. 方案 A 前端 SSE 订阅（joinStream）可行性验证

> 日期：2026-08-22  
> 结论：**不可行**

### 10.1 验证过程

在 langgraph 1.2.6 + langgraph_api 0.4.42 + langgraph_sdk 1.0.3 环境下，通过 Python SDK 和 Node.js SDK 分别测试了 `joinStream` / `join_stream` API 对后台 async run 的可用性：

**Python SDK 测试：**

| 方法 | 结果 |
|------|------|
| `client.threads.join_stream(thread_id)` | 需要 `await`，返回 async generator，但消费时卡住超时 |
| `client.runs.join_stream(thread_id, run_id)` | 对已完成 run 返回空流（0 chunks）；对新创建 run 返回 4 个 values 事件后正常结束 |

**Node.js SDK 测试：**

| 方法 | 结果 |
|------|------|
| `client.threads.joinStream(threadId)` | 返回 async iterable，但消费时卡住超时 |

### 10.2 根因分析

子智能体通过 `start_async_task` → `client.runs.create` 创建**后台 run**，运行在独立线程中。`threads.join_stream` 设计为订阅当前线程上**活跃的 run**，但后台 run 的 SSE 流可能未正确路由到 `threads` 端点。

`runs.join_stream` 虽能正常工作（需要 `thread_id + run_id`），但：
1. 前端在 `start_async_task` 返回时只能拿到 `task_id`（= `thread_id`），**拿不到 `run_id`**
2. 需要额外一次 `client.runs.list` 查询才能获取 `run_id`，此时 run 可能还未创建
3. 时序问题：run 创建是异步的，join 过早会失败

### 10.3 结论

方案 A 的 SSE 订阅路径在现有架构下**不可行**。当前最优方案是**后端 sync 守护线程（0.5s）+ 前端轮询（1s）**，数据流：

```
子智能体 write_todos
  → 后端 sync 守护线程 (0.5s) update_state 写入 subagent_steps_map
  → 前端 Loop A 轮询 (1s) getState 读取
  → useChat 派生 queryTasks
  → ChatInterface 渲染 SubAgentProgressCard
```

### 10.4 未来方向

如果 LangGraph 后续版本支持以下能力之一，可重新评估方案 A：

- `threads.join_stream` 支持订阅后台 run（不依赖前台 run 的 SSE 路由）
- `start_async_task` 返回值中附带 `run_id`，使前端可直接 `runs.join_stream`
- `astream_events(version="v3")` 的 `StreamMux` 支持外部事件注入（可跨线程推送进度）

### 11.2 优化效果

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 最大进度延迟 | 2.5s（2s 前端 + 0.5s 后端） | 1.5s（1s 前端 + 0.5s 后端） |

### 11.3 与 streaming v3 的关系

`astream_events(version="v3")` 是 LangGraph 的 typed projection 流式协议，底层仍是 `astream(version="v2")`。v3 的 `StreamMux` + 自定义 `StreamTransformer` 被动响应 graph 事件流，**无法解决跨线程数据推送问题**（主 agent 等待子智能体时无 graph 事件产生）。v3 的价值在于主 agent 自身执行过程的更结构化流式输出，而非子智能体进度推送。
