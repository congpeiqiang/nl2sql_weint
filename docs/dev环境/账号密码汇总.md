## 9. 常用运维命令

```bash
# 应用栈（5 容器：nginx / frontend / langgraph-api / postgres / devdb）
cd /mydata/nl2sql/nl2sql-app && docker compose ps
docker compose logs -f --tail=100 langgraph-api      # 看后端日志
docker compose restart langgraph-api                 # 改了 /mydata/nl2sql/src 里的代码后重启

# Langfuse 栈（6 容器：web / worker / postgres / clickhouse / minio / redis）
cd /mydata/nl2sql/langfuse && docker compose ps
docker compose logs -f --tail=100 langfuse-web
```

## 11. 已知事项

1. **34 无外网** → 公网模型 API 不可用；装新镜像只能从 25.64 搬（`ssh 64 "docker save X" | docker load`，64 上零落盘）。
2. **前端改动要重构建镜像**（34 上 build 不了），后端改动只需换 /mydata/nl2sql/src 里的文件 + 重启容器。
3. **首次配模型后必须重启后端**：模型是**导入时**解析的，模型库为空时子 agent 会落到框架默认的 Anthropic 模型，run 会以「error 字段为空」的方式失败。
4. dev Langfuse 是全新实例，prompt / dataset 都还没有，需要时单独建。
