# 02 · 界面导航

> 适用环境：Langfuse **v4.x**（自托管或 Cloud，UI 一致）

---

## 1. 登录

浏览器打开 Langfuse 地址：

| 环境 | 地址 |
|------|------|
| 自托管 | `http://your-server:3001` |
| Langfuse Cloud | `https://cloud.langfuse.com` |

首次登录需注册账号（Cloud）或使用管理员分配的账号（自托管）。

## 2. 全局导航

登录后左侧/顶部导航栏包含以下主要页面：

```
┌────────────────────────────────────────────────────┐
│  Langfuse                                          │
│                                                    │
│  📊 Dashboard       ← 总览看板                      │
│  🔍 Traces          ← 追踪列表 + 详情               │
│  🤖 Generations     ← LLM 生成记录                  │
│  📈 Scores          ← 打分汇总                      │
│  ⚖️ Evaluations     ← LLM-as-Judge 配置             │
│  📚 Datasets        ← 数据集管理                    │
│  📝 Prompts         ← Prompt 版本管理               │
│  👥 Sessions        ← 会话分组                      │
│  🏷️ Tags            ← 标签管理                      │
│  📦 Models          ← 模型配置（单价/token 计算）     │
│  ⚙️ Settings        ← 项目设置、密钥、成员           │
└────────────────────────────────────────────────────┘
```

## 3. 各页面详解

### 3.1 Dashboard（看板）

总览页面，展示关键指标：

- **Trace 数量趋势**：按天/小时的请求量
- **成本统计**：LLM 调用总成本、按模型拆分
- **延迟分布**：P50/P90/P99 响应时间
- **Score 趋势**：各评分维度的变化曲线
- **Top Users / Sessions**：活跃用户和会话排行

> 💡 使用顶部的时间范围选择器切换查看区间。

### 3.2 Traces（追踪列表）

**最常用的页面**。展示所有上报的 trace。

**列表视图**：

| 列 | 说明 |
|----|------|
| Name | Trace 名称（通常是 agent 名） |
| User | 用户标识 |
| Session | 所属会话 |
| Latency | 总耗时 |
| Cost | LLM 成本 |
| Scores | 评分汇总 |
| Tags | 标签 |
| Timestamp | 创建时间 |

**筛选与搜索**：

- 按名称、用户、会话 ID、标签筛选
- 按时间范围过滤
- 按 Score 范围过滤
- 全文搜索

**详情视图**（点击一条 trace 进入）：

```
Trace: nl2sql-agent  (12.3s, $0.05)
├── 🤖 generate-sql         (generation, 3.2s, 1200 tokens)
│   Input: {"question": "统计 artist 表有多少艺术家"}
│   Output: "SELECT COUNT(*) FROM artist"
│   Model: gpt-4o
│
├── 🔧 execute-sql          (tool, 1.1s)
│   Input: {"sql": "SELECT COUNT(*) FROM artist"}
│   Output: {"row_count": 275, "error": null}
│
└── 📊 Scores
    ├── sql-correctness: 1.0
    └── schema_match: 1.0
```

### 3.3 Generations（生成记录）

只展示 `as_type="generation"` 的 LLM 调用记录。适合：

- 分析模型调用效率
- 对比不同模型的 token 消耗
- 查看 prompt/completion 内容

### 3.4 Scores（打分汇总）

所有评分记录的汇总视图：

- **按评分名称分组**：如 `sql-correctness`、`user-feedback`
- **分布图**：分数的分布直方图
- **趋势图**：评分随时间的变化
- **筛选**：按 trace、时间、评分类型筛选

### 3.5 Evaluations（评估配置）

配置 **LLM-as-Judge** 自动评估规则：

1. 点击 **New Evaluator**
2. 选择评估模型（需先在 Models 页配置 API Key）
3. 选择评估模板（如 Hallucination、Helpfulness）或自定义
4. 配置目标：哪些 trace / generation 需要评估
5. 设置采样率（避免全量评估带来高成本）

> 详细配置方法见 [04-评估与打分](04-评估与打分.md)。

### 3.6 Datasets（数据集）

管理测试数据集：

- **创建数据集**：手动添加或通过 API 自动采集
- **数据集详情**：每条记录包含 input / expected_output / metadata
- **Dataset Runs**：查看在该数据集上运行的实验结果

> 详见 [06-数据集与实验](06-数据集与实验.md)。

### 3.7 Prompts（提示词管理）

Prompt 版本管理与发布：

- **Prompt 列表**：所有已注册的 prompt
- **版本历史**：每个 prompt 的所有版本
- **标签管理**：`production` / `staging` / `canary` 等标签
- **快速操作**：回滚到旧版本、对比版本差异

> 详见 [05-Prompt 管理](05-Prompt管理.md)。

### 3.8 Sessions（会话）

按 `session_id` 分组的多轮对话视图：

- 一个 session 包含多个 trace
- 适合分析多轮交互的完整上下文
- 可以看到用户在一次会话中的完整操作链

### 3.9 Models（模型配置）

配置 LLM 模型的单价信息：

- 添加模型（如 `gpt-4o`、`deepseek-chat`）
- 设置 input/output token 单价
- Langfuse 自动计算每次 generation 的成本

> 如果不配置模型单价，trace 的成本列会显示为空。

### 3.10 Settings（项目设置）

- **API Keys**：查看/创建 Public Key 和 Secret Key
- **Members**：添加项目成员、设置角色
- **Project**：项目名称、删除项目、数据导出
- **Integrations**：与其他平台集成（如 PostHog、Segment）

## 4. 常用操作速查

| 操作 | 路径 |
|------|------|
| 查看最新 trace | Traces → 按 Timestamp 降序 |
| 搜索特定用户的 trace | Traces → User 筛选 |
| 查看某个评分的趋势 | Scores → 选择评分名称 |
| 创建新的 Prompt | Prompts → New Prompt |
| 配置 LLM-as-Judge | Evaluations → New Evaluator |
| 创建数据集 | Datasets → New Dataset |
| 查看 API 密钥 | Settings → API Keys |
| 清空测试数据 | Settings → Danger Zone → Delete Project |
