# 02 · 界面导航

> Langfuse v4 Web UI 各页面功能详解  
> 适用环境：Langfuse **v4.x**（自托管或 Cloud，UI 一致）

---

## 1. 登录与初始设置

### 1.1 登录

| 环境 | 地址 |
|------|------|
| 自托管 | `http://your-server:3001` |
| Langfuse Cloud | `https://cloud.langfuse.com` |

### 1.2 组织与项目

登录后左上角可以切换组织和项目：

```
组织: AgentLab
├── 项目: default (proj_7qzwty81)
└── 项目: nl2sql-project (proj_6nMyvFmN)
```

- **组织**：团队协作的顶层容器
- **项目**：数据隔离的单位（每个项目有独立的 API 密钥、traces、scores）

### 1.3 获取 API 密钥

**Settings → API Keys → Create new API keys**

```
Public Key:  pk-lf-xxxxxxxxxx
Secret Key:  sk-lf-xxxxxxxxxx   ← 只在创建时显示一次！
```

## 3. 各页面详解

### 3.1 Dashboard（看板）

总览页面，展示关键运营指标。

**核心指标卡片**：

| 指标 | 说明 | 关注点 |
|------|------|--------|
| Total Traces | 总 trace 数 | 请求量趋势 |
| Total Cost | LLM 总成本 | 成本变化 |
| Avg Latency | 平均延迟 | 性能健康 |
| Avg Score | 平均评分 | 质量趋势 |

**图表区域**：

- **Traces 时间趋势**：按天/小时的请求量折线图
- **成本趋势**：按天/小时的 LLM 成本折线图（可按模型拆分）
- **延迟分布**：P50/P90/P99 延迟趋势
- **Score 趋势**：各评分维度的变化曲线
- **Top Users**：活跃用户排行
- **Top Sessions**：活跃会话排行

**交互功能**：

- 时间范围选择器（1h / 6h / 24h / 7d / 30d / 自定义）
- 点击图表中的数据点可跳转到对应的 trace 列表
- 图表支持缩放和拖拽

### 3.2 Traces（追踪列表）

**最常用的页面**。

**列表视图**：

| 列 | 说明 | 排序 |
|----|------|------|
| Name | Trace 名称 | ✅ |
| User | 用户标识 | ✅ |
| Session | 所属会话 | ✅ |
| Latency | 总耗时 | ✅ |
| Cost | LLM 成本 | ✅ |
| Scores | 评分汇总（显示各维度分数） | ✅ |
| Tags | 标签 | |
| Timestamp | 创建时间 | ✅ |
| Release | 发版标记 | |
| Environment | 环境标签 | |

**筛选与搜索**：

| 筛选方式 | 说明 |
|----------|------|
| 名称筛选 | 按 trace name 精确/模糊匹配 |
| 用户筛选 | 按 user_id 筛选 |
| 会话筛选 | 按 session_id 筛选 |
| 标签筛选 | 按 tags 筛选 |
| 时间范围 | 按创建时间过滤 |
| Score 范围 | 按评分值过滤（如 sql_biz_correct < 0.5） |
| 全文搜索 | 搜索 input/output/metadata |

**详情视图**（点击一条 trace 进入）：

**Observation 详情面板**（点击树中的节点）：

- Input：该步骤的输入数据
- Output：该步骤的输出数据
- Metadata：附加信息
- Model：使用的模型（仅 generation）
- Token Usage：token 消耗明细
- Cost：该步骤的成本
- Latency：该步骤的耗时
- Status：成功/错误/超时

### 3.3 Generations（生成记录）

只展示 `as_type="generation"` 的 LLM 调用记录。

**用途**：

- 分析各模型的调用频次和成本
- 查看 prompt/completion 内容
- 对比不同模型的效率

**列表列**：

| 列 | 说明 |
|----|------|
| Name | Generation 名称 |
| Model | 使用的模型 |
| Input Tokens | 输入 token 数 |
| Output Tokens | 输出 token 数 |
| Total Cost | 成本 |
| Latency | 耗时 |
| Trace | 所属 trace（可跳转） |

### 3.4 Scores（打分汇总）

所有评分记录的汇总视图。

**按评分名称分组**：

```
sql_biz_correct_score (N=1,234)
├── 分布直方图
├── 趋势折线图
└── 最近评分列表

sql_exec_success (N=3,456)
├── 分布直方图
└── 成功率趋势

user-feedback (N=890)
├── 好评率趋势
└── 最近差评列表
```

**筛选**：按 trace 名、时间范围、评分类型、分数范围。

### 3.5 Evaluations（评估配置）

配置和管理 LLM-as-Judge 评估器。

**评估器列表**：

| 列 | 说明 |
|----|------|
| Name | 评估器名称 |
| Status | Active / Inactive |
| Target | 评估目标（哪些 trace） |
| Model | 使用的评估模型 |
| Sampling | 采样率 |
| Last Run | 最后运行时间 |

**创建评估器**：

1. 选择评估模板（Hallucination / Helpfulness / 自定义）
2. 配置评估 Prompt
3. 选择评估模型
4. 设置目标（按 trace name / tag / environment 筛选）
5. 设置采样率

### 3.6 Datasets（数据集）

管理测试数据集。

**数据集列表**：

| 列 | 说明 |
|----|------|
| Name | 数据集名称 |
| Items | 记录数 |
| Runs | 实验运行次数 |
| Last Updated | 最后更新时间 |

**数据集详情**：

- **Items 标签**：所有 item 列表（input / expected_output / metadata）
- **Runs 标签**：在该数据集上运行的所有实验（可对比多轮）
- **添加 Item**：手动添加或 API 写入

### 3.7 Experiments（实验）

v4 新增的独立实验对比页面。

**实验列表**：

| 列 | 说明 |
|----|------|
| Experiment Name | 实验名称 |
| Dataset | 使用的数据集 |
| Runs | 实验运行数 |
| Status | 运行中 / 已完成 |

**实验详情**：

- 按 item 展示每个实验臂的结果
- Expected Output 列显示金标
- 逐条对比不同臂的输出和评分
- 聚合统计（均值、标准差）

### 3.8 Prompts（提示词管理）

Prompt 版本管理与发布。

**Prompt 列表**：

| 列 | 说明 |
|----|------|
| Name | Prompt 名称 |
| Production | 当前 production 版本号 |
| Latest | 最新版本号 |
| Last Updated | 最后更新时间 |

**Prompt 详情**：

- **版本历史**：所有版本按版本号倒序
- **版本对比**：选择两个版本高亮差异
- **标签管理**：拖动标签到目标版本
- **内容编辑**：基于当前版本创建新版本

### 3.9 Sessions（会话）

按 `session_id` 分组的多轮对话视图。

```
Session: thread-001 (alice)
├── Trace 1: "chat-turn" (15:12, 12.3s, ✅)
├── Trace 2: "chat-turn" (15:15, 8.5s, ✅)
├── Trace 3: "chat-turn" (15:18, 15.2s, ❌)  ← 差评
└── Trace 4: "chat-turn" (15:22, 6.1s, ✅)
```

### 3.10 Users（用户分析）

按 `user_id` 分组的用户分析视图。

### 3.11 Models（模型配置）

配置 LLM 模型的单价信息：

```
添加模型:
  Model Name: gpt-4o
  Input Price: $0.0025 / 1K tokens
  Output Price: $0.01 / 1K tokens
```

### 3.12 Settings（项目设置）

| 子页面 | 功能 |
|--------|------|
| **API Keys** | 查看/创建 Public Key 和 Secret Key |
| **Members** | 添加项目成员、设置角色（Admin/Member/Viewer） |
| **Project** | 项目名称、删除项目、数据导出 |
| **Integrations** | 与其他平台集成（PostHog、Segment） |
| **Billing** | Cloud 版计费信息 |
| **Danger Zone** | 清空数据、删除项目（不可恢复） |

## 4. 常用操作速查

| 操作 | 路径 |
|------|------|
| 查看最新 trace | Traces → 按 Timestamp 降序 |
| 搜索特定用户 | Traces → User 筛选 |
| 查看差评 trace | Scores → user-feedback = 0 |
| 查看评分趋势 | Scores → 选择评分名称 |
| 创建 Prompt | Prompts → New Prompt |
| 发布 Prompt | Prompts → 版本详情 → 移动标签 |
| 配置评估器 | Evaluations → New Evaluator |
| 创建数据集 | Datasets → New Dataset |
| 查看实验结果 | Experiments / Datasets → Runs |
| 配置模型单价 | Models → Add Model |
| 获取 API 密钥 | Settings → API Keys |
| 清空测试数据 | Settings → Danger Zone |
| 添加成员 | Settings → Members → Invite |
