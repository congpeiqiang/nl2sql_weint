# 10 · 自托管部署与运维

> Langfuse 自托管部署完整指南  
> 涵盖：Docker Compose 架构、组件拓扑、内存调优、运维命令、升级指南  
> 参考：[Langfuse Self-Hosting](https://langfuse.com/docs/deployment/self-host)

## 1. 部署架构

### 1.1 组件拓扑

```
   浏览器 / Agent SDK（NL2SQL Agent 等）
              │  HTTP 3001
              ▼
   ┌────────────────────────────────────────────┐
   │          Docker 网络 langfuse_default       │
   │                                            │
   │   ┌──────────────┐    ┌───────────┐        │
   │   │ langfuse-web │───▶│   redis   │ 队列/缓存│
   │   │  (UI + API)  │    └───────────┘        │
   │   └───────┬──────┘                         │
   │           │ 内部                        ┌───────────┐
   │   ┌───────▼──────┐                      │   minio   │ S3 媒体/事件
   │   │worker(入库)  │─────────────────────▶│           │
   │   └───────┬──────┘                      └───────────┘
   │           │ 写入
   │   ┌───────▼──────┐
   │   │  clickhouse  │   trace/观测数据
   │   └──────────────┘
   └───────────┬────────────────────────────────┘
               │ 172.17.0.1:5432（docker 网关 → 宿主机）
   ┌───────────▼────────────────────────────────┐
   │  宿主机 PostgreSQL 14.x（systemd 服务）    │ 账号/项目/元数据
   │  /var/lib/postgresql/14/main                │
   └────────────────────────────────────────────┘
```

### 1.2 组件说明

| 组件 | 运行方式 | 数据位置 | 用途 |
|------|----------|----------|------|
| **langfuse-web** | Docker 容器 | 无（应用代码） | UI + API 服务 |
| **langfuse-worker** | Docker 容器 | 无（应用代码） | 后台任务（入库、评估、数据保留） |
| **ClickHouse** | Docker 容器 | volume | trace/observation 事件数据 |
| **Redis** | Docker 容器 | volume | 上报队列、任务队列、缓存 |
| **MinIO** | Docker 容器 | volume | S3 媒体文件、事件文件 |
| **PostgreSQL** | 宿主机 systemd | `/var/lib/postgresql/` | 账号、项目、元数据 |

### 1.3 数据流

```
SDK/浏览器 → web（3001）→ Redis 队列 → worker 消费 → ClickHouse（trace/观测）
                                                  → PostgreSQL（账号/项目）
                                                  → MinIO（媒体/事件文件）
```

## 2. Docker Compose 部署

### 2.1 目录结构

```bash
/opt/langfuse/
├── docker-compose.yml    # 编排文件
├── .env                  # 环境变量（权限 600）
└── data/                 # 数据目录（可选）
```

### 2.2 docker-compose.yml 核心配置

```yaml
version: "3.8"

services:
  langfuse-web:
    image: langfuse/langfuse:4
    container_name: langfuse-web
    ports:
      - "3001:3000"
    environment:
      - DATABASE_URL=postgresql://langfuse:${PG_PASSWORD}@172.17.0.1:5432/langfuse
      - NEXTAUTH_SECRET=${NEXTAUTH_SECRET}
      - SALT=${SALT}
      - ENCRYPTION_KEY=${ENCRYPTION_KEY}
      - CLICKHOUSE_URL=http://clickhouse:8123
      - CLICKHOUSE_USER=${CH_USER}
      - CLICKHOUSE_PASSWORD=${CH_PASSWORD}
      - REDIS_HOST=redis
      - REDIS_PORT=6379
      - REDIS_AUTH=${REDIS_PASSWORD}
      - LANGFUSE_INIT_ORG_NAME=${INIT_ORG}
      - LANGFUSE_INIT_PROJECT_NAME=${INIT_PROJECT}
      - LANGFUSE_INIT_USER_EMAIL=${INIT_EMAIL}
      - LANGFUSE_INIT_USER_PASSWORD=${INIT_PASSWORD}
      - LANGFUSE_MIGRATION_V4_WRITE_MODE=dual
    depends_on:
      - redis
      - clickhouse
    mem_limit: 1600m
    restart: unless-stopped

  langfuse-worker:
    image: langfuse/langfuse-worker:4
    container_name: langfuse-worker
    environment:
      # 与 web 相同的数据库配置
      - DATABASE_URL=postgresql://langfuse:${PG_PASSWORD}@172.17.0.1:5432/langfuse
      - CLICKHOUSE_URL=http://clickhouse:8123
      - REDIS_HOST=redis
      - REDIS_AUTH=${REDIS_PASSWORD}
    depends_on:
      - redis
      - clickhouse
    mem_limit: 512m
    restart: unless-stopped

  clickhouse:
    image: clickhouse/clickhouse-server:25.12
    container_name: langfuse-clickhouse
    volumes:
      - clickhouse_data:/var/lib/clickhouse
    mem_limit: 900m
    restart: unless-stopped

  redis:
    image: redis:7
    container_name: langfuse-redis
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis_data:/data
    mem_limit: 128m
    restart: unless-stopped

  minio:
    image: minio/minio
    container_name: langfuse-minio
    command: server /data --console-address ":9091"
    ports:
      - "9090:9000"    # S3 API
    volumes:
      - minio_data:/data
    environment:
      - MINIO_ROOT_USER=${MINIO_USER}
      - MINIO_ROOT_PASSWORD=${MINIO_PASSWORD}
    mem_limit: 256m
    restart: unless-stopped

volumes:
  clickhouse_data:
  redis_data:
  minio_data:
```

### 2.3 .env 文件

```bash
# PostgreSQL
PG_PASSWORD=your_secure_password

# ClickHouse
CH_USER=clickhouse
CH_PASSWORD=your_secure_password

# Redis
REDIS_PASSWORD=your_secure_password

# MinIO
MINIO_USER=minio
MINIO_PASSWORD=your_secure_password

# Langfuse 初始化
NEXTAUTH_SECRET=$(openssl rand -base64 32)
SALT=$(openssl rand -base64 32)
ENCRYPTION_KEY=$(openssl rand -hex 32)
INIT_ORG=AgentLab
INIT_PROJECT=default
INIT_EMAIL=admin@langfuse.local
INIT_PASSWORD=YourStrongPassword

# v4 迁移模式
LANGFUSE_MIGRATION_V4_WRITE_MODE=dual
```

### 2.4 启动

```bash
cd /opt/langfuse
chmod 600 .env
sudo docker compose up -d

# 检查状态
sudo docker compose ps
```

## 3. 端口与安全

### 3.1 端口规划

| 服务 | 端口 | 绑定 | 安全组 |
|------|------|------|--------|
| langfuse-web (UI/API) | 3001 | 0.0.0.0 | ✅ 放行 |
| MinIO S3 API | 9090 | 0.0.0.0 | ✅ 放行 |
| PostgreSQL | 5432 | 0.0.0.0 | ✅ 仅限可信来源 |
| MinIO 控制台 | 9091 | 127.0.0.1 | ❌ 仅本机 |
| ClickHouse | 8123/9000 | 127.0.0.1 | ❌ 仅本机 |
| Redis | 6379 | 127.0.0.1 | ❌ 仅本机 |

### 3.2 安全建议

- `.env` 文件权限 `600`
- PostgreSQL 限制 `pg_hba.conf` 仅允许可信 IP
- Redis 设置强密码
- 定期更换密钥
- 不对外暴露 ClickHouse 和 Redis

## 4. 运维命令

### 4.1 日常运维

```bash
cd /opt/langfuse

# 状态检查
sudo docker compose ps                      # 5 个容器（无 postgres 容器属正常）
curl http://localhost:3001/api/public/health # 健康检查

# 日志查看
sudo docker compose logs -f langfuse-web-1     # web 日志
sudo docker compose logs -f langfuse-worker-1  # worker 日志

# 重启
sudo docker compose restart                    # 重启全部
sudo docker compose restart langfuse-web-1     # 重启单个

# PostgreSQL（宿主机服务）
sudo systemctl status postgresql
sudo systemctl restart postgresql
```

### 4.2 数据查询

```bash
# ClickHouse 查询
sudo docker exec -it langfuse-clickhouse-1 clickhouse-client

# 查看最近 traces
SELECT name, timestamp, user_id FROM events_core ORDER BY timestamp DESC LIMIT 10;

# 查看评分分布
SELECT name, avg(value), count() FROM scores GROUP BY name;

# PostgreSQL 查询
psql -h 127.0.0.1 -U langfuse -d langfuse

# 查看项目列表
SELECT id, name, created_at FROM projects;
```

### 4.3 资源监控

```bash
# Docker 资源使用
sudo docker stats

# 磁盘使用
sudo docker system df
du -sh /var/lib/postgresql/14/main
```

### 4.4 内存调优

| 组件 | 默认内存 | 最小推荐 | 调优建议 |
|------|----------|----------|----------|
| langfuse-web | 1600m | 1024m | Node 堆 1024MB |
| langfuse-worker | 512m | 384m | 后台任务密集时可加 |
| ClickHouse | 900m | 512m | 数据量大时增加 |
| Redis | 128m | 64m | 队列积压时增加 |
| MinIO | 256m | 128m | 媒体文件多时增加 |

## 5. 升级指南

### 5.1 版本升级

```bash
cd /opt/langfuse

# 1. 拉取最新镜像
sudo docker compose pull

# 2. 滚动更新（会重建有变化的容器）
sudo docker compose up -d

# 3. 检查健康
curl http://localhost:3001/api/public/health
# 期望: {"status":"OK","version":"4.x.x"}
```

### 5.2 v3 → v4 迁移

v4 是重大架构升级，迁移需要注意：

| 事项 | 说明 |
|------|------|
| 写模式 | `LANGFUSE_MIGRATION_V4_WRITE_MODE=dual`（双写） |
| 读接口 | v3 读接口在 events_only 模式下不可用 |
| SDK | 必须升级到 `langfuse >= 4.x` |
| API | 新接口 `v2/observations`、`v3/scores` |

## 6. 备份与恢复

### 6.1 备份

```bash
# PostgreSQL 备份
pg_dump -h 127.0.0.1 -U langfuse langfuse > backup_$(date +%Y%m%d).sql

# ClickHouse 备份
sudo docker exec langfuse-clickhouse-1 clickhouse-client \
    --query "ALTER TABLE events_core FREEZE"

# Docker volumes
sudo docker run --rm -v langfuse_redis_data:/data -v $(pwd):/backup \
    alpine tar czf /backup/redis_$(date +%Y%m%d).tar.gz /data
```

### 6.2 恢复

```bash
# PostgreSQL 恢复
psql -h 127.0.0.1 -U langfuse langfuse < backup_20261014.sql

# Docker volumes 恢复
sudo docker run --rm -v langfuse_redis_data:/data -v $(pwd):/backup \
    alpine tar xzf /backup/redis_20261014.tar.gz -C /
```

## 7. 常见问题

### 7.1 容器不断重启

```bash
sudo docker compose logs langfuse-web-1 --tail 50
# 常见原因：PostgreSQL 连接失败、内存不足
```

### 7.2 ClickHouse 磁盘满

```bash
# 查看磁盘使用
sudo docker exec langfuse-clickhouse-1 df -h

# 清理旧数据（保留最近 90 天）
sudo docker exec langfuse-clickhouse-1 clickhouse-client \
    --query "ALTER TABLE events_core DELETE WHERE timestamp < now() - INTERVAL 90 DAY"
```

### 7.3 数据清理

通过 Langfuse UI 的 **Settings → Danger Zone** 可以：

- 清空项目数据
- 删除项目
- 设置数据保留策略
