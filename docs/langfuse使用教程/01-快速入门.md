# 01 · 快速入门

> 从零开始，5 分钟内完成第一条 trace 上报  
> 涵盖：安装、配置、SDK 直连、LangChain 集成、OpenTelemetry 接入

---

## 1. 环境准备

### 1.1 Python 环境要求

| 要求 | 值 |
|------|-----|
| Python 版本 | ≥ 3.10（推荐 3.11+） |
| SDK 版本 | `langfuse >= 4.14.0`（v4.x 必须） |
| 包管理器 | pip / uv / conda 均可 |

### 1.2 安装 SDK

**方式一：pip（最常用）**

```bash
pip install -U langfuse

# 验证
python -c "import langfuse; print(langfuse.version.__version__)"
# 期望: >= 4.14.0
```

**方式二：uv（更快的包管理器）**

```bash
uv pip install langfuse
```

**方式三：pyproject.toml（项目级依赖）**

```toml
[project]
dependencies = [
    "langfuse>=4.14.4",
]
```

```bash
# 安装
pip install -e .
# 或
uv sync
```

**方式四：conda**

```bash
conda activate your-env
pip install langfuse
```

> ⚠️ **v4 SDK 与 v2/v3 有重大 API 变化**：
> - `langfuse.trace()` → 已移除，改用 `start_as_current_observation()`
> - `langfuse.span()` → 已移除
> - `langfuse.generation()` → 已移除
> - `CallbackHandler` 从 `langfuse.callback` 迁移到 `langfuse.langchain`

## 2. 配置连接

### 2.1 获取 API 密钥

**Langfuse Cloud**：

1. 注册 [cloud.langfuse.com](https://cloud.langfuse.com)
2. 创建项目（或选择已有项目）
3. **Settings → API Keys** → Create new API keys
4. 保存 Public Key 和 Secret Key

**自托管实例**：

1. 打开自托管 Langfuse Web UI
2. 使用管理员分配的账号登录
3. **Settings → API Keys** → 复制密钥

### 2.2 配置方式（四选一）

#### 方式 A：环境变量（推荐，生产首选）

```bash
# Linux / macOS
export LANGFUSE_PUBLIC_KEY="pk-lf-xxxxxxxxxx"
export LANGFUSE_SECRET_KEY="sk-lf-xxxxxxxxxx"
export LANGFUSE_HOST="http://your-server:3001"    # 或 https://cloud.langfuse.com

# Windows PowerShell
$env:LANGFUSE_PUBLIC_KEY = "pk-lf-xxxxxxxxxx"
$env:LANGFUSE_SECRET_KEY = "sk-lf-xxxxxxxxxx"
$env:LANGFUSE_HOST = "http://your-server:3001"
```

代码中无需传参：

```python
from langfuse import Langfuse
langfuse = Langfuse()  # 自动从环境变量读取
```

#### 方式 B：代码直传（开发/测试用）

```python
from langfuse import Langfuse

langfuse = Langfuse(
    public_key="pk-lf-xxxxxxxxxx",
    secret_key="sk-lf-xxxxxxxxxx",
    host="http://your-server:3001",
)
```

#### 方式 C：.env 文件 + python-dotenv

```bash
# .env 文件（不要提交到 git！）
LANGFUSE_PUBLIC_KEY=pk-lf-xxxxxxxxxx
LANGFUSE_SECRET_KEY=sk-lf-xxxxxxxxxx
LANGFUSE_HOST=http://your-server:3001
```

```python
from dotenv import load_dotenv
load_dotenv()  # 加载 .env

from langfuse import Langfuse
langfuse = Langfuse()  # 自动从 os.environ 读取
```

#### 方式 D：get_client() 全局单例

```python
from langfuse import get_client

# 必须在环境变量加载之后调用
client = get_client()  # 进程级单例，读 LANGFUSE_* 环境变量
```

### 2.3 连通性检查

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 检查连接
try:
    result = langfuse.auth_check()
    if result:
        print("✅ Langfuse 连接成功")
    else:
        print("❌ 连接失败：请检查密钥和地址")
except Exception as e:
    print(f"❌ 连接异常：{e}")
```

**常见连通性问题**：

| 现象 | 原因 | 解决 |
|------|------|------|
| `Connection refused` | 服务未启动或端口错 | 确认 `LANGFUSE_HOST` 正确 |
| `401 Unauthorized` | 密钥错误 | 重新复制密钥 |
| `timeout` | 网络不通 | 检查防火墙/安全组 |
| `ModuleNotFoundError` | SDK 未装 | `pip install langfuse` |

## 3. 第一条 Trace（SDK 直连）

### 3.1 最小可运行示例

```python
from langfuse import Langfuse

langfuse = Langfuse()

# ━━━ 最外层 observation = trace 根节点 ━━━
with langfuse.start_as_current_observation(
    name="my-first-agent",          # trace 名称（低基数、稳定）
    as_type="agent",                 # 类型：agent = trace 根
    input="你好，帮我分析一下销售数据",
    metadata={                       # 附加信息
        "user": "demo-user",
        "source": "tutorial",
    },
) as trace:

    # ━━━ 子步骤 1：LLM 生成 ━━━
    with langfuse.start_as_current_observation(
        name="analyze-request",
        as_type="generation",        # LLM 调用
        model="gpt-4o",              # 模型名（用于成本计算）
        model_parameters={
            "temperature": 0.7,
            "max_tokens": 1000,
        },
        input={"messages": [
            {"role": "system", "content": "你是一个数据分析助手"},
            {"role": "user", "content": "分析销售数据"},
        ]},
    ) as gen:
        response = "根据分析，本月销售额同比增长 15%..."  # 替换为真实 LLM 调用
        gen.update(output={"content": response})

    # ━━━ 子步骤 2：工具调用 ━━━
    with langfuse.start_as_current_observation(
        name="fetch-data",
        as_type="tool",              # 工具调用
        input={"query": "SELECT SUM(amount) FROM sales WHERE month = CURRENT_MONTH"},
    ) as span:
        data = {"total": 1250000, "growth": "15%"}  # 替换为真实查询
        span.update(output=data)

    # ━━━ 设置 trace 级输出 ━━━
    langfuse.set_current_trace_io(
        input="你好，帮我分析一下销售数据",
        output=response,
    )

    # ━━━ 打分 ━━━
    langfuse.score_current_trace(
        name="response-quality",
        value=0.85,
        comment="回答准确但缺少图表",
    )

# ⚠️ 必须调用 flush()，否则数据不会上报到服务端！
langfuse.flush()
print("✅ Trace 已上报，请到 Langfuse UI 查看")
```

### 3.2 运行验证

```bash
python your_script.py
```

预期输出：

```
✅ Trace 已上报，请到 Langfuse UI 查看
```

然后打开 Langfuse Web UI → **Traces** → 刷新列表，应看到名为 `my-first-agent` 的 trace。

### 3.3 完整 NL2SQL 示例

```python
from langfuse import Langfuse

langfuse = Langfuse()

def nl2sql_agent(question: str, db_name: str = "chinook"):
    """模拟一个 NL2SQL Agent 的完整执行流程"""

    with langfuse.start_as_current_observation(
        name="nl2sql-agent",
        as_type="agent",
        input=question,
        metadata={
            "db_name": db_name,
            "user": "demo-user",
            "session_type": "nl2sql",
        },
        session_id=f"session-{db_name}-001",
        user_id="demo-user",
    ):
        # ━━━ Phase 1: Schema Discovery ━━━
        with langfuse.start_as_current_observation(
            name="schema-linking",
            as_type="chain",
            input={"question": question, "db": db_name},
        ) as schema_span:
            # 模拟 LLM 识别相关表和字段
            with langfuse.start_as_current_observation(
                name="llm-schema-identify",
                as_type="generation",
                model="gpt-4o",
                model_parameters={"temperature": 0},
                input={"prompt": f"Identify relevant tables for: {question}"},
            ) as gen:
                schema_info = {
                    "tables": ["artist", "album"],
                    "columns": ["artist.name", "album.title", "album.artistid"],
                    "joins": "artist.artistid = album.artistid",
                }
                gen.update(output=schema_info)
            schema_span.update(output=schema_info)

        # ━━━ Phase 2: SQL Generation ━━━
        with langfuse.start_as_current_observation(
            name="sql-generation",
            as_type="chain",
            input={"question": question, "schema": schema_info},
        ) as sql_span:
            with langfuse.start_as_current_observation(
                name="llm-sql-generate",
                as_type="generation",
                model="gpt-4o",
                model_parameters={"temperature": 0},
                input={"prompt": f"Generate SQL for: {question} using {schema_info}"},
            ) as gen:
                sql = "SELECT COUNT(*) AS artist_count FROM artist"
                gen.update(output=sql)
            sql_span.update(output=sql)

        # ━━━ Phase 3: SQL Execution ━━━
        with langfuse.start_as_current_observation(
            name="execute-sql",
            as_type="tool",
            input={"sql": sql, "db": db_name},
        ) as exec_span:
            # 模拟执行
            result = {"rows": [{"artist_count": 275}], "row_count": 1, "error": None}
            exec_span.update(output=result)

        # ━━━ Phase 4: Response Generation ━━━
        with langfuse.start_as_current_observation(
            name="generate-response",
            as_type="generation",
            model="gpt-4o",
            input={"sql_result": result, "question": question},
        ) as gen:
            answer = f"根据查询结果，{db_name} 数据库的 artist 表共有 275 位艺术家。"
            gen.update(output=answer)

        # ━━━ 五维评分 ━━━
        # 确定性评估（同步、零成本）
        langfuse.score_current_trace(name="schema_match_score", value=1.0)
        langfuse.score_current_trace(name="sql_valid_score", value=1.0,
                                     comment="SELECT 只读查询，含 LIMIT")
        langfuse.score_current_trace(name="sql_exec_success", value=1.0,
                                     comment="执行成功，返回 1 行")

        # LLM-Judge 评估（模拟异步）
        langfuse.score_current_trace(name="sql_biz_correct_score", value=0.9,
                                     comment="SQL 正确回答了用户问题")

        # 设置 trace 输出
        langfuse.set_current_trace_io(input=question, output=answer)

    langfuse.flush()
    return answer

# 运行
answer = nl2sql_agent("统计 artist 表有多少艺术家")
print(f"Answer: {answer}")
```

## 4. LangChain 集成接入

如果你的项目使用 LangChain，可以用 `CallbackHandler` 自动追踪，无需手写埋点：

### 4.1 安装额外依赖

```bash
pip install langfuse langchain langchain-openai
```

### 4.2 基础集成

```python
from langfuse.langchain import CallbackHandler
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

# 创建 Langfuse 回调处理器
handler = CallbackHandler()

# 创建 LangChain 模型，注入回调
llm = ChatOpenAI(model="gpt-4o", callbacks=[handler])

# 正常调用 — trace 自动上报
response = llm.invoke([HumanMessage(content="你好")])

# ⚠️ 必须 flush
handler.flush()
```

### 4.3 LangGraph Agent 集成

```python
from langfuse.langchain import CallbackHandler
from langgraph.graph import StateGraph, MessagesState

handler = CallbackHandler()

# 创建 Agent
graph = create_react_agent(model, tools)

# 通过 config 注入回调
config = {
    "recursion_limit": 50,
    "callbacks": [handler],
}

# 运行 — 完整 trace 自动上报（含工具调用、多步推理）
result = graph.invoke(
    {"messages": [("user", "统计 artist 表有多少艺术家")]},
    config=config,
)

handler.flush()
```

> 💡 **优势**：CallbackHandler 会自动捕获 LLM 调用（模型名、token、耗时、成本）、工具调用（参数、结果）、Agent 链路（规划、决策），无需任何手动埋点。

详细集成方案见 [09-LangChain 集成](09-LangChain集成.md)。

## 5. OpenTelemetry (OTLP) 接入

v4 原生支持 OTel，适合非 Python 语言或需要与已有 OTel 基础设施集成的场景：

### 5.1 环境变量配置

```bash
OTEL_EXPORTER_OTLP_ENDPOINT=http://your-server:3001/api/public/otel
OTEL_EXPORTER_OTLP_HEADERS=Authorization=Basic $(echo -n "pk-xxx:sk-xxx" | base64)
OTEL_SERVICE_NAME=nl2sql-agent
```

### 5.2 Python OTel SDK

```python
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor

# 配置 OTel
provider = TracerProvider()
exporter = OTLPSpanExporter(
    endpoint="http://your-server:3001/api/public/otel/v1/traces",
    headers={"Authorization": f"Basic {base64_credentials}"},
)
provider.add_span_processor(BatchSpanProcessor(exporter))
trace.set_tracer_provider(provider)

# 使用
tracer = trace.get_tracer("nl2sql")
with tracer.start_as_current_span("generate-sql") as span:
    span.set_attribute("input.question", "统计 artist 表行数")
    sql = generate_sql()
    span.set_attribute("output.sql", sql)
```

## 6. 核心 API 速查

### 6.1 Observation 类型

| `as_type` | 用途 | 自动记录 |
|-----------|------|----------|
| `agent` | Agent 根节点（= trace） | 输入输出、metadata |
| `generation` | LLM 调用 | 模型名、token、成本、延迟 |
| `tool` | 工具调用 | 参数、结果、错误 |
| `span` | 通用步骤 | 输入输出 |
| `chain` | 链式调用 | 输入输出 |
| `retriever` | 检索 | 查询、文档列表 |
| `embedding` | 嵌入计算 | 模型、维度 |
| `evaluator` | 评估 | 评分结果 |
| `guardrail` | 护栏 | 检查结果 |

### 6.2 常用操作

```python
# 开启根节点（=trace）
with langfuse.start_as_current_observation(name="...", as_type="agent", input=...) as trace:

# 子节点 span/tool
with langfuse.start_as_current_observation(name="...", as_type="span" | "tool", ...):

# LLM 记录（带模型和参数）
with langfuse.start_as_current_observation(
    name="...", as_type="generation",
    model="gpt-4o",
    model_parameters={"temperature": 0},
    input=..., output=...,
):

# 动态更新输出/元数据
obs.update(output=...)
obs.update(metadata={"key": "value"})

# trace 级 IO
langfuse.set_current_trace_io(input=..., output=...)

# 打分
langfuse.score_current_trace(name="...", value=0.85, comment="...")
langfuse.score_current_span(name="...", value=1.0)

# 生成 trace ID（跨服务传递）
tid = langfuse.create_trace_id()

# 刷盘（程序退出前必调）
langfuse.flush()

# 连通性检查
langfuse.auth_check()
```

### 6.3 进程退出自动 flush

```python
import atexit
from langfuse import Langfuse

langfuse = Langfuse()
atexit.register(langfuse.flush)  # 进程退出时自动刷盘
```
