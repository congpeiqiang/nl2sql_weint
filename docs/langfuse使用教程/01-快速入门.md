# 01 · 快速入门

> 5 分钟内完成第一条 trace 上报

---

## 1. 安装 SDK

```bash
pip install -U langfuse

# 验证版本（需要 v4.x）
python -c "import langfuse; print(langfuse.version.__version__)"
# 期望输出 >= 4.14.0
```

> ⚠️ v4 SDK 与 v2/v3 的 API 有重大变化。旧版 `langfuse.trace()` 方法已移除，改用 `start_as_current_observation()` 上下文管理器。

## 2. 配置连接

### 方式一：代码直传

```python
from langfuse import Langfuse

langfuse = Langfuse(
    public_key="pk-lf-xxx",          # 替换为你的 Public Key
    secret_key="sk-lf-xxx",          # 替换为你的 Secret Key
    host="http://your-host:3001",    # 自托管地址或 https://cloud.langfuse.com
)
```

### 方式二：环境变量（推荐）

```bash
export LANGFUSE_PUBLIC_KEY="pk-lf-xxx"
export LANGFUSE_SECRET_KEY="sk-lf-xxx"
export LANGFUSE_HOST="http://your-host:3001"
```

```python
from langfuse import Langfuse

# 自动从环境变量读取
langfuse = Langfuse()
```

### 获取密钥

1. 登录 Langfuse Web UI
2. 进入 **Settings → API Keys**
3. 复制 Public Key 和 Secret Key

> 🔒 Secret Key 只在创建时显示一次，请妥善保存。

## 3. 连通性检查

```python
# 检查连接是否正常
result = langfuse.auth_check()
print(result)  # True = 连接成功
```

## 4. 第一条 Trace

### 4.1 最小示例

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 最外层 observation（as_type="agent"）= trace 根节点
with langfuse.start_as_current_observation(
    name="my-first-agent",
    as_type="agent",
    input="你好，帮我查一下销售数据",
) as trace:
    # 模拟一个 LLM 生成步骤
    with langfuse.start_as_current_observation(
        name="generate-response",
        as_type="generation",
        model="gpt-4o",
        model_parameters={"temperature": 0.7},
        input={"prompt": "你是一个数据分析助手..."},
    ) as gen:
        response = "根据销售数据，本月同比增长 15%"
        gen.update(output=response)

    # 设置 trace 输出
    langfuse.set_current_trace_io(
        input="你好，帮我查一下销售数据",
        output=response,
    )

# ⚠️ 程序退出前必须调用 flush()，否则数据不会上报！
langfuse.flush()
```

### 4.2 NL2SQL 示例

```python
from langfuse import Langfuse

langfuse = Langfuse()

def nl2sql_agent(question: str):
    with langfuse.start_as_current_observation(
        name="nl2sql",
        as_type="agent",
        input=question,
        metadata={"db": "chinook", "user": "demo-user"},
    ):
        # Step 1: LLM 生成 SQL
        with langfuse.start_as_current_observation(
            name="generate-sql",
            as_type="generation",
            model="gpt-4o",
            model_parameters={"temperature": 0},
            input={"question": question},
        ) as gen:
            sql = "SELECT COUNT(*) FROM artist"  # 替换为你的 LLM 调用
            gen.update(output=sql)

        # Step 2: 执行 SQL
        with langfuse.start_as_current_observation(
            name="execute-sql",
            as_type="tool",
            input={"sql": sql},
        ) as span:
            result = {"row_count": 275, "error": None}
            span.update(output=result)

        # Step 3: 打分
        langfuse.score_current_trace(
            name="sql-correctness",
            value=1.0,
            comment="SQL 正确执行，返回预期结果",
        )

    langfuse.flush()
    return result

nl2sql_agent("统计 artist 表有多少艺术家")
```

## 5. 查看结果

1. 打开 Langfuse Web UI
2. 进入 **Traces** 页面
3. 刷新列表，应能看到刚上报的 trace
4. 点击 trace 查看详情：时间线树、输入输出、token 消耗、打分

## 6. 核心概念速查

| 概念 | 说明 | 对应 API |
|------|------|----------|
| **Trace** | 一次完整的 Agent 任务 | 最外层 `start_as_current_observation(as_type="agent")` |
| **Observation** | Trace 内的一个步骤 | `start_as_current_observation(as_type=...)` |
| **Generation** | LLM 调用（记录模型/token/成本） | `as_type="generation"` |
| **Span** | 通用步骤（非 LLM） | `as_type="span"` |
| **Tool** | 工具调用 | `as_type="tool"` |
| **Score** | 评估打分 | `score_current_trace()` / `score_current_span()` |
| **Session** | 多轮会话分组 | `session_id` 参数 |
| **Metadata** | 附加信息 | `metadata={}` 参数 |

### `as_type` 可选值

```
generation / embedding / span / agent / tool /
chain / retriever / evaluator / guardrail
```
