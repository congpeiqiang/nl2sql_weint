# 06 · 数据集与实验

> Datasets & Experiments 是 Langfuse 的回归测试框架。  
> 本章覆盖：数据集管理、四维 A/B 实验、多臂对比、统计门禁、Expected Output 金标、双落点。  
> 参考：[Langfuse Datasets](https://langfuse.com/docs/evaluation/datasets)、[Experiments](https://langfuse.com/docs/evaluation/experiments)

---

## 1. 核心概念

### 1.1 数据模型

```
Dataset（数据集）
├── Item 1: { input, expected_output, metadata }
├── Item 2: { input, expected_output, metadata }
└── Item N: ...

Dataset Run（实验运行）
├── Run Item 1: trace_id + scores
├── Run Item 2: trace_id + scores
└── Run Score: 聚合评分（挂在 Run 上）

Experiment（实验实体）
├── experiment_id / experiment_name
├── experiment_dataset_id
├── experiment_item_id → 关联 Dataset Item
└── experiment_item_metadata → Expected Output 金标
```

### 1.2 关系图

```
Dataset ──1:N──▶ Dataset Item ──1:N──▶ Dataset Run Item ──▶ Trace
                     │                      │
                     └── expected_output    └── Run Score（聚合分）
                            ↓
                    Experiment Item（OTel 属性注入）
                            ↓
                    Experiment 页面（Expected Output 列展示）
```

## 2. 创建数据集

### 2.1 通过 UI

1. **Datasets → New Dataset**
2. 填写名称和描述

### 2.2 通过 SDK

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 创建数据集
langfuse.create_dataset(
    name="nl2sql-regression",
    description="NL2SQL 回归测试集：覆盖 count / top-n / join / 聚合 四类查询",
)

# 批量添加 item
items = [
    {
        "input": {"question": "统计 artist 表有多少艺术家"},
        "expected_output": {
            "sql": "SELECT COUNT(*) AS artist_count FROM artist",
        },
        "metadata": {
            "db_name": "chinook",
            "category": "count",
            "difficulty": "easy",
        },
    },
    {
        "input": {"question": "列出销量最高的 5 张专辑"},
        "expected_output": {
            "sql": "SELECT a.title, SUM(il.quantity) as total FROM album a JOIN track t ON a.albumid = t.albumid JOIN invoiceline il ON t.trackid = il.trackid GROUP BY a.title ORDER BY total DESC LIMIT 5",
        },
        "metadata": {
            "db_name": "chinook",
            "category": "top-n",
            "difficulty": "medium",
        },
    },
    {
        "input": {"question": "哪个国家的客户最多"},
        "expected_output": {
            "sql": "SELECT country, COUNT(*) as cnt FROM customer GROUP BY country ORDER BY cnt DESC LIMIT 1",
        },
        "metadata": {
            "db_name": "chinook",
            "category": "aggregation",
            "difficulty": "easy",
        },
    },
]

for item in items:
    langfuse.create_dataset_item(
        dataset_name="nl2sql-regression",
        input=item["input"],
        expected_output=item["expected_output"],
        metadata=item["metadata"],
    )

langfuse.flush()
```

采集规则：

| 条件 | 阈值 | 说明 |
|------|------|------|
| 用户差评 | `user-feedback = 0` | 用户点了 👎 |
| 业务正确性低 | `sql_biz_correct < 0.6` | LLM Judge 判定不正确 |
| 执行失败 | `sql_exec_success = 0` | SQL 执行报错 |

### 2.4 Dataset Item 字段契约

本项目的 Item 遵循统一字段契约：

```json
{
    "input": {
        "question": "用户的问题文本"
    },
    "expected_output": {
        "sql": "标准 SQL（机器可读权威）",
        "cube": "Cube 聚合规范（报表类查询，可选）"
    },
    "metadata": {
        "db_name": "chinook",
        "category": "aggregation",
        "difficulty": "medium",
        "source_trace_id": "原始 trace ID（回溯用）",
        "scores": {"sql_biz_correct": 0.25},
        "reasons": ["sql_biz_correct_score=0.25", "user_feedback=0"],
        "user_note": "用户评论（可选）"
    }
}
```

| 字段 | 用途 | 是否必须 |
|------|------|----------|
| `input.question` | 实验时的输入 | ✅ |
| `expected_output.sql` | 标准答案 SQL（回归对比基准） | 推荐 |
| `expected_output.cube` | Cube 聚合规范 | 可选 |
| `metadata.source_trace_id` | 回溯到原始 trace | 自动 |
| `metadata.scores` | 采集时的评分快照 | 自动 |

## 3. 运行实验

### 3.1 基础实验（单臂）

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 获取数据集
dataset = langfuse.get_dataset(name="nl2sql-regression")
run_name = f"v1.1-prompt-fix-{datetime.now():%Y%m%d-%H%M}"

scores = []

for item in dataset.items:
    # 用 Agent 处理每条测试用例
    with langfuse.start_as_current_observation(
        name="experiment-run",
        as_type="agent",
        input=item.input,
    ):
        # 运行 Agent
        result = nl2sql_agent(item.input["question"])

        # 评估结果
        score = evaluate_sql_result(result, item.expected_output)
        scores.append(score)

        langfuse.score_current_trace(name="experiment-score", value=score)

    # 关联到 Dataset Run
    langfuse.create_dataset_run_item(
        dataset_name="nl2sql-regression",
        dataset_item_id=item.id,
        run_name=run_name,
        run_metadata={
            "prompt_version": "v1.1",
            "model": "gpt-4o",
        },
    )

avg = sum(scores) / len(scores)
print(f"Run [{run_name}]: avg={avg:.3f}, items={len(scores)}")
langfuse.flush()
```

### 3.2 多臂 A/B 实验

```python
def run_experiment_arm(arm_name, prompt_label, skill_ref=None, semantic_ref=None, dataset_name="nl2sql-regression"):
    """运行一个实验臂
    
    四维 A/B：
    - prompt_label: prompt 版本标签
    - skill_ref: skill git 版本
    - semantic_ref: 语义库 git 版本
    - dataset: 数据集名称
    """
    dataset = langfuse.get_dataset(name=dataset_name)
    run_name = f"{arm_name}:{semantic_ref or 'head'}@{datetime.now():%Y%m%d}"
    records = []

    for item in dataset.items:
        # 设置实验环境（进程级注入）
        env = {
            "LANGFUSE_PROMPT_LABEL": prompt_label,
            "LANGFUSE_TRACING_ENVIRONMENT": "experiment",
        }
        if skill_ref:
            env["SKILLS_REF"] = skill_ref
        if semantic_ref:
            env["WREN_SEMANTIC_OVERRIDE"] = semantic_ref

        with langfuse.start_as_current_observation(
            name=f"experiment-{arm_name}",
            as_type="agent",
            input=item.input,
        ):
            # 注入实验属性（Experiment 页面可见）
            otel_trace = otel_trace_api.get_current_span()
            otel_trace.set_attribute("langfuse.experiment.experiment_id", f"exp-{run_name}")
            otel_trace.set_attribute("langfuse.experiment.experiment_name", run_name)
            otel_trace.set_attribute("langfuse.experiment.item.item_id", item.id)
            
            # Expected Output 金标（Experiment 页面 Expected Output 列）
            if item.expected_output:
                otel_trace.set_attribute(
                    "langfuse.experiment.item.expected_output",
                    json.dumps(item.expected_output),
                )

            # 运行 Agent
            result = nl2sql_agent(item.input["question"])
            score = evaluate(result, item.expected_output)
            records.append({"question": item.input["question"], "score": score, "trace_id": ...})

            langfuse.score_current_trace(name=f"{arm_name}-score", value=score)

        # Dataset Run Item
        langfuse.create_dataset_run_item(
            dataset_name=dataset_name,
            dataset_item_id=item.id,
            run_name=run_name,
        )

    return records

# ━━━ 运行两个臂对比 ━━━
baseline_records = run_experiment_arm("baseline", "production", semantic_ref="v1.1.1")
candidate_records = run_experiment_arm("candidate", "staging", semantic_ref="v1.1.1")
```

### 3.3 统计门禁

```python
CORE_DIMS = ("sql_biz_correct_score", "sql_valid_score", "sql_exec_success")
THRESHOLD = 0.05

def gate_check(baseline_scores, candidate_scores):
    """双门槛门禁
    
    判据 1：overall 核心维均值 candidate ≥ baseline - threshold
    判据 2：A 类策略核心维 candidate ≥ baseline - threshold
    任一不满足 → exit 1（阻止发版）
    """
    for dim in CORE_DIMS:
        b_avg = mean([r[dim] for r in baseline_records])
        c_avg = mean([r[dim] for r in candidate_records])
        
        if c_avg < b_avg - THRESHOLD:
            print(f"❌ 门禁失败: {dim} 退化 {b_avg:.3f} → {c_avg:.3f}")
            return False
    
    print(f"✅ 门禁通过")
    return True
```

## 4. 四维 A/B 实验（本项目实践）

### 4.1 四个维度

| 维度 | 参数 | 说明 | 默认值 |
|------|------|------|--------|
| 数据集 | `--datasets` | 多选数据集名称 | `badcase` |
| Prompt 版本 | `--prompt-label` | prompt 标签 | `production` |
| Skill 版本 | `--skill-ref` | git tag/branch | 当前磁盘 |
| 语义库版本 | `--semantic-ref` | git tag/branch | 当前 HEAD |

### 4.2 CLI 方式

```bash
# 基础双臂对比
PYTHONPATH=src .venv/Scripts/python.exe -m agent.eval.run_experiment \
    --dataset nl2sql-regression \
    --labels production staging \
    --run-name "prompt-comparison-20261014"

# 四维全指定
PYTHONPATH=src .venv/Scripts/python.exe -m agent.eval.run_experiment \
    --datasets badcase goodcase \
    --arms '[
        {"name": "baseline", "prompt_label": "production", "skill_ref": "v1.0", "semantic_ref": "v1.1.1"},
        {"name": "candidate", "prompt_label": "staging", "skill_ref": "v1.1", "semantic_ref": "v1.1.1"}
    ]' \
    --threshold 0.05 \
    --judge  # 启用 LLM-Judge

# BadCase 回归
PYTHONPATH=src .venv/Scripts/python.exe -m agent.eval.run_experiment \
    --from-badcase \
    --labels production staging \
    --run-name "fix-join-logic"
```

## 6. 最佳实践

### 6.1 数据集维护

- **定期更新**：每周将新 BadCase 加入回归集
- **去重**：合并相似测试用例（`(question, db_name)` 去重）
- **分层**：按难度/类别/数据库分多个数据集
- **状态管理**：`pending` → `reviewed` → `fixed` / `invalid`
- **固定 BadCase 过滤**：`fixed`/`invalid` 状态的 item 不参与回归

### 6.2 Run Name 规范

```
✅ v1.2-fix-join-logic-20261014
✅ prompt-canary-10pct-20261014
✅ baseline:v1.1.1@20261014
❌ test-run-1
❌ experiment
```
