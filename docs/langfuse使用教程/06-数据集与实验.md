# 06 · 数据集与实验

> Datasets & Experiments 是 Langfuse 的回归测试框架：沉淀测试用例 → 批量跑 Agent → 对比评分 → 门禁发版。

---

## 1. 核心概念

```
Dataset（数据集）
├── Item 1: {input: "统计 artist 表行数", expected_output: "SELECT COUNT(*) FROM artist"}
├── Item 2: {input: "最畅销的专辑 Top5", expected_output: "SELECT ... LIMIT 5"}
└── Item 3: {input: "...", expected_output: "..."}

Dataset Run（实验运行）
├── Run "v1.0-baseline":   跑完所有 Item → 评分均值 0.82
├── Run "v1.1-prompt-fix": 跑完所有 Item → 评分均值 0.91  ✅ 改善
└── Run "v1.2-new-model":  跑完所有 Item → 评分均值 0.78  ❌ 退化
```

| 概念 | 说明 |
|------|------|
| **Dataset** | 一组测试用例的集合 |
| **Dataset Item** | 一条测试用例（input + expected_output + metadata） |
| **Dataset Run** | 在某个数据集上的一次完整运行 |
| **Run Item** | 单个 Item 的运行结果 |
| **Run Score** | 整个 Run 的聚合评分 |

## 2. 创建数据集

### 2.1 通过 UI

1. 进入 **Datasets** 页面
2. 点击 **New Dataset**
3. 输入名称（如 `"nl2sql-regression"`）和描述
4. 手动添加测试用例

### 2.2 通过 SDK

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 创建数据集
langfuse.create_dataset(name="nl2sql-regression", description="NL2SQL 回归测试集")

# 添加测试用例
langfuse.create_dataset_item(
    dataset_name="nl2sql-regression",
    input={"question": "统计 artist 表有多少艺术家"},
    expected_output={"sql": "SELECT COUNT(*) FROM artist", "expected_rows": 1},
    metadata={
        "db": "chinook",
        "category": "count",
        "difficulty": "easy",
    },
)

langfuse.create_dataset_item(
    dataset_name="nl2sql-regression",
    input={"question": "列出销量最高的 5 张专辑"},
    expected_output={
        "sql": "SELECT a.title, SUM(il.quantity) as total FROM album a JOIN track t ON a.albumid = t.albumid JOIN invoiceline il ON t.trackid = il.trackid GROUP BY a.title ORDER BY total DESC LIMIT 5",
    },
    metadata={
        "db": "chinook",
        "category": "top-n",
        "difficulty": "medium",
    },
)
```

## 3. 运行实验

### 3.1 基础实验

```python
from langfuse import Langfuse

langfuse = Langfuse()

# 获取数据集
dataset = langfuse.get_dataset(name="nl2sql-regression")

run_name = f"v1.1-prompt-fix-{datetime.now():%Y%m%d}"

for item in dataset.items:
    # 用你的 Agent 处理每条测试用例
    with langfuse.start_as_current_observation(
        name="experiment-run",
        as_type="agent",
        input=item.input,
    ):
        # 运行 Agent
        result = nl2sql_agent(item.input["question"])
        
        # 评估结果
        score = evaluate(result, item.expected_output)
        
        # 记录到 Dataset Run
        langfuse.score_current_trace(
            name="experiment-score",
            value=score,
        )

    # 将此 trace 关联到 Dataset Run
    langfuse.create_dataset_run_item(
        dataset_name="nl2sql-regression",
        dataset_item_id=item.id,
        run_name=run_name,
        run_metadata={
            "prompt_version": "v1.1",
            "model": "gpt-4o",
        },
    )

langfuse.flush()
```

### 3.2 A/B 实验（多臂对比）

```python
def run_experiment_arm(arm_name, prompt_label, dataset_name):
    """运行一个实验臂"""
    dataset = langfuse.get_dataset(name=dataset_name)
    scores = []

    for item in dataset.items:
        with langfuse.start_as_current_observation(
            name=f"experiment-{arm_name}",
            as_type="agent",
            input=item.input,
        ):
            # 使用指定标签的 prompt
            prompt = langfuse.get_prompt(
                name="nl2sql_system_prompt",
                label=prompt_label,
            )
            result = nl2sql_agent(item.input["question"], system_prompt=prompt.prompt)
            score = evaluate(result, item.expected_output)
            scores.append(score)

            langfuse.score_current_trace(
                name=f"{arm_name}-score",
                value=score,
            )

    avg_score = sum(scores) / len(scores)
    print(f"Arm [{arm_name}]: avg_score={avg_score:.3f}")
    return avg_score

# 运行两个臂对比
baseline_score = run_experiment_arm("baseline", "production", "nl2sql-regression")
candidate_score = run_experiment_arm("candidate", "staging", "nl2sql-regression")

# 回归门禁
THRESHOLD = 0.05
if candidate_score < baseline_score - THRESHOLD:
    print(f"❌ 回归！candidate({candidate_score:.3f}) < baseline({baseline_score:.3f}) - {THRESHOLD}")
    exit(1)
else:
    print(f"✅ 通过门禁")
    exit(0)
```

## 4. 查看实验结果

### 4.1 UI 查看

1. 进入 **Datasets** → 选择数据集
2. 点击 **Runs** 标签
3. 查看所有运行记录：

- 定位哪些 Item 退步了
- 查看每个 Item 的 trace 详情

## 5. Dataset Item 字段契约

本项目的 Dataset Item 遵循统一字段契约：

```json
{
  "input": {
    "question": "用户的问题文本"
  },
  "expected_output": {
    "sql": "标准 SQL（机器可读权威）",
    "cube": "Cube 聚合规范（可选）"
  },
  "metadata": {
    "db_name": "chinook",
    "category": "aggregation",
    "difficulty": "medium",
    "source_trace_id": "原始 trace ID",
    "scores": {"sql_biz_correct": 0.25},
    "reason": "采集原因说明",
    "user_note": "用户评论（可选）"
  }
}
```

| 字段 | 用途 |
|------|------|
| `input.question` | 用户提问（实验时的输入） |
| `expected_output.sql` | 标准答案 SQL（回归对比基准） |
| `expected_output.cube` | Cube 聚合规范（报表类查询） |
| `metadata.source_trace_id` | 回溯到原始 trace |
| `metadata.scores` | 采集时的评分快照 |

## 6. 最佳实践

### 6.1 数据集维护

- **定期更新**：每周将新的 BadCase 加入回归集
- **去重**：合并相似的测试用例
- **分层**：按难度/类别/数据库分多个数据集
- **标记状态**：`pending` → `reviewed` → `fixed` / `invalid`

### 6.2 实验命名

建议使用有意义的 Run Name：

```
✅ v1.2-fix-join-logic-20261014
✅ prompt-canary-10pct-20261014
❌ test-run-1
❌ experiment
```

### 6.3 回归门禁

设置自动化的回归门禁（CI/CD 集成）：

```bash
# 发版前必须通过
python -m agent.eval.run_experiment \
    --dataset nl2sql-regression \
    --prompt-label staging \
    --threshold 0.05 \
    --run-name "pre-release-$(date +%Y%m%d)"

# exit 0 = 通过，可以发版
# exit 1 = 退化，阻止发版
```
