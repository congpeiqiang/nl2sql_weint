## 1. Trace 上报问题

### 1.1 UI 里看不到新 trace

**排查流程**：

```
1. 代码是否调用了 flush()?
   └─ 否 → 添加 langfuse.flush()
   └─ 是 → 继续

2. LANGFUSE_ENABLE 是否为 true?
   └─ 否 → 设为 true
   └─ 是 → 继续

3. Host/密钥是否正确?
   └─ python -c "from langfuse import Langfuse; print(Langfuse().auth_check())"
   └─ False → 检查配置
   └─ True → 继续

4. SDK 版本是否 >= 4.x?
   └─ python -c "import langfuse; print(langfuse.version.__version__)"
   └─ < 4.0 → pip install -U langfuse
   └─ >= 4.0 → 继续

5. 服务是否正常运行?
   └─ curl http://host:3001/api/public/health
   └─ 失败 → 检查服务状态
   └─ 正常 → 检查 UI 筛选条件（时间范围、名称过滤）
```

**快速验证脚本**：

```python
"""debug_trace.py — 验证 trace 上报链路"""
from langfuse import Langfuse

langfuse = Langfuse()

# Step 1: 连通性
print(f"SDK: v{langfuse.version.__version__}")
print(f"Host: {langfuse.host}")
print(f"Auth: {langfuse.auth_check()}")

# Step 2: 手动上报
import uuid
test_id = f"debug-{uuid.uuid4().hex[:8]}"
with langfuse.start_as_current_observation(
    name=test_id, as_type="agent", input="debug test",
):
    pass
langfuse.flush()
print(f"✅ 已上报 trace: {test_id}")
print(f"请在 UI 中搜索名称: {test_id}")
```

### 1.2 trace 有但缺少 token / 成本

| 原因 | 解决 |
|------|------|
| `model` 参数未填 | `as_type="generation", model="gpt-4o"` |
| 模型未在 Models 页配置单价 | Settings → Models → 添加模型和单价 |
| CallbackHandler 未正确捕获 | 确认 `callbacks=[handler]` 传入了正确的 handler |

### 1.3 trace 嵌套不正确

**症状**：子 Agent 的 observation 跑到了别的 trace 下，或成为独立 trace。

**排查**：

```bash
# 搜索日志中的 nesting 相关告警
grep "orphan\|leaf nesting\|parent_trace" logs/agent-server.log
```

**常见原因**：

| 原因 | 解决 |
|------|------|
| OTel context 丢失（跨线程） | 使用 `trace_context` 手动指定 |
| `langfuse_parent_trace_id` 未注入 | 检查 `deepagents_async_config_patch.py` |
| NonRecordingSpan 未正确设置 | 检查 `span_context` 构造 |

### 1.4 v4 SDK `langfuse.trace()` 报错

```python
# ❌ v2/v3 写法（v4 已移除）
trace = langfuse.trace(name="my-trace")
# AttributeError: 'Langfuse' object has no attribute 'trace'

# ✅ v4 写法
with langfuse.start_as_current_observation(name="my-trace", as_type="agent"):
    ...
```

## 2. 评估问题

### 2.1 LLM-Judge 没有触发

| 检查项 | 排查 |
|--------|------|
| 评估器是否启用 | Evaluations 页面检查状态 |
| 采样率是否为 0 | 检查 Sampling 配置 |
| 模型 API Key | Settings → Models 检查 |
| 模型调用超时 | 查看 worker 日志 |
| 评估队列堆积 | 检查 daemon worker 是否存活 |

### 2.2 评分不准确（Judge 失真）

参考 [04-评估与打分](04-评估与打分.md) §7 的七个失真源：

| 失真源 | 排查方法 |
|--------|----------|
| Judge 拿探路 SQL 当最终答案 | 检查评估单元 `final_sql` 是否正确 |
| 大结果只留 VFS 占位符 | 检查 `result_summary` 是否携带 |
| 报告被压缩到 2KB | 检查 `report.text_head` |
| 问题文本解析错误 | 检查评估单元 `question` |
| rubric 笼统 | 检查 Langfuse Prompt 中的 rubric |

### 2.3 用户反馈不写入

```bash
# 检查反馈写入日志
grep "user-feedback\|feedback.*score" logs/agent-server.log | tail -20

# 检查 trace_id 映射
grep "find_message_trace_id\|trace_bind" logs/agent-server.log | tail -20
```

## 3. Prompt 管理问题

### 3.1 启动时 prompt 拉取失败

```
日志: [langfuse] prompt 拉取失败，本地兜底: ...
```

| 原因 | 解决 |
|------|------|
| `LANGFUSE_PROMPT_ENABLED=0` | 改为 `1` |
| Prompt 在 Langfuse 中不存在 | 先执行 `sync_prompts` 上传 |
| 标签不存在 | 检查 `LANGFUSE_PROMPT_LABEL` 值 |
| 网络问题 | `curl http://host:3001/api/public/health` |
| v4 events_only 模式 | 读接口可能受限，使用本地兜底 |

### 3.2 修改 prompt 后不生效

**原因**：Prompt 在服务启动时拉取并缓存。

```bash
# 必须重启服务
netstat -ano | grep ":2026" | grep LISTEN
taskkill //F //PID <pid>
.venv/Scripts/python.exe start_server.py

# 验证新 prompt 生效
grep "langfuse.*prompt.*生效" logs/agent-server.log
```

## 6. ClickHouse 查询参考

### 6.1 常用查询

```sql
-- 最近 10 条 traces
SELECT name, timestamp, user_id, session_id
FROM events_core
WHERE type = 'TRACE'
ORDER BY timestamp DESC
LIMIT 10;

-- 评分分布
SELECT name, avg(value) as avg_score, count() as total
FROM scores
GROUP BY name
ORDER BY total DESC;

-- 按模型统计成本
SELECT model, sum(cost) as total_cost, count() as calls
FROM events_core
WHERE type = 'GENERATION'
GROUP BY model;

-- 延迟分布
SELECT
    quantile(0.5)(latency) as p50,
    quantile(0.9)(latency) as p90,
    quantile(0.99)(latency) as p99
FROM events_core
WHERE type = 'TRACE'
  AND timestamp > now() - INTERVAL 7 DAY;

-- 按评分筛选 trace
SELECT t.name, t.timestamp, s.name as score_name, s.value
FROM events_core t
JOIN scores s ON t.trace_id = s.trace_id
WHERE s.name = 'sql_biz_correct_score'
  AND s.value < 0.5
ORDER BY t.timestamp DESC
LIMIT 20;
```

### 6.2 数据清理

```sql
-- 清理 90 天前的数据
ALTER TABLE events_core DELETE WHERE timestamp < now() - INTERVAL 90 DAY;
ALTER TABLE events_full DELETE WHERE timestamp < now() - INTERVAL 90 DAY;

-- 查看磁盘使用
SELECT table, formatReadableSize(sum(bytes)) as size
FROM system.parts
WHERE active
GROUP BY table;
```

## 7. 性能调优

### 7.1 SDK 参数调优

| 参数 | 默认值 | 调优建议 |
|------|--------|----------|
| `flush_interval` | 1s | 高频场景可增至 5s |
| `batch_size` | 100 | 大批量场景可增至 500 |
| `max_retries` | 3 | 网络不稳定时增至 5 |

### 7.2 大文本截断

```python
MAX_CHARS = 8000  # 环境变量 LARGE_RESULT_TRUNCATE_CHARS

def truncate_output(output):
    text = str(output)
    if len(text) > MAX_CHARS:
        return text[:MAX_CHARS] + f"... [truncated, total={len(text)}]"
    return text
```

### 7.3 评估成本控制

| 策略 | 方法 | 节省 |
|------|------|------|
| 采样 | `NL2SQL_EVAL_JUDGE_SAMPLE=0.1` | 70% |
| 降级模型 | Judge 用 GPT-4o-mini | 80% |
| 确定性优先 | 确定性评估全量，Judge 采样 | 视场景 |

## 8. SDK API 完整速查

### 8.1 核心 API

| 需求 | v4 API |
|------|--------|
| 客户端初始化 | `Langfuse()` / `get_client()` |
| 开启 trace | `with langfuse.start_as_current_observation(as_type="agent")` |
| 子 span | `with langfuse.start_as_current_observation(as_type="span")` |
| LLM 记录 | `as_type="generation", model=..., input=..., output=...` |
| 更新输出 | `obs.update(output=...)` / `obs.update(metadata=...)` |
| trace 级 IO | `langfuse.set_current_trace_io(input=..., output=...)` |
| trace 打分 | `langfuse.score_current_trace(name=..., value=..., comment=...)` |
| span 打分 | `langfuse.score_current_span(name=..., value=..., comment=...)` |
| 写分数 | `langfuse.create_score(name=..., value=..., trace_id=...)` |
| 生成 trace ID | `langfuse.create_trace_id()` |
| 刷盘 | `langfuse.flush()` |
| 连通检查 | `langfuse.auth_check()` |

### 8.2 Dataset API

| 需求 | API |
|------|-----|
| 获取数据集 | `langfuse.get_dataset("name")` |
| 遍历 items | `for item in dataset.items:` |
| 创建数据集 | `langfuse.create_dataset(name=..., description=...)` |
| 添加 item | `langfuse.create_dataset_item(dataset_name=..., input=..., expected_output=...)` |
| Run item | `langfuse.create_dataset_run_item(dataset_name=..., dataset_item_id=..., run_name=...)` |

### 8.3 Prompt API

| 需求 | API |
|------|-----|
| 获取 prompt | `langfuse.get_prompt(name=..., label="production")` |
| 创建版本 | `langfuse.create_prompt(name=..., prompt=..., labels=[...])` |
| 更新标签 | `langfuse.update_prompt_labels(name=..., version=N, new_labels=[...])` |
| 读取内容 | `prompt.prompt` / `prompt.config` |
| 变量编译 | `prompt.compile(var1=..., var2=...)` |
