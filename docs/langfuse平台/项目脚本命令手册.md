# 项目脚本命令手册

> 所有命令在任意目录的 **PowerShell** 中直接复制执行（已通过 `.venv/Lib/site-packages/_nl2sql_src.pth` 自动注册 `src` 到 Python 路径，无需设置 `PYTHONPATH`）
>
> Python 解释器：`D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe`
>
> 环境变量：脚本自动加载 `.env`（无需手动 source）

## 1. BadCase 状态管理（日常最常用）

### 交互式复审 pending badcase
```powershell
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status review
```
逐条展示待处理 badcase，自动打开 Langfuse trace 页面，按键标记：`f`=修好 / `i`=误报 / `r`=待修 / `s`=跳过 / `q`=退出。

### 列出 badcase 状态
```powershell
# 全部
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status list

# 只看待处理的
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status list --status pending
```

### 查看状态分布
```powershell
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status summary
```
输出各状态数量 + 回归集规模。

### 手动标记某条状态
```powershell
# 标记为已修复（支持 trace_id 前缀匹配，12 字符即可）
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status mark 9e0ad442c830 fixed --note "修复了 JOIN 逻辑"

# 标记为误报
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.badcase_status mark 707b335d invalid --note "用户测试差评"
```

## 2. BadCase 采集

### 采集近 N 天的 badcase
```powershell
# 默认扫近 1 天
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.collect_badcase --days 1

# 扫近 30 天，强制重新处理已采集项
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.collect_badcase --days 30 --force
```
差评/低分/异常的 session → 写入 Langfuse Dataset:badcase + 本地状态注册 pending。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--days` | 1 | 扫描近 N 天 |
| `--threshold` | 0.6 | 五维分低于此值视为低分 |
| `--limit` | 200 | trace 扫描上限 |
| `--force` | 关 | 忽略已采集 stamp，全部重处理 |

> **通常不需要手动跑**——每日 02:13 cron 自动执行（`scripts/daily_collect_badcase.ps1`）。

## 3. 真实反馈门禁

### 查看好评率报表
```powershell
# 只看报表，不做门禁判断
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.feedback_gate --days 7 --report-only
```

### 做 A/B 门禁对比
```powershell
# 对比 production vs prod-a，好评率差 > 5% 则 exit 1
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.feedback_gate --days 7 `
    --ref production --cand prod-a --threshold 0.05 --min-rated 5
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--days` | 7 | 统计窗口 |
| `--ref` | production | 基准组 prompt_label |
| `--cand` | prod-a | 对比组 prompt_label |
| `--threshold` | 0.05 | 好评率差值阈值 |
| `--min-rated` | 5 | 每组最少反馈数 |
| `--report-only` | 关 | 只看报表不门禁 |
| `--fail-insufficient` | 关 | 数据不足时 exit 2（默认 exit 0 跳过） |

> **通常不需要手动跑**——每日 02:13 cron 自动执行。

## 4. 离线 A/B 实验

### 用 badcase 集做回归测试
```powershell
# 单 label 跑（验证当前版本在 badcase 上的表现）
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.run_experiment `
    --from-badcase --labels production

# 双 label 对比 + 门禁（candidate 低于 reference → exit 1）
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.run_experiment `
    --from-badcase --labels production prod-a --threshold 0.05
```

### 用自定义查询集
```powershell
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.run_experiment `
    --queries queries.json --labels production prod-a
```
`queries.json` 格式：`[{"question": "查评分最高的电影", "db_name": "imdb"}]`

### 混合（badcase + 自定义查询）
```powershell
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.eval.run_experiment `
    --from-badcase --queries queries.json --labels production prod-a
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--from-badcase` | 关 | 用 Dataset:badcase 作为查询集 |
| `--from-badcase-limit` | 不限 | badcase 条数上限 |
| `--badcase-status` | pending,reviewed | 状态过滤，传 `all` 包含全部 |
| `--queries` | — | 自定义查询集 JSON 文件路径 |
| `--labels` | — | 参与对比的 label（首个为 reference） |
| `--judge` | 关 | 追加 LLM-judge 打分（慢，控成本） |
| `--threshold` | 0.05 | 门禁阈值 |
| `--timeout` | 1800 | 单 worker 超时秒数 |

## 5. Prompt 同步

### 同步主/子系统 prompt
```powershell
# 同步所有默认 prompt（main_system_prompt + nl2sql_system_prompt）
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.prompt.sync_prompts --all

# 只同步某一个
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.prompt.sync_prompts `
    --name main_system_prompt --file src/agent/prompts/main_system_prompt.md
```

### 同步全部 skill 到 Langfuse
```powershell
D:\code_work_space\llm\nl2sql\.venv\Scripts\python.exe -m agent.prompt.sync_prompts --skills
```
把 `shared_skills_dir` 下每个 SKILL.md 同步为 Langfuse prompt `skill/{group}/{name}`。新增 skill 后跑一次，消除 `Prompt not found during refresh` 警告。

| 参数 | 说明 |
|---|---|
| `--all` | 同步所有默认 prompt |
| `--skills` | 同步全部 SKILL.md |
| `--name` + `--file` | 指定单个 prompt 同步 |
| `--label` | 打标签（默认 production + latest） |
| `--commit` | 变更说明 |
| `--force` | 内容未变也强制新版本 |
